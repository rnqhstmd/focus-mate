## Testability 평가
8/10. 기존 모델/controller 테스트 및 UI seed/실패주입 seam을 재사용한다. 시간 입력만 native AX slider와 실제 DragGesture로 새 관찰 가능 인터페이스(time.ruler)가 생긴다. 배치/그라데이션 상수를 복사하는 테스트는 추가하지 않고 동일 기기 캡처를 직접 대조한다. 실제 햅틱/VoiceOver 체감 및 OS 위젯 표시의 물리 검증은 별도이며 자동 테스트 점수에 포함하지 않는다.
