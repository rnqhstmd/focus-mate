# PRD: W10 카드 꾸미기

## 배경
현재 iOS는 카드 ID·발급 시각과 기본 카드 외형을 제공한다. 웹은 사진·색·배치 편집을 제공하며, W10은 이 경험을 네이티브 카드 FR-4 / AC-6과 NFR-2 / AC-5로 구현한다. 저장 카드의 정체성과 정류장·여정·기록은 유지한다.

## 목표
발급 카드 한 장을 꾸미고 다시 편집하며 앱 재실행 후 사진·색·배치가 복원된다. 사진 원본이 사진 보관함에서 삭제되어도 저장한 사진을 사용할 수 있다. 실패하거나 취소한 작업은 기존 저장 데이터를 손상시키지 않는다.

## 요구사항
- [Must] 기존 회귀: W02 XXXL60분2014 선택 후 준비 진입, W01 XXXL본문 끝 도달을 보수한다. 시간WheelSpike20초 기준은 완화하지 않는다.
- [Must] FR-4: 발급 사용자는 메인에서 꾸미기를 열고 현재 저장 외형을 초안으로 받는다. W11 마이페이지 구현 전에도 사용할 최소 진입점을 제공한다.
- [Must] FR-4: 준비된 배경색과 사용자 지정 색상, 플랫폼 사진 선택으로 최대 6장의 사진을 편집한다.
- [Must] FR-4: 사진 선택·위치·비율을 유지한 크기·앞뒤 순서·삭제·되돌리기·기본 카드 복원을 제공한다.
- [Must] FR-4: 기본 카드는 서울 점묘 배경이다. 다른 배경색 또는 사진이 있으면 브랜드·이름·문구가 사라진다. IC 칩·비접촉 표시는 고정되고 사진은 카드 경계에서 잘린다. 카드 번호는 표시하지 않는다.
- [Must] FR-4: 변경이 있거나 사진 입력 중 종료하면 계속 편집/변경 버리기를 확인한다.
- [Must] NFR-2: 카드 외형과 사진 자체를 로컬 보존하고 실제 저장·재실행 복원을 검증한다. 저장 성공 후 공통 카드에 반영한다.
- [Must] NFR-2: 입력·읽기·저장 실패를 안내하고 재시도를 제공한다. 기존 카드·사진·이용 상태를 보존한다.
- [Should] FR-4: 사진 조작·선택·저장 상태를 보조기술로 구분하고 드래그 외 이동 조작을 제공한다. 전체 작업 공통 접근성 요구사항은 그대로 적용한다.

## 비즈니스 규칙
1. 꾸미기로 카드 ID·발급 시각·한 장 정책을 변경하지 않는다.
2. 초안과 저장 외형의 사진은 0~6장이다. 초과 선택은 선택 순서대로 남은 자리만 추가한다.
3. **확정 사진 정책:** 플랫폼이 읽을 수 있는 HEIC 등 사진, 입력 장당 8MiB(8×1024×1024바이트), 비율 0.1~10을 허용한다. 최종 보존 사진은 장당 1MiB(1,048,576바이트) 이하·전체 6MiB(6,291,456바이트) 이하로 제한한다. 사용자 모든 작업 진행 지시로 확정했다.
4. **확정 편집 범위:** 사진 너비는 카드 너비의 15~250%, 중심 위치는 카드 너비·높이 기준 각각 -100~200%, 앞뒤 한 단계 이동, 최근 20회 되돌리기를 적용한다. 같은 값 적용·선택만 변경은 이력을 만들지 않는다.
5. 초안은 저장 성공 전 저장 외형에 반영하지 않는다. 사진 선택 취소는 변경·되돌리기 이력을 만들지 않는다.
6. 사진 입력 중 저장·추가 입력·초안 변경은 막고 종료 확인은 허용한다. 버리기 후 늦게 완료된 입력은 반영하지 않는다.
7. 일부 사진 읽기 실패는 성공한 사진만 남은 자리까지 추가하고 실패를 안내한다. 모두 실패하면 이전 초안을 유지한다.
8. 외형과 사진 보존 모두 성공한 뒤 저장 완료를 안내한다. 실패하면 편집 화면·초안을 유지하고 기존 저장 카드·사진·정류장·여정·기록을 보존한다.
9. 저장 상태·사진 읽기 실패를 새 기본값으로 조용히 덮어쓰거나 자동 삭제하지 않는다. 오류·재시도를 제공하고 기존 명시적 정리·원본 보존 정책을 유지한다.
10. 버전 1·2 사용자를 계속 읽고 꾸미기 정보가 없으면 기본 외형으로 시작한다. 발급됐지만 카드 정보가 없는 사용자는 기존 카드 보충 규칙을 유지한다.
11. 카드 도메인은 ID·외형을 공급하며 접촉 성공·여행 완료·기록 합계를 결정하지 않는다.

## 사용자 시나리오
- 진입 → 색·사진 편집 → 저장 → 재진입·재실행 복원.
- 변경 후 종료 → 계속 편집하면 초안 유지, 버리면 마지막 저장 외형 유지.
- 사진 0장·6장·부분 입력 실패·입력 중 종료·저장 실패 후 재시도.
- 기존 사용자 데이터 읽기·꾸미기 후 보존, 저장 데이터 읽기 실패 후 원본 유지.

## 영향 범위
공통 PassFace 외형, 최소 화면 진입, 카드·사진 로컬 보존 및 기존 사용자 호환성. W04 승하차·W11 마이페이지는 저장 외형을 사용할 수 있지만 해당 화면 신규 구현은 포함하지 않는다. 서울 점묘·고정 장식 위치·색 목록·사진 잘림 등 시각 속성은 설계에서 정의하고 AC는 관찰 가능한 상태와 동작을 검증한다.

## 수용 기준
사진·편집 정책과 전체 진행을 사용자 지시로 확정했다. AC32·33은 기존 W02·W01 회귀 보수이며 새 카드FR로 등록하지 않는다.

### AC-W10-01: 진입
- Given: 발급 카드 한 장과 저장 외형이 있다
- When: 메인에서 꾸미기를 연다
- Then: 초안은 저장 외형과 같고 카드 ID·발급 시각·카드 수는 유지된다

### AC-W10-02: 미발급
- Given: 카드가 미발급이다
- When: 꾸미기 진입을 요청한다
- Then: 편집 초안을 만들지 않고 기존 발급 경로로 안내한다

### AC-W10-03: 색상
- Given: 기본색·사진 0장의 초안이다
- When: 준비된 색 또는 사용자 색을 선택한다
- Then: 초안 색은 선택값이며 저장 색은 이전값이다

### AC-W10-04: 사진 추가
- Given: 사진 0장이다
- When: 허용 사진 한 장의 읽기에 성공한다
- Then: 초안은 1장이고 선택·이동·크기·순서·삭제가 가능하며 저장 외형은 0장이다

### AC-W10-05: 입력 정책
- Given: 플랫폼이 읽을 수 있는 HEIC/JPG/PNG/WebP, 8,388,608바이트 및 8,388,609바이트, 비율0.1/10 및 범위 밖 사진이 있다
- When: 각 사진을 선택한다
- Then: 읽을 수 있고8,388,608바이트 이하·비율0.1~10인 사진은 추가하고 초과·범위 밖·읽기 불가능 사진은 추가하지 않으며 이유를 안내한다

### AC-W10-06: 최대 개수
- Given: 사진 6장이다
- When: 추가를 요청한다
- Then: 6장을 유지하며 추가를 제한하고 최대 6장 안내를 제공한다

### AC-W10-07: 초과 선택
- Given: 사진 5장이다
- When: 정상 사진 3장을 선택한다
- Then: 선택 순서의 첫 사진만 추가하여 6장이고 한도 안내를 제공한다

### AC-W10-08: 선택 취소
- Given: 사진 2장이고 되돌리기 이력이 없다
- When: 사진 선택을 취소한다
- Then: 사진·색·배치·순서를 유지하고 이력을 만들지 않는다

### AC-W10-09: 부분 실패
- Given: 사진 1장이다
- When: 정상 사진과 읽기 불가능 사진 각 한 장을 선택한다
- Then: 정상 사진만 추가하여 2장이고 실패 안내 후 저장·편집이 가능하다

### AC-W10-10: 모두 실패
- Given: 편집 초안이 있다
- When: 선택 사진 모두 읽기에 실패한다
- Then: 초안을 유지하고 실패 안내·다시 선택을 제공한다

### AC-W10-11: 이동·크기
- Given: 사진 두 장 중 한 장을 선택했다
- When: 선택 사진을 이동·크기 변경한다
- Then: 선택 사진의 중심·너비만 변경하고 원래 비율과 다른 사진·저장 외형을 유지한다

### AC-W10-12: 편집 경계
- Given: 선택 사진이 있다
- When: 중심 각축-100%/200%, 너비15%/250% 및 범위 밖 값을 요청한다
- Then: 경계값은 적용하고 중심 각축은-100~200%, 너비는15~250%로 제한한다

### AC-W10-13: 겹침 순서
- Given: 순서 A·B·C에서 B를 선택했다
- When: 앞으로 한 단계 이동한다
- Then: A·C·B이고 수·위치·크기는 같다. 맨앞 앞으로/맨뒤 뒤로 조작은 제한한다

### AC-W10-14: 삭제
- Given: 사진 6장 중 한 장을 선택했다
- When: 삭제한다
- Then: 5장이고 해당 사진만 제거되며 추가를 다시 사용할 수 있다

### AC-W10-15: 되돌리기
- Given: 사진 추가·색·이동·크기·순서·삭제를 수행했다
- When: 역순으로 되돌린다
- Then: 각 조작 직전 사진·색·배치·순서를 복원하고 저장 외형을 유지한다

### AC-W10-16: 되돌리기 한도
- Given: 서로 다른 상태 변경을21회 수행했다
- When: 20회 되돌린다
- Then: 첫번째 변경 직후 상태는 남고 추가 되돌리기는 불가능하다. 선택만 변경·같은 값 재적용은 이력을 만들지 않는다

### AC-W10-17: 기본 복원
- Given: 다른 색과 사진 3장이 있다
- When: 기본 카드로 복원한다
- Then: 초안은 기본색·0장, 저장 외형은 유지되며 한 번 되돌리면 복원 전 초안이다

### AC-W10-18: 표시 상태
- Given: 기본 카드와 다른 색 또는 사진이 있는 카드가 있다
- When: 공통 카드로 표시한다
- Then: 기본의 브랜드·이름·문구는 표시, 꾸민 카드에서는 숨김이다. IC·비접촉·경계 잘림은 활성이고 번호는 표시하지 않는다

### AC-W10-19: 변경 없는 종료
- Given: 초안은 저장 외형과 같다
- When: 종료한다
- Then: 버리기 확인 없이 이전 화면으로 돌아가며 저장 데이터는 같다

### AC-W10-20: 계속 편집
- Given: 미저장 변경이 있다
- When: 종료 요청 후 계속 편집한다
- Then: 편집 화면·초안·이력을 유지하며 저장 외형은 같다

### AC-W10-21: 변경 버리기
- Given: 미저장 변경이 있다
- When: 종료 요청 후 버린다
- Then: 이전 화면으로 돌아가고 재진입 초안은 마지막 저장 외형이며 기존 카드·사진·이용 상태는 같다

### AC-W10-22: 입력 중 종료
- Given: 사진을 불러오는 중이다
- When: 종료 확인에서 버린 뒤 읽기가 완료된다
- Then: 확인을 거쳐 이전 화면으로 돌아가고 늦은 사진은 초안·저장·공통 외형에 추가되지 않는다

### AC-W10-23: 입력 중 조작
- Given: 사진을 불러오는 중이다
- When: 저장·추가 입력·초안 변경을 요청한다
- Then: 조작은 실행되지 않고 입력 상태를 표시하며 완료·실패 후 다시 사용할 수 있다

### AC-W10-24: 실제 저장·복원
- Given: 사진 6장의 허용 초안이다
- When: 실제 저장 성공 후 종료·재실행한다
- Then: 색·사진 6장·위치·크기·순서는 저장값이고 ID·발급 시각은 같다. 성공 뒤에만 완료 안내한다

### AC-W10-25: 보관함 독립
- Given: 저장 후 보관함 원본을 삭제했다
- When: 앱을 재실행한다
- Then: 사진 수·내용·배치·순서는 삭제 전과 같다

### AC-W10-26: 저장 실패·재시도
- Given: 기존 저장 카드와 수정 초안이 있다
- When: 외형 또는 사진 보존에 실패하고 재시도한다
- Then: 실패 시 완료 안내 없이 초안·재시도를 유지하며 실제 저장 카드·사진·정류장·여정·기록은 기존값이다. 성공 후 수정값이 복원된다

### AC-W10-27: 보존 한도
- Given: 장당1,048,576/1,048,577바이트, 전체6,291,456/6,291,457바이트 결과가 있다
- When: 각각 저장한다
- Then: 장당1,048,576·전체6,291,456바이트 이하는 저장·복원되고 초과는 완료로 처리하지 않으며 초안·기존 데이터를 유지하고 용량을 안내한다

### AC-W10-28: 읽기 실패
- Given: 저장 상태 또는 사진을 읽을 수 없다
- When: 앱 시작·복원을 요청한다
- Then: 오류·재시도를 안내하고 자동 삭제·덮어쓰기 없이 원본을 유지한다

### AC-W10-29: 기존 데이터
- Given: 꾸미기 정보 없는 버전 1·2 사용자다
- When: 시작 후 꾸며 저장·재실행한다
- Then: 이용 단계·정류장·여정·기록과 기존 ID·발급 시각을 유지한다. 보충 대상은 카드 한 장을 얻고 매번 재발급하지 않는다

### AC-W10-30: 공통 외형·책임
- Given: 꾸미기를 저장했다
- When: 공통 외형을 조회한다
- Then: 저장 색·사진·배치·순서를 공급하고 여행 완료·기록 수·합계를 변경하지 않는다

### AC-W10-31: 접근성
- Given: 보조기술 사용 중 사진 한 장을 선택했다
- When: 편집·저장 조작을 탐색한다
- Then: 이름·선택·사용 가능 여부·현재값을 구분하고 드래그 없이 위치 변경할 수 있다

### AC-W10-32: W02 큰 글자 여정 선택 회귀
- Given: XXXL 글자 크기, 현재 정류장 성수역 정방향, 시간 선택 화면이다.
- When: 60분·2014 버스를 선택하고 진행한다.
- Then: 준비 화면에 진입하고 선택값 minutes60·busID2014·destination성동구민체육센터를 유지한다.
