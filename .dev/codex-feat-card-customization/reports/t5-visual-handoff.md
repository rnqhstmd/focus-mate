# T5 시안 구현 인계 — 독립 참조 검토

상태: **참조 검토 완료 / 최종 시뮬레이터 시각 일치 PENDING**. 이 문서는 구현 또는 UI 시험 통과 증거가 아니다.

## 근거와 우선순위

- `design.md`의 최종 계약 및 “시안 구현 기준 — 사용자 방향 재확인”을 읽었다.
- `design-reference/pencil-read.txt`와 R39 `z3LCu.png`, R40 `x3PCFl.png`를 직접 대조했다. 기준 프레임은 402×874pt이며 보존 PNG는 2배 표현(804×1748px)이다.
- 화면 구성은 R39/R40, 충돌하는 내용은 후속 확정 PRD와 서체 결정이 우선한다. 이전 bright palette나 일반 Form 구성으로 대체하지 않는다.

글자 위계는 제목20/섹션15/안내12/저장15pt이며 보조 저장 안내는11pt 기준이다. 주요 글자는 흰색, 안내 #B8BFC5, 보존 안내 #B0BAC2다. **서울알림체 Medium/Bold**가 최종 기준이며 Pencil의 Noto Sans KR 표기를 그대로 채택하지 않는다. 서체 교체로 자폭이 달라질 수 있으므로 텍스트 폭을 강제로 축소해 옛 픽셀 위치에 맞추지 않는다.

## 카드와 선택 사진

- 기본 카드의 브랜드는 내부 x20/y17.2, 카드명은 x84.47/y89.16, 목적 문구는 x84.47/y137.08 부근이다. IC는 x26.78/y96.25/40.68×30.68, 비접촉 표시는 우측 x319/y14.65 부근이다. 카드 크기 변경 시 이 상대 배치를 비교한다.
- R40은 샌드 바탕 위 사진 2장이다. 첫 사진은 카드 왼쪽·위 밖으로 나가 잘리고, 두 번째 사진은 오른쪽 아래에서 겹친다. 두 번째 사진의 흰 선택 테두리와 오른쪽 아래 크기 손잡이, 두 번째 썸네일의 흰 선택 테두리가 대응한다.
- 선택 사진·목록·크기 수치는 같은 대상을 가리켜야 한다. R40의 53%는 예시 사진 너비이며 모든 사진의 고정 기본값이 아니다. 확정 계약의 초기 너비60%와 편집 범위를 유지한다.
- PNG 하단에는 “사진 크기”와 53%가 보이지만 슬라이더 트랙은 뚜렷하지 않다. 이 래스터의 생략을 슬라이더 제거 근거로 쓰지 않는다. 최종 설계의 크기 슬라이더와 X/Y·앞뒤·삭제를 선택 사진 도구 영역에 연결한다.
- 시각적 둥근 clip과 터치 경계는 별도로 확인한다. 카드 밖 사진·손잡이가 아래 안내나 색상 조작을 가로채면 실패다. 완전히 밖으로 이동한 사진도 목록에서 재선택하고 위치 제어로 복귀할 수 있어야 한다.
- IC·비접촉 표시는 사진 위에서 고정된다. 공통 PassFace의 그림과 편집용 선택·제스처 계층을 혼동하여 저장 후 공통 카드에 선택 테두리를 남기지 않는다.

## 후속 결정에 따라 허용·필수인 차이

- R39/R40에 보이는 **카드 번호는 두 상태 모두 제거**한다. R40의 브랜드 배지와 번호 배경도 복제하지 않는다.
- 다른 색 또는 사진이 있으면 브랜드·카드명·목적 문구를 숨긴다. 기본 상태의 “나를 위한 시간, 한 장으로.”는 승인 시안 문구이므로 사용할 수 있다.
- 기본 카드 서울 점묘는 확정 PRD에 따라 유지한다. 참조 PNG에서 점묘가 뚜렷하지 않다는 이유로 제거하지 않는다.
- 서울알림체, Dynamic Type 재배치, 명시된 위치·순서·삭제 접근성 조작은 승인 계약의 반영이다. W11 전체 마이페이지나 W04 신규 화면, 임의 새 도구를 추가할 허가는 아니다.

## XXXL·고정 저장·최종 캡처

- 기본 글자 402×874pt 화면에서 R39 기본/빈 사진 상태와 R40 샌드/사진 2장/두 번째 선택 상태를 각각 캡처한다. 다른 디바이스라면 pt 크기·scale·safe area를 기록하고 동일 pt 기준으로 비교한다. 해상도만 맞추려고 화면 비율을 늘이지 않는다.
- 원본 PNG와 시뮬레이터 원본을 보존하고, 비교용 이미지만 같은 논리 크기로 맞춘다. 상태바 시각·기기 아이콘은 콘텐츠 불일치로 판정하지 않는다.
- 먼저 카드 비율·좌우 여백·헤더 위계·색 순서·CTA 위치를 비교하고, 이어 글자·선택 링·사진 겹침·고정 장식을 확인한다. 단순 픽셀 차이 수치만으로 서체 후속 결정이나 PRD 예외를 실패 처리하지 않는다.
- XXXL은 기본 상태와 사진 선택 상태의 시작/끝 스크롤을 남긴다. 사진 도구·기본 복원·마지막 안내 전체가 고정 저장 버튼 위로 올라와 읽히고 모든 조작에 도달해야 한다. 선택 도구의 수직 재배치와 본문 길이 증가는 허용한다. 글자 축소나 본문 고정 높이로 잘림을 숨기면 실패다.
- 취소 확인과 가져오기/저장 오류는 별도 캡처한다. 기존 초안이 유지되고 안내·재시도·계속 편집/버리기가 읽혀야 한다. 시스템 확인창의 플랫폼 모양을 새 커스텀 화면으로 재설계하지 않는다.
- 캡처만으로 clip 밖 hit, 드래그, 저장, 실제 PhotosPicker, VoiceOver를 PASS 처리하지 않는다. 상호작용 결과와 시각 대조는 별도 증거다.

**최종 판정은 T5 실제 구현 후 수행한다. 현재 실제 시뮬레이터 화면 대조, XXXL 전체 도달, 실제 PhotosPicker·VoiceOver 확인은 이 인계에서 검증하지 않았다.**

## 부모 실제 font descriptor 확인
원본 TTF를 설치하지 않고 CoreText CTFontManagerCreateFontDescriptorsFromURL로 읽었다. PostScript명은 Medium=`SeoulAlrimTTF-Medium`, Bold=`SeoulAlrimTTF-Bold`. font-probe.log/SDK probe exit0. 번들등록 또는 실제SwiftUI화면의서체적용은아직미검증이며T5에서확인한다. 기존 SOURCE.md의서울시출처·이용조건을복사본과함께유지한다.
