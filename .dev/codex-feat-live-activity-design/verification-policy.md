# 사용자 지정 검증 순서 (2026-10-16)

사용자 지시: W17 → W09b → W18 위젯 구현 완료까지 관련 테스트만 실행하고, 마지막에 전체 테스트·빌드를 실행해 수정한다.

- 진행 중: RED 실패 확인, 변경 관련 focused 테스트, 필요한 iOS 빌드와 시각 확인.
- 중간 전체 기준선/회귀/verify는 최종 통합 검증으로 이연한다. 각 작업의 전체 verify를 통과했다고 기록하지 않는다.
- W18까지 완료한 뒤 config의 전체 Node/iOS/Python 테스트·빌드를 실행하고 실패를 수정한다.
- 최종 전체 검증 전 main 병합하지 않는다. 순차 구현은 현재 통합 브랜치에서 진행하며 단계별 문서와 변경을 보존한다.
- 기존 baseline 전체 iOS 테스트는 사용자 지시로 중단; Node test/build는 이미 exit0. 중단한 실행을 실패나 통과로 집계하지 않는다.
