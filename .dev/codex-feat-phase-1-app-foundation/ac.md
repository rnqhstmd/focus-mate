# Phase 1 앱 기반 — 범위 초안

2026-10-12 사용자 범위 승인. SwiftUI·최소 iOS17은 승인된 우선 작업 기준이며 출시 설정 확정이 아니다. 현재 native 소스/프로젝트는 없고 Xcode 약관이 미동의다.

## 배경

현재 웹/Pen 흐름을 native로 연결할 앱 진입·화면 전환·로컬 저장 기반을 만든다. 제품의 단계 구분은 유지하고 Phase2~6의 기능을 구현 완료로 표시하지 않는다.

## 요구사항 (AC)

AC-1: 저장 상태에 따른 앱 진입
  Given: 정상 앱 상태가 없거나 카드/최초 정류장 설정 상태가 저장되어 있다.
  When: 앱을 새로 실행한다.
  Then: 저장 없음은 첫 이용 진입점, 발급 후 최초 정류장 설정 전은 설정 진입점, 설정 완료 상태는 현재 정류장 메인으로 진입한다.

AC-2: 기본 화면 전환과 뒤로가기
  Given: 메인에 진입한 상태다.
  When: 여행 준비·기록·설정·마이페이지를 열고 뒤로 돌아간다.
  Then: 요청한 기본 화면으로 이동하고 이전 화면/메인으로 복귀하며 저장된 출발 상태는 바뀌지 않는다.

AC-3: 로컬 저장·복원 및 손상 데이터 보존
  Given: 지원 버전의 앱 상태, 손상 데이터 또는 미지원 버전의 기존 데이터가 있다.
  When: 저장·앱 재실행 복원 또는 데이터 읽기를 수행한다.
  Then: 지원 상태는 같은 값으로 복원되고 손상/미지원 데이터는 자동 삭제·덮어쓰기 없이 오류로 보고된다. 저장 실패를 성공으로 안내하지 않는다.

## 검증 전제

- Xcode 라이선스는 사람이 직접 검토·동의해야 한다. simctl과 compiler/SDK가 준비된 뒤 native 하네스를 구성한다.
- Native 빌드/테스트 명령과 실행 환경을 먼저 확인한다. 기존 npm/VM 통과를 Swift 검증으로 간주하지 않는다.
- 앱 기반을 위한 프로젝트/테스트 하네스 구성과 실제 기능 RED→GREEN을 구분한다. runner 미실행이나 compiler 오류만을 정상 behavioral RED로 판정하지 않는다.
- 최소 iOS/시뮬레이터/로컬 개발 bundle ID는 제안/환경 선택이고, 배포 Team·서명은 확정하지 않는다.

## 범위 경계

후속 단계의 카드 발급·버스/시간/태그/소리 선택·승하차·MapKit 코스/타이머·기록 분석·꾸미기와 backend는 완료 범위 밖이다. 이번 화면은 그 기능을 연결할 기본 진입과 이동 경로다.
Phase0 실제 승차/태그 화면 확인2건은 계속 pending이며 Phase1 착수가 그 확인을 대체하지 않는다.
