# 빈 iOS 하네스 구축

## 배경

gx-tdd 레이어별 하네스 게이트에서 native 러너가 없음을 확인했다. 사용자가 승인한 앱 기반·테스트 구성 및 “모두 진행” 범위에서 gx-dev 방식으로 빈 하네스만 별도 구축한 뒤 gx-tdd를 재개한다. 이 작업은 제품 동작 RED/GREEN이나 AC 완료가 아니다.

## 요구사항 (AC)

- H-AC-1: iOS 17 SwiftUI 빈 앱과 공유 FocusMate scheme이 iOS 27 Simulator 대상으로 빌드된다.
- H-AC-2: 연결된 단위 테스트 1개와 빈 앱 UI 실행 검사 1개가 실제 실행돼 0 failures다.
- H-AC-3: 카드/정류장/라우팅/저장 등 제품 수용 동작은 선구현하지 않는다. 웹 및 Pen 자료는 유지한다.

사용자 승인 근거: Phase1 “앱 기반과 테스트 구성” 승인 및 전체 과정 “모두 진행”. 별도 범위 확장·재승인 없음. 실제 실행 명령과 결과는 harness-bootstrap.md에 기록하고 이후 제품 TDD를 시작한다. 제품 검증 전체 통과 전 커밋/PR하지 않는다.
