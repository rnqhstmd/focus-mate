# Phase 1 PR 맥락

## 배경

웹 시안과 디자인 자료만으로는 저장된 이용 단계에 맞춰 실행되는 iOS 앱을 검증할 수 없었다. Phase1은 SwiftUI 앱 진입, 기본 화면 왕복, 로컬 상태 저장과 복원 기반을 추가한다.

## 요구사항과 결과

무저장은 카드 진입, 카드 발급만 저장된 상태는 최초 정류장 진입, 설정 완료 상태는 저장된 현재 정류장 메인으로 실행된다. 여행 준비·기록·설정·마이페이지 기본 화면 왕복은 저장 상태를 변경하지 않는다. 손상·미지원 원본은 덮어쓰지 않고 오류를 보고하며 저장 실패는 성공으로 안내하지 않는다.

전체 시안 이식·실제 카드 발급·정류장 선택·지도·타이머·기록 생성은 Phase2~6에 남긴다. Phase0 미확인 화면2건도 기존 대기를 유지한다.

## 검증

UI8건의 실제 assertion RED→GREEN, R1 추가2건 RED→GREEN을 기록했다. 추가 제품 Unit14건과 UI10건, smoke2건을 전체 실행한다. 웹31 tests/VM26 경계 검사와 양쪽 build가 검증 대상이다. Release에서 시험 인자·진단 문자열 제외를 확인했다. 실제 원자 교체 실패·전원 장애와 실기기는 미검증이다.
