# PRD: Phase 1 iOS 앱 기반

상태: 2026-10-12 사용자 “모두 진행”으로 PRD 확인 및 후속 전체 과정 진행 승인.

## 배경

Focus Mate의 네이티브 iOS 앱은 아직 시작되지 않았다. 이번 단계는 이후 기능을 연결할 앱 진입, 기본 화면 이동, 로컬 상태 저장·복원 기반을 마련한다. SwiftUI와 최소 iOS 17은 우선 작업 기준이며 출시 설정 확정이 아니다. gx-tdd는 표준 프로파일의 전체 과정으로 진행한다.

## 목표

사용자가 저장된 이용 단계에 맞는 화면에서 시작하고, 메인의 기본 경로를 왕복하며, 지원 상태를 재실행 후에도 같은 값으로 이어가게 한다. 손상·미지원 데이터와 저장 실패를 성공으로 오인시키지 않는다.

## 요구사항

### 기능 요구사항

- **[Must] P1-FR-1 — 이용 단계별 진입:** 저장 데이터가 없으면 첫 이용/집중동행카드 발급 진입점을 연다. 카드 발급 정보는 있으나 최초 정류장 설정 전이면 최초 정류장 설정 진입점을 연다. 설정 완료 상태면 저장된 현재 정류장을 보여주는 메인을 연다.
- **[Must] P1-FR-2 — 기본 화면 연결:** 메인에서 여행 준비, 기록, 설정, 마이페이지 기본 화면을 각각 열고 뒤로가기로 이전 화면 또는 메인에 복귀할 수 있다. 이동과 복귀는 저장된 출발 상태를 바꾸지 않는다.
- **[Must] P1-FR-3 — 상태 저장과 복원:** 지원되는 앱 상태를 로컬에 저장하고 재실행하면 같은 값과 이용 단계를 복원한다.

### 비즈니스 규칙

- **[Must] P1-BR-1 — 기존 데이터 보존:** 손상 데이터와 미지원 버전 데이터는 명시적 정리 없이 자동 삭제하거나 덮어쓰지 않고 오류로 보고한다.
- **[Must] P1-BR-2 — 실패 안내의 정확성:** 저장 실패 시 성공 안내를 표시하지 않고 재실행 복원이 보장되지 않는 상태임을 구분한다.
- **[Must] P1-BR-3 — 단계 경계:** 상태 준비용 테스트 입력은 허용하지만, 후속 기능이 끝난 것처럼 보이는 사용자용 완료 버튼이나 가짜 완료 동작은 제공하지 않는다.

## 사용자 시나리오

1. 처음 앱을 연 사용자는 첫 이용/카드 발급 진입점을 본다.
2. 카드 발급 정보만 있는 사용자는 최초 정류장 설정 진입점에서 이어간다.
3. 최초 정류장 설정을 마친 사용자는 저장된 현재 정류장이 표시된 메인에서 시작한다.
4. 사용자는 메인에서 여행 준비·기록·설정·마이페이지 기본 화면을 확인하고 메인으로 돌아온다.
5. 저장 오류나 읽을 수 없는 데이터가 있으면 성공이나 초기화 완료 안내 대신 오류 상태를 본다.

## 영향 범위

- 카드 발급 및 접촉 화면의 진입 기반은 **카드 도메인 iOS FR-3**에 부분 연결된다. 실제 발급·접촉·사진 입력 완료를 뜻하지 않는다.
- 기록 화면과 상태 기반은 **기록 도메인 iOS FR-5**에 부분 연결된다. 기록 생성·메모·집계는 포함하지 않는다.
- 설정 화면 진입은 **환경·복구 설정 도메인 iOS FR-3**에 부분 연결된다. 접근성·모션 기능 완료를 뜻하지 않는다.
- 여정 상태 기반은 제공하지만 **여정 도메인 iOS FR-5, FR-6, NFR-2**의 타이머·MapKit·실기기 검증은 충족하지 않는다.

## 수용 기준

### P1-AC-1 — 진입 분기 (P1-FR-1, P1-FR-3)

Given: 저장 데이터가 없는 상태, 카드 발급 정보만 있고 `initialStation`이 없는 상태, 카드와 `initialStation` 및 현재 정류장이 저장된 상태가 각각 준비되어 있다.

When: 각 상태에서 앱을 실행한다.

Then: 첫 경우는 첫 이용/카드 발급 진입점, 둘째는 최초 정류장 설정 진입점, 셋째는 저장된 현재 정류장 값을 표시하는 메인이 열린다.

### P1-AC-2 — 기본 화면 왕복 (P1-FR-2, P1-BR-3)

Given: 저장된 현재 정류장과 출발 상태로 메인에 진입해 있다.

When: 여행 준비, 기록, 설정, 마이페이지를 하나씩 열고 각 화면에서 뒤로간다.

Then: 선택한 이름의 기본 화면이 열리고 이전 화면 또는 메인으로 복귀하며, 왕복 전후의 현재 정류장과 출발 상태 값이 같다. 이번 기본 진입 화면에는 카드 발급·최초 정류장 선택·여행·기록 등 후속 기능을 완료하는 사용자용 버튼이나 완료 동작이 나타나지 않는다.

### P1-AC-3 — 지원 상태 복원 (P1-FR-3)

Given: 지원 버전의 카드 발급 여부, `initialStation`, 현재 정류장 값이 준비되어 있다.

When: 상태를 저장하고 앱을 종료한 뒤 다시 실행한다.

Then: 세 값이 저장 전과 같고 그 값에 해당하는 진입 화면이 열린다.

### P1-AC-4 — 손상·미지원·저장 실패 (P1-BR-1, P1-BR-2)

Given: 손상된 원본 데이터, 미지원 버전 원본 데이터, 저장 실패 조건이 각각 준비되어 있다.

When: 앱이 원본을 읽거나 새 상태를 저장한다.

Then: 손상·미지원 원본은 삭제되거나 바뀌지 않고 오류가 보고되며, 저장 실패에는 성공 안내가 나타나지 않는다.

## 제외 범위

카드 발급과 최초 정류장 선택의 실제 상호작용, 공통 카드 접촉, 사진 저장, 실제 여행 준비·승하차, 실제 분 타이머, MapKit 지도, 기록 생성·메모·집계, 접근성·모션 완성, 실제 GPS·버스 API·서버·계정·클라우드는 제외한다. 홈은 지도 중심 구성을 참고하되 지도 구현은 Phase 3 범위다.

Phase 0의 승차·태그 브라우저 검증 2건은 계속 대기 상태다. PRD 작성 당시 개발 도구 확인은 Xcode 라이선스 오류(exit 69)였다. 이후 사용자의 직접 동의와 iOS27 설치를 확인했다. 현재 실행 증거는 reports와 docs/PHASE-1-FOUNDATION.md에 별도 기록한다.
