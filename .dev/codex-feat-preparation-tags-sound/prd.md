# PRD: W03 준비 허브·태그·소리

상태: 2026-10-14 사용자 ‘모두 진행’으로 범위 승인. 이후 사용자 지시로 브라우저 화면 확인은 보류하고 설계·TDD를 진행한다. 브라우저 화면 확인 완료로 판정하지 않는다. 설계 확정, 기존 회귀 GREEN 확인 후 RED 진입 예정.

## 배경

W02에서 시간·버스·도착지 선택을 마친 사용자가 태그·할 일·소리를 정하고 후속 단계에 전달해야 한다. 현재 iOS 준비 화면은 W02 선택값을 받는 자리표시자다. 대상은 journey FR-9 준비 허브·태그와 FR-10 소리 선택·재생이다.

최신 docs/FLOWS.md 2026-10-13 3차는 인라인 태그 칩과 `+` 진입을 정의한다. 기존 별도 `tags` 선택 화면·태그 관리는 신규 iOS 기능으로 추가하지 않는다. Phase 0 문서의 이전 `tags` 확인 항목은 최신 경로와 대조가 필요하다. 실제 브라우저 열기는 사용자 거절로 차단되었고 화면·뒤로가기·초안 보존을 확인하지 않았다. 소스 대조와 자동 검사로 이 게이트를 통과 처리하지 않는다.

## 목표

- 유효한 여정·태그·비공백 할 일이 있을 때만 준비를 확정한다.
- 태그 만들기·소리 선택·뒤로가기에서 실행 중 입력을 유지한다.
- 소리 없음·재생 실패가 준비 완료를 막지 않는다.
- W04가 소비할 확정 준비값을 제공하고 진행 여정·완료 기록은 만들지 않는다.

## 요구사항

### 기능 요구사항

- [Must] FR-9: ‘무엇을 할까요?’ 제목, 태그 선택·추가, 선택 후 한 줄 할 일 입력, 현재 소리, ‘승차권 보기’를 제공한다. 최초 준비는 태그 미선택·빈 할 일이다.
- [Must] FR-9: 독서·공부·업무·휴식 중 한 태그를 선택한다. 선택만으로 할 일을 자동 입력하지 않는다.
- [Must] FR-9: `+`의 ‘태그 만들기’에서 이름·아이콘·색을 정한다. 유효한 ‘태그 저장’은 준비로 돌아와 새 태그를 선택한다. 취소는 추가하지 않는다.
- [Must] FR-9: 태그·소리 편집과 준비→시간→준비 왕복에서 세션 초안을 유지한다. 유효하지 않은 여정은 준비 확정을 차단한다.
- [Must] FR-9: ‘승차권 보기’는 준비값을 확정하고 후속 단계 진입 요청을 제공한다. 실제 승차권과 접촉은 W04다.
- [Must] FR-10: 버스·비 오는 버스·지하철·숲속·소리 없음 중 하나를 선택한다. 기본 확정 소리는 버스다.
- [Must] FR-10: 임시 선택과 확정값을 구분한다. ‘소리 저장’은 확정하고 취소는 이전 확정값을 유지한다.
- [Must] FR-10: ‘선택한 소리 미리 듣기’를 누르면 반복 재생하고 다시 누르면 중지한다. 선택만으로 자동 재생하지 않는다.
- [Must] FR-10: 시작·중지 페이드를 적용한다. 선택 변경·저장·취소·화면 이탈·앱 비활성화 시 중지하고 이전 요청의 늦은 완료로 재생하지 않는다.
- [Must] FR-10: 재생 실패를 안내하고 무음 상태로 선택·저장·준비를 계속 허용한다.
- [Must] FR-9/FR-10: 이름·선택 상태·사용 가능 여부·현재 값을 접근성으로 제공한다. 큰 글자·동작 줄이기에서도 같은 흐름을 사용할 수 있어야 한다.

### 비즈니스 규칙

- [Must] BR-1 → FR-9: 완료 조건은 유효한 W02 여정·존재하는 태그 한 개·양 끝 공백과 줄바꿈을 제거한 비공백 할 일이다. 소리 없음·오디오 실패는 차단 조건이 아니다.
- [Must] BR-2 → FR-9: 태그 이름은 양 끝 공백·줄바꿈을 제거하고 UTF-16 1~20단위다. NFKC 정규화 후 소문자로 비교해 중복을 차단하고 표시 이름의 대소문자는 유지한다.
- [Must] BR-3 → FR-9: 할 일 입력은 UTF-16 최대 80단위다. 확정할 때 양 끝 공백·줄바꿈을 제거한다. 진행 여정·기록의 500단위 저장 유효성 상한으로 입력 범위를 확대하지 않는다.
- [Must] BR-4 → FR-9: 아이콘은 독서·업무·공부·개발·쓰기, 색은 모래빛·파랑·보라·초록·분홍 중 하나다. 최초 편집값은 빈 이름·독서·모래빛이다.
- [Must] BR-5 → FR-9/FR-10: 준비 초안·추가 태그·확정 준비값은 세션 값이다. 재실행 복원·영속 태그 라이브러리·저장 구조 변경은 추가하지 않는다.
- [Must] BR-6 → FR-9/FR-10: 전달값은 W02의 시간·버스·출발/도착·방면·정류장/거리, 태그 이름·아이콘·색, 정리한 할 일, 확정 소리 식별자를 포함한다. 진행 여정·진도·완료 기록은 생성하지 않는다.
- [Must] BR-7 → FR-10: 식별자는 bus/rainBus/subway/forest/none이다. 출처·라이선스 확인된 기존 네 샘플을 사용하며 사람 목소리 녹음·새 소리는 추가하지 않는다.
- [Must] BR-8 → FR-10: 미리듣기는 최대 한 개다. none은 재생 요청이 없다. 실패 시 소리 식별자를 임의로 none으로 바꾸지 않는다.
- [Must] BR-9 → FR-10: 시작 120ms·중지 60ms 페이드를 유지한다. 앱 복귀·준비 진입에서 미리듣기를 자동 재개하지 않는다.
- [Must] BR-10 → FR-9/FR-10: 태그·소리 취소는 할 일과 여정 선택을 바꾸지 않는다. 닫힌 화면에 접근성 포커스를 남기지 않는다.

## 디자인 표현 계약

태그색 칩·아이콘, 두 줄 가로 스크롤, 마지막 `+`, 선택 배경·테두리, 입력 테두리, 소리 칩 왼쪽·승차권 버튼 오른쪽 배치는 후속 디자인 명세에 연결한다. 색·여백·폰트·애니메이션 모양은 기능 테스트의 assert 대상에서 분리한다.

버스·시간·정류장 부제목, 태그 관리, 별도 할 일 화면, 중복 제목, 시각적 하단 안내는 추가하지 않는다. 입력 라벨과 상태 안내는 화면 낭독기에 제공한다.

## 사용자 시나리오

- 정상: W02 완료 → 준비 → 태그 → 할 일 → 소리 선택·미리듣기 → 저장 → 준비값 전달.
- 새 태그: `+` → 이름·아이콘·색 → 저장 → 새 태그 선택과 기존 할 일 유지.
- 차단: 미선택·공백 할 일·빈 태그·중복·이름 상한 초과.
- 취소·왕복: 태그 취소·소리 취소·시간 화면 왕복에서 세션 초안 유지.
- 오디오 오류·이탈: 실패를 안내하고 준비 계속. 이탈·비활성화·늦은 완료로 재생 재개 없음.
- 저장 실패 환경: W03은 저장을 시도하지 않고 기존 복구·원본 보존 계약을 유지한다.

## 영향 범위와 호환성

W02 준비 자리표시자를 실제 준비 기능으로 바꾸고 기존 ‘뒤로가기만 존재’ 검사를 새 계약으로 교체한다. W02 선택·최초 정류장 저장과 카드·기록·복구 데이터는 유지한다. 웹의 별도 tags 경로는 이식하지 않는다. 이전 소리 식별자 변환은 후속 진행 여정 저장·복원에서 다룬다. W04는 승차권·접촉, W05는 집중 여행 소리·타이머 통합을 담당한다.

## 수용 기준

‘전달’은 W04가 소비할 준비값·진입 요청 경계이며 실제 승차권 화면은 아니다.

### AC-1: 최초 준비 → FR-9 / BR-1,5
- Given: 유효한 W02 선택으로 새 준비에 진입한다.
- When: 준비 허브가 열린다.
- Then: 제목은 ‘무엇을 할까요?’, 태그 없음·빈 할 일·입력 숨김·확정 소리 bus·승차권 보기 비활성이다.

### AC-2: 태그 선택 → FR-9 / BR-1
- Given: 태그 미선택이다.
- When: 독서를 선택한다.
- Then: 독서 한 개 선택·할 일 입력 표시·입력 빈 값·승차권 보기 비활성이다.

### AC-3: 공백 차단 → FR-9 / BR-1,3
- Given: 태그를 선택했다.
- When: 빈 값 또는 공백·줄바꿈만 입력한다.
- Then: 승차권 보기 비활성이고 전달 횟수는 0이다.

### AC-4: 할 일 상한 → FR-9 / BR-3
- Given: 태그·여정이 유효하다.
- When: UTF-16 80단위 할 일 뒤에 추가 입력·붙여넣기를 시도한다.
- Then: 입력은 80단위를 넘지 않고 비공백 80단위는 확정 가능하다.

### AC-5: 태그 만들기 → FR-9 / BR-2,4
- Given: 준비 초안이 있다.
- When: +를 누른다.
- Then: 태그 만들기가 열리고 이름 빈 값·독서 아이콘·모래빛이며 준비 초안은 동일하다.

### AC-6: 빈 이름 → FR-9 / BR-2
- Given: 태그 이름이 빈 값·공백뿐이다.
- When: 저장을 요청한다.
- Then: 이름 오류가 표시되고 태그 수·선택은 동일하며 편집 화면에 남는다.

### AC-7: 중복 이름 → FR-9 / BR-2
- Given: 기존 이름과 NFKC·소문자 비교 결과가 같은 이름이다.
- When: 저장을 요청한다.
- Then: 중복 오류·추가 횟수 0이다. 대소문자·전각/반각 차이를 각각 검증한다.

### AC-8: 이름 상한 → FR-9 / BR-2
- Given: 중복되지 않는 이름이다.
- When: UTF-16 20단위·21단위 저장을 각각 요청한다.
- Then: 20은 저장 가능하고 21은 저장되지 않는다.

### AC-9: 태그 저장 → FR-9 / BR-2,4,5
- Given: 이름·아이콘·색이 유효하다.
- When: 저장을 한 번 완료한다.
- Then: 정리한 이름·아이콘·색의 태그 한 개 추가·선택 후 준비로 돌아오고 할 일·여정은 동일하다.

### AC-10: 태그 취소 → FR-9 / BR-10
- Given: 준비에서 태그 만들기를 열어 편집했다.
- When: 취소·뒤로가기를 한다.
- Then: 추가 0, 선택 태그·할 일·소리·여정은 동일하고 포커스는 새 태그 추가로 돌아온다.

### AC-11: 시간 왕복 → FR-9 / BR-1,10
- Given: 준비 초안이 있다.
- When: 시간으로 돌아갔다 유효한 선택으로 준비에 재진입한다.
- Then: 태그·할 일·확정 소리는 동일하다. 시간 변경으로 후보가 해제되면 전달 0이다.

### AC-12: 확정 준비 전달 → FR-9 / BR-1,6
- Given: 유효 여정·태그·‘  책 읽기  ’·확정 소리다.
- When: 승차권 보기를 요청한다.
- Then: 할 일은 ‘책 읽기’, 태그 정의·소리·W02 선택값이 일치하고 진행 여정·기록 생성은 각각 0이다.

### AC-13: 직접 호출 차단 → FR-9 / BR-1
- Given: 여정·태그·할 일 중 하나가 유효하지 않다.
- When: 준비 확정을 직접 요청한다.
- Then: 확정 준비값·후속 요청이 생성되지 않는다.

### AC-14: 소리 화면 → FR-10 / BR-7
- Given: 확정 소리는 bus다.
- When: 소리 칩을 누른다.
- Then: 소리 선택의 다섯 선택지·임시 bus가 표시되고 재생 시작은 0이다.

### AC-15: 소리 취소 → FR-10 / BR-10
- Given: 확정 bus·임시 forest다.
- When: 취소·뒤로가기를 한다.
- Then: 확정 bus를 유지하고 준비로 돌아오며 할 일·태그·여정은 동일하다.

### AC-16: 소리 저장 → FR-10 / BR-7
- Given: 임시 rainBus다.
- When: 소리 저장을 누른다.
- Then: 확정 rainBus·준비 현재 값 ‘비 오는 버스’이며 준비로 돌아온다.

### AC-17: 미리듣기 반복 → FR-10 / BR-8,9
- Given: 네 샘플 중 하나를 선택했다.
- When: 미리듣기를 누르고 샘플 길이를 지난다.
- Then: 한 샘플만 반복, 시작 페이드 요청 120ms, 버튼 ‘미리 듣기 중지’와 재생 상태 노출이다.

### AC-18: 미리듣기 중지·변경 → FR-10 / BR-8,9
- Given: 미리듣기 재생 중이다.
- When: 중지·다른 소리 선택을 한다.
- Then: 중지 페이드 60ms 요청·중지 후 재생 0이며 새 선택만으로 시작 횟수가 늘지 않는다.

### AC-19: 소리 없음 → FR-10 / BR-8
- Given: none을 선택했다.
- When: 미리듣기 요청·소리 저장을 한다.
- Then: 재생 시작 0·확정 none·준비 ‘소리 없음’이며 유효한 준비를 차단하지 않는다.

### AC-20: 오디오 실패 → FR-10 / BR-8
- Given: 샘플 준비·재생이 실패한다.
- When: 실패 결과가 반환된다.
- Then: 안내·중지 상태이며 선택값을 바꾸지 않고 소리 저장·유효 준비 확정이 가능하다.

### AC-21: 늦은 완료 → FR-10 / BR-9
- Given: 미리듣기 준비 요청 중이다.
- When: 선택 변경·저장·취소·화면 이탈·비활성화 후 이전 요청이 완료된다.
- Then: 이전 샘플 시작 0·현재 선택 유지다.

### AC-22: 이탈·복귀 → FR-10 / BR-9
- Given: 미리듣기 재생 중이다.
- When: 화면을 닫거나 앱 비활성화 후 복귀한다.
- Then: 기존 재생 중지·복귀 자동 시작 0이다.

### AC-23: 세션·저장 불변 → FR-9/FR-10 / BR-5
- Given: 기존 저장 실패 또는 정상 저장 상태다.
- When: 태그 생성·할 일·소리 저장·준비 확정 후 재실행한다.
- Then: W03 저장 호출 0·기존 바이트 동일·새 준비에 세션 태그·할 일·소리 초안 복원 없음이다.

### AC-24: 접근성 → FR-9/FR-10 / BR-10
- Given: 화면 낭독기 사용 중이다.
