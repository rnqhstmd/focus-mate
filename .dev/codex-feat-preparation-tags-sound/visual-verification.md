## 실제 네이티브 검증 판정 기준

- 최초 준비: 제목 하나, 어두운 둥근 패널, 태그색 알약과 아이콘, 두 행 가로 스크롤과 마지막 +, 입력 숨김, 버스 기본값, 확정 비활성.
- 선택/입력: 선택 하나만 진한 배경·색 테두리·흰 글자. 선택 뒤 빈 한 줄 입력, 입력 중 태그색 테두리. 유효 입력에서 확정 활성, 키보드와 하단 동작 겹침 확인.
- 소리: 일반 글자에서 3+2 선택지, 버스/비구름/지하철/나무/음소거 아이콘, 설명 없음, 미리듣기와 저장, 오류에도 저장 가능.
- 태그 편집: 기본값과 잘못된 이름, 유효 저장 시 추가/선택/할 일 유지, 취소 시 초안 불변.
- 왕복: 준비→시간→준비 초안 유지, 시간 변경 후 유효성 차단.
- 소리 생명주기: 선택만으로 재생 없음, 시작/중지·소리 변경·저장·취소·닫기·비활성화 종료, 복귀 자동 재생 없음.
- 최대 글자: 마지막 태그/+·입력·소리 저장·확정 실제 도달, 닫힌 편집 컨트롤 미노출.

실제 simulator screenshot을 최초/입력/태그 편집/소리 선택/오류/최대 글자 상태에서 keepAlways 첨부로 확보하고 직접 열람한다. UI assertion 통과만으로 시각 일치 판정하지 않는다.

최신 docs/FLOWS.md 계약을 PNG보다 우선한다: 입력 중 선택 태그색 테두리 및 입력 후에도 하단 소리 칩 유지. 휴식 아이콘은 승인 PNG의 연필(.writing)과 대조한다.

W03 패널 자체 구성 차이는 미충족이다. W09 지도 배경·노선·차량·지도 오류 재시도, W04 실제 승차권·카드 접촉, W05 집중 여행 오디오는 후속 범위로 분리한다. native 기본 뒤로가기와 PNG 닫기 X의 플랫폼 적용 차이를 명시한다. 브라우저 확인, 실기기 청취, 실제 VoiceOver 포커스는 별도 검증 상태를 유지한다.

## 승인 폰트

CoreText로 기존 승인 TTF의 PostScript 이름을 직접 확인: SeoulAlrim-Bold.ttf → SeoulAlrimTTF-Bold, SeoulAlrim-Medium.ttf → SeoulAlrimTTF-Medium. 앱 화면 구현에서 번들 등록·Dynamic Type 반영을 검토한다. 실제 앱 렌더링과 승인 참고 대조 완료.
