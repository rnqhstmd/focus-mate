## Background

앱 시작 때 손상·미지원 버전·읽기 실패를 감지해도 복구 선택지가 없었습니다. 원본을 유지한 채 재시도하거나, 명시적으로 확인한 뒤 원본을 내부에 보존하고 처음부터 시작할 수 있어야 합니다.

## Summary

W13 저장 오류 화면에 재시도와 확인·취소를 추가했습니다. 정리는 원본 바이트를 별도 파일에 쓰고 다시 읽어 일치를 확인한 뒤 활성 파일을 삭제하며, 완료 확인까지 성공해야 첫 카드 화면으로 이동합니다.

## Changes

재시도·확인 화면 진입·취소는 저장물을 쓰거나 삭제하지 않습니다. 확인 당시 원본이 바뀌거나 정상 상태로 회복되면 정리를 거부하고, 백업·읽기 검증·삭제 실패는 오류 화면에 설명합니다. 삭제 후 확인이 실패할 수 있으므로 정리 시도 이력을 유지해 이후 재확인·취소에서도 원본이 변경되지 않았다고 단정하지 않습니다.

저장 v2 계약과 v1 읽기를 유지하고, 최신 main의 W08 기록·메모 저장 기능을 통합했습니다. 외부 내보내기 없이 앱 내부 원본 보존만 제공합니다. DEBUG의 실제 파일 진단과 I/O 경계 실패 주입으로 재실행·큰 글자·백업 실패 흐름을 검증했습니다.
