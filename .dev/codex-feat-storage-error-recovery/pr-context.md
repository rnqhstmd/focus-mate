# W13 PR 배경

## 배경
앱 시작 때 저장 데이터를 읽지 못하면 기존 오류 화면에는 복구 경로가 없었다. 사용자는 원본을 유지한 채 다시 불러오거나, 명시적으로 확인하고 내부에 원본을 보존한 뒤 새 카드 화면으로 돌아갈 수 있어야 한다.

## 요구사항
재시도는 저장·삭제 없이 최신 파일을 실제로 읽는다. 정리는 확인 당시 원본을 비교하고 별도 백업을 같은 바이트로 기록·재확인한 뒤 활성 파일을 삭제한다. 백업·검증·정리 실패는 성공으로 표시하지 않는다. 정상화된 파일은 정리를 거부한다. 외부 내보내기는 이번 범위에 포함하지 않고 v2 저장 형식을 유지한다.

## 검증 한계
iOS26.5 시뮬레이터에서 실제 파일·앱 재실행·큰글자 조작을 검증한다. iOS27은 기준선 러너 연결 실패로 미검증이며 실기기와 VoiceOver 실제 포커스 이동은 P6에서 직접 확인해야 한다. 단일 프로세스 MainActor 쓰기 경계이며 파일 비교·삭제는 OS 트랜잭션이나 강제 종료 내구성을 보장하지 않는다.
