# W09b 완료 기록 분석·앱/위젯 공용 집계 PRD

## 배경과 범위
승인 계획의 records FR-6·FR-7. 기존 완료 저장/메모/연간 잔디/날짜별 기록을 유지하고 주·월/태그 분석과 인사이트를 추가한다. W18은 같은 순수 집계 결과를 소비한다. AppGroup/홈 위젯/링크는 W18, LiveActivity는 W17 범위다. 사용자 지시 W17→W09b→W18 모두 구현 후 전체검증, 중간에는 focused만.

## 요구사항과 정책
- 기록의 선택 날짜가 속한 월로 분석 진입. 주(월~일 정확히7일)/월(그레고리 실제일수), 이전/다음, 오늘복귀 제공. 미래기간 이동 차단. 기간종류/기간 이동은 태그 해제.
- 실제 하차 완료 RecordSection만 사용. 진행/포기/예시는 기존 완료저장 계약으로 제외. section.validate로 중복/손상은 접근불가를 반환하며 일부집계/가짜0/원본수정 금지.
- 일별소속은 저장된 date가 권위. 현재날짜는 주입한 now/시간대에서 산출. 미래기록 제외, 빈날0 및 미래표시. 과거날짜를 현재시간대로 재분류하지 않는다.
- 전체 합계분/횟수/집중일수/반올림평균, 날짜별 태그누적, 태그별분/횟수/비중, 이전기간 비교 제공. 현재기간은 오늘까지와 이전같은경과일수(말일제한), 과거기간은 이전전체기간. 이전0이면 증감률없음.
- 완료당시 태그이름으로 묶고 삭제/변경된 현재태그와 무관하게 보존. 최신완료기록 색 대표. 순위는 분↓/횟수↓/이름↑. 전체태그와 상위3+나머지 기타를 구분해 합계보존. 실제이름기타와 묶음기타를 식별자로 구분.
- 전체합계/태그구성/비교/최장연속일은 기간전체. 태그선택은 날짜별활동/최근여행/시간대/노선/길이/메모만 좁힌다. 화면에 범위명시. 기간에없는태그는 전체로 복귀.
- 공용주결과는7일, 월은모든날짜. 앱도 같은일별결과 사용. W18에 메모/할일원문 전달금지.
- 시간대: 완료시각을 주입 표시시간대로 분류(완료당시시간대라고설명하지않음). 새벽00~05/오전05~12/오후12~18/저녁18~24. 대상3회미만 추가기록안내.
- 노선=저장버스/출발/도착 조합, 횟수↓/시간↓/이름↑ 상위3. 길이1~30/31~60/61~120/121~240/241~360분. 기간 내 서로다른date 연속일최장값, 같은날중복은1일.
- 최근5회 최신순(같은시각은입력순서), 메모있는수와최신3개. 항목선택시 해당날짜기록/메모수정 연결. 저장뒤 갱신 및뒤로복귀.
- 긴한국어/큰글자/색외의접근성요약/ReduceMotion 정보보존. 자동/시각/실제VO 증거 구분.

## 수용 기준
### AC-1 기간·날짜
Given: 오늘2026-10-16, 선택10-14, 고정시각/시간대.
When: 월진입/주전환/기간이동/오늘복귀.
Then: 월31일, 주10-12~18 7일,17~18 미래표시, 이후주차단. 윤년2024-02 29일/2025-02 28일과연도경계 일관. 저장date 유지.
### AC-2 합계·비교·공용일치
Given: 월10+20분,수30분,그외없음. 이전같은경과기간40분.
When: 앱/위젯공용입력 집계.
Then:60분/3회/2일/평균20,일별[30,0,30,0,0,0,0]. 이전대비+20. 이전없음은비교불가. 월일별합도전체일치.
### AC-3 태그·필터
Given:A40/B30/C20/D10분, A는현재태그목록에서삭제.
When: 전체/A/없는태그/상위결과/기간이동.
Then:A보존,전체100,상위ABC/기타10. 상위+기타분·횟수합전체일치. A의하위활동만좁히고상단100범위명시. 없는태그/기간이동은전체.
### AC-4 인사이트
Given:04:59/05:00/12:00/18:00 완료시각,알려진노선,길이30/31/60/61/120/121/240/241/360,연속3일.
When: 전체/태그인사이트집계.
Then:새벽/오전/오후/저녁 경계일치,3회미만추가기록안내,노선상위3정확,길이구간합대상횟수,같은날중복은연속일추가없고최장3.
### AC-5 회고·연결
Given:6회중메모4회.
When:최근/메모확인과항목선택/메모저장.
Then:최근5/메모수4/최신메모3,해당날짜기록·기존메모편집연결,저장뒤갱신/기록복귀. 공용위젯소비형식에메모/할일없음.
### AC-6 빈상태·잘못된입력
Given:첫기록전/빈기간/진행·포기·예시/동일여정재완료/중복·손상.
When:완료저장또는집계.
Then:빈상태0안내,진행·포기·예시제외,재완료1회,손상·중복접근불가/일부집계없음/원본변경없음.
### AC-7 접근성·기존흐름
Given:긴태그·큰글자·ReduceMotion/정상·빈사례.
When:기간/태그해제/기록복귀/메모진입과증거기록.
Then:핵심수치/경로접근가능,그래프날짜·이름·분·횟수요약,잔디/기록/메모유지. 자동/시각/실제VO결과또는미확보사유 구분.

## 근거와 결정
product-owner 사전조사에서 기존 웹/앱계약을 검토한 초안에 기반. 추가 사업범위 없음. 상위3·동률·대표색은 구현의 결정성 확보를 위한 기본값이며 사용자 규모/담당자 등 미확인값은 추정하지 않는다. 사용자 기존 순차전체실행 범위 내 진행, 새로 사용자답변을 받았다고 기록하지 않는다.
