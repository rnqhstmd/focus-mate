# W09b 시각·동작 검증

## 직접 확보한 증거
`t3-ui-actual.log`: 신규 기능 UI4 + 캡처1, 실제5건/0fail. 이전 `t3-green-run.log`는 실행0건으로 무효이며 이 로그가 대체한다. 기본 크기 캡처 `w09b-analysis-normal.png`, 최근/메모 캡처 `w09b-analysis-recent.png`를 부모가 직접 열었다. 실제 네이티브 Simulator 화면이며 HTML 모형이 아니다.

## 시안 대조
`designs/revised/analytics.png`를 직접 열어 대조했다. 검정 배경, 큰 합계, 완료횟수/활동일/평균, 기간 조작, 태그 도넛·구성, 하위 활동/최근/메모 순서를 반영했다. 값은 시안의 예시가 아닌 실행일 테스트 기록(150분/6회/1일/평균25분)이다. 앱의 기존 NavigationStack 전체화면으로 연결하므로 시안의 지도 위 모달 프레임·잔디/분석 탭과는 다르다. 분석 진입/복귀와 편집 연결은 기존 기록 화면을 재사용한다. 이 프레임 차이는 시안과 픽셀 일치로 주장하지 않는다.

## 후속 수정/검증
상위3+묶음 기타 표시와 전체 태그 선택 분리, UTF16 행 식별자 회귀는 리뷰에서 추가됐으며 별도 회귀 로그가 최종 근거다. 이 문서 캡처는 그 수정 전 증거여서 최종 캡처를 추가한다.

## 접근성 범위
신규 UI4에는 accessibility3XL 빈 상태 기간 조작·복귀가 포함돼 실제 통과했다. 색 외 분/횟수·요약 label은 코드와 XCUI에서 확인했다. 실제 VoiceOver 음성 청취, 실기기, 시스템 Reduce Motion 설정 전환은 수행하지 않았다. 자동 UI/정적 확인과 실제 낭독 검증을 구분한다. 전체 회귀는 사용자 지시로 W18 구현 뒤 수행한다.

## 수정 후 확인
`t1-green-w09b-regression.log`(W18 reports)에서 Row2/0fail 및 분석UI5+캡처1=6/0fail. `w09b-analysis-final.png`를 부모가 직접 열어 상위 구성 정적범례와 별도 태그 필터 표시를 확인했다. 4태그 시드에서 기타10분이 비선택 Text, D 태그 필터는 선택가능하며 전체100분4회 유지하는 UI 회귀도 통과했다.
