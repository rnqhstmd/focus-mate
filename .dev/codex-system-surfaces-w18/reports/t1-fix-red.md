# W18 T1 리뷰 회귀 RED 인계

## 범위와 독립성 한계
이 에이전트는 직전 T1 리뷰에서 생산 코드 4개를 이미 읽었다. 따라서 생산 코드에 노출되지 않은 독립 RED 작성자라고 주장하지 않는다. 이번 역할 전환 뒤에는 테스트 파일과 테스트 fixture만 읽었으며 생산 코드를 추가로 읽지 않았다.

## 추가한 회귀
- WidgetPresentationTests에 stale 접근성 기준일/업데이트 필요/해당 주/60분 3회 보존 및 오늘·이번 주 표현 금지 1개.
- WidgetSnapshotTests에 named 4개, 기타 단독, 기타 중간 위치, 기타 중복, 기타 횟수 0 거부 5개. 합계는 모든 사례에서 100분/4회로 유지하여 단순 합계 불일치로 거부되지 않게 했다.
- 정상 named 1~3개와 named 3개+마지막 기타 왕복 허용 2개.
- 잘못된 구조는 JSONEncoder 직접 입력으로 decode 거부와 공개 encode의 invalidSnapshot을 각각 검사한다.

총 8개 테스트를 추가했다. 기존 테스트 본문은 변경하지 않았다. 새 fixture helper는 테스트 파일 내부에만 있다.

## 실행 상태
빌드·테스트를 실행하지 않았다. RED 관측은 아직 없다. 부모가 실제 assertion failure를 확인한 뒤 GREEN을 진행해야 한다. 중복 기타/횟수 0 거부와 정상 왕복은 기존 방어 동작을 유지하는 회귀이므로 처음부터 통과할 수 있다.
