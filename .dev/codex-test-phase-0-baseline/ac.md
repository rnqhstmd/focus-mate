# 제품 Phase 0 — 수용 기준

상태: 2026-10-12 사용자 승인. gx-tdd core / standard.

## 배경

현재 웹·Pen·문서의 기준선을 고정한다. 기능 추가나 향후 iOS 개발 계획은 범위 밖이다.
자동 검사와 실제 브라우저·실기기 확인을 구분한다. 최신 승차 브라우저 검증은 아직 미완료다.

## 요구사항 (AC)

AC-1: 실행 자료 불일치 감지
  Given: 최신 HTML과 실행용 HTML·필수 자산이 준비되어 있다.
  When: 기준선 검사를 실행한다.
  Then: 동일한 자료는 통과하고 복제본 불일치·필수 파일 누락은 파일명을 표시하며 실패한다.

AC-2: 화면 연결 누락 감지
  Given: 제품 18개 장면·회귀 21개 장면·Pen 42개 상태 연결표가 있다.
  When: 연결표를 검사한다.
  Then: 존재하지 않는 장면·Pen 노드, 중복 또는 누락된 화면 연결을 오류로 보고한다.

AC-3: 검증 상태 구분
  Given: 자동 검사 결과와 브라우저 확인 상태가 별도로 기록되어 있다.
  When: 기준선 보고서를 만든다.
  Then: 자동 검사가 통과해도 브라우저 확인이 미완료면 Phase 0를 완료로 표시하지 않는다.

## 검증 범위

기존 승차 인식·중복 접촉·화면 이탈·저장/복원 VM 회귀를 다시 실행한다.
최신 브라우저 렌더·터치·청취 증거를 VM/Pen 검사로 대신하지 않는다.
문서·기준선 검사·검증 근거를 PR로 남긴다. G-W-T 게이트: AC 3건 모두 Given/When/Then과 관찰 가능한 결과를 포함하며 통과.

## 절차 근거

설치된 gx-tdd/phases/phase-requirements.md core 분기의 전문 표시 + 승인 확인.
이 초안의 승인 이후 ac.md를 확정하며 RED → GREEN → REFACTOR, core 보안 감사, fresh verify, 인수 검증, commit/PR 순으로 진행한다.

## 감사 보강 (2026-10-12 모두 진행 승인)

AC-4: 필수 수동 검토 항목 누락 차단
  Given: 원본 HTML에 browser와 productScreenCoverage가 필수 검토 항목으로 선언되어 있다.
  When: 연결표에서 항목을 삭제하거나 원본의 필수 검토 선언을 제거한다.
  Then: 삭제 항목 또는 선언명을 포함한 JSON 오류와 exit 1을 반환하며 phase0Complete는 false다.

AC-5: 잘못된 CLI 인자 차단
  Given: 허용 인자는 무인자 또는 --root <존재하는 폴더>다.
  When: 미지원 옵션, 값 누락, 추가 인자 또는 존재하지 않는 폴더를 전달한다.
  Then: JSON 오류와 exit 1을 반환하고 기본 프로젝트를 대신 검사하지 않는다.
