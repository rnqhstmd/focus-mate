## 배경
- W05까지는 메인 '여행 시작하기'가 진행 중인 여정을 확인 없이 기록 없이 지웠다 — 사용자가 여정을 잃을 수 있는 유일한 지점이었다.
- 출발 후 타이머 화면에는 나가는 길이 없었고, 앱을 다시 켜면 여정이 일시정지로 남지만 이어갈 방법이 없었다.
- 현재 정류장은 여정을 끝내도 바뀌지 않았다.

## 요구사항 (journey FR-13 / AC-15, NFR-2 Simulator)
- 메인 이어가기 카드("잠시 멈춘 여정이 있어요." / 도착이면 "도착한 여정이 있어요"), '이전 여정 이어가기 →'는 바로 흐름(사용자 결정).
- 진행 여정이 있으면 시작 버튼이 '새 여정 시작'이 되고 확인 창을 거쳐 도달 정류장을 현재 정류장으로 저장한다.
- 타이머 일시정지 중에만 '포기하기' → "여행을 그만둘까요?" → 도달 정류장 저장·메인 안내. 완료 기록은 어떤 경로에서도 만들지 않는다.
- 도달 정류장 = 저장된 경과 ÷ 버스 정류장 간격 몫(총 정류장 수 상한, 방향 유지, 9개 순환).
- 저장 실패는 이동하지 않고 "저장하지 못했어요. 다시 눌러주세요."로 안내, 연타는 한 번만 처리.
- 메인으로 여정을 남긴 채 나가는 버튼은 만들지 않는다(사용자 결정). 확인 창은 iOS 기본 alert(첫 VoiceOver 포커스는 W14).
- 수용 기준 35건(G-W-T), testability 8/10, 통합 리뷰 SPEC PASS 35/35, 인수 검증 ACCEPT.
