# PRD: W07 포기·이어가기·생명주기 (journey FR-13 / AC-15, NFR-2 Simulator 부분 / AC-8) — 확정본

규모: 대형. 메인, 타이머 화면, 현재 정류장 저장, 재실행 복원에 걸치고, 여정을 잃을 수 있는 확인 단계가 새로 생긴다.

## 배경
- 현재 제품 상태 (iOS):
  - 승차 후 '시작'을 누르면 실제 분 타이머가 돈다. 일시정지와 재개를 할 수 있고, 백그라운드에서도 시간은 흐른다. (W05 완료)
  - 앱을 종료했다 다시 켜면 메인으로 간다. 진행 여정은 마지막 저장 진도에서 일시정지 상태로 남는다. 메인에는 "진행 중인 여정이 있어요 / 여행 시작하기를 누르면 이 여정은 기록 없이 정리돼요."라는 임시 안내만 있고 이어갈 방법이 없다.
  - 메인의 '여행 시작하기'는 진행 여정이 있어도 **확인 없이** 기록 없이 지운다. 사용자가 여정을 잃을 수 있는 유일한 지점이다.
  - 출발 후 타이머 화면에는 나가는 길이 없다. 뒤로가기 버튼이 없고 스와이프도 막혀 있으며 포기도 없다. (W05 사용자 결정)
  - 도착하면 "도착했어요"만 보이고 나갈 수단이 없다. 하차와 완료 기록은 W09다.
  - 현재 정류장은 여정을 끝내도 바뀌지 않는다.
- 웹 프로토타입 기준(designs/final/animation-preview.html): 포기는 일시정지 중에만 가능하고, 확인 후 "지금 도달한 정류장"이 새 현재 정류장이 되며 완료 기록은 없다. 메인에는 "잠시 멈춘 여정이 있어요." 이어가기 카드가 있고, 이어가기를 누르면 바로 재생된다. 새 여정은 확인이 필요하다.
- 이미 정해진 것: 백그라운드·제어 센터에서도 시간이 흐르고 저장된다. 앱 종료는 "여행 중 끊고 간 것"이며 재실행 시 메인에서 새 여정/이전 여정 이어가기를 고른다. 0분 여정은 시작 불가. 도착은 임시 "도착했어요"만 있고 완료 기록·하차는 W09. 다이나믹 아일랜드는 W15.
- 이번 사용자 결정 (2026-10-15 확정):
  1. 메인으로 여정을 남긴 채 나가는 버튼은 **만들지 않는다**. 타이머 화면에서 메인으로 가는 길은 포기뿐이다.
  2. "이전 여정 이어가기"를 누르면 타이머가 **바로 흐르는 상태(진행 중)**로 열린다(웹과 동일).
  3. 도착한 여정은 이어가기 없이 "새 여정 시작"만 두고, 확정하면 도착지가 현재 정류장이 된다.

## 목표
- 여정은 사용자가 확인했을 때만 사라진다. 앱 종료, 백그라운드, 잠금, 실수로 누른 버튼에는 사라지지 않는다.
- 여행을 중간에 그만둬도 지금까지 간 위치에서 다음 여행을 시작할 수 있다. 완료 기록은 남지 않는다.
- 앱을 껐다 켠 사용자가 메인에서 이전 여정을 이어갈지, 새로 갈지 직접 고른다.
- 성공 지표: 실수 한 번의 탭으로 진행 여정이 사라지는 경로 0개 / 저장 실패를 성공으로 안내하는 경로 0개 / 포기·새 여정·이어가기 후 재실행해도 정류장과 여정이 한 벌만 남는다(중복 0, 완료 기록 증가 0).

## 요구사항

### 기능 요구사항
- [Must] FR-1 이어가기 카드: 메인에서 진행 여정이 출발 후 상태(일시정지 포함)이면 이어가기 카드를 보여준다. 구성은 제목 "잠시 멈춘 여정이 있어요.", 할 일, 버스(종류+번호), 남은 시간 "N min 남음", "{태그} · {도착지}까지", 버튼 "이전 여정 이어가기 →"다. 남은 시간은 타이머 화면과 같은 올림 규칙이다(웹의 "최소 1"과 다름). 이 카드가 임시 안내(`main.activeJourney`)를 대체한다.
- [Must] FR-2 이어가기 진입(바로 흐름): "이전 여정 이어가기"를 누르면 그 순간 (저장된 경과, paused=false)를 **즉시 1회 저장**하고 타이머 화면을 **진행 중**으로 연다. 남은 시간은 저장된 진도에서 이어서 줄어든다. 흐르는 시간은 화면이 열린 시점부터 센다(메인에 머문 시간·종료 중 시간은 더하지 않는다).
  - 저장에 실패하면 화면을 이동하지 않고 메인에 머문다. 메인에 "저장하지 못했어요. 다시 눌러주세요."를 보이고 저장값은 그대로다(BR-7).
  - 낭독 안내: 타이머 화면이 열릴 때 VoiceOver 사용자에게 "이전 여정을 남은 시간부터 이어갑니다."를 1회 알린다. 화면에 보이는 문구로는 추가하지 않는다.
- [Must] FR-3 메인 시작 버튼 변경: 진행 여정이 있으면 시작 버튼 문구를 "새 여정 시작"으로 바꾸고, 누르면 확인 대화상자를 연다. 제목 "새 여정을 시작할까요?", 본문 "이전 여정은 그만두고 새 여행을 준비해요. 완료 기록은 남기지 않아요.", 버튼 "이전 여정 유지하기"(취소·기본 선택)/"새 여정 시작".
- [Must] FR-4 새 여정 확정: 한 번의 저장으로 현재 정류장을 그 여정의 도달 정류장(방향 유지)으로 바꾸고 진행 여정을 삭제한 뒤 시간 선택 화면으로 간다. 완료 기록은 만들지 않는다. "이전 여정 유지하기"는 대화상자만 닫는다.
- [Must] FR-5 포기 버튼: 타이머 화면이 일시정지일 때만 "포기하기" 버튼을 보인다(진행 중·도착·출발 대기에는 없음). 이어가기로 연 직후는 진행 중이므로 먼저 일시정지해야 포기할 수 있다. 누르면 대화상자: 제목 "여행을 그만둘까요?", 본문 "지금 도달한 정류장에서 다음 여행을 시작할 수 있어요. 완료 기록은 남기지 않습니다.", 버튼 "계속 여행"(취소·기본 선택)/"그만두기". "계속 여행"이면 일시정지가 유지되고 포커스가 포기하기 버튼으로 돌아온다.
- [Must] FR-6 포기 확정: 한 번의 저장으로 도달 정류장(BR-1)을 현재 정류장으로 저장(방향 유지)하고 진행 여정을 삭제한다. 완료 기록은 만들지 않는다. 메인으로 이동하고 "{정류장}에서 여행을 마쳤어요. 완료 기록은 남기지 않았어요."를 보인다.
- [Must] FR-7 저장 실패(BR-7): 포기·새 여정 확정의 저장이 실패하면 이동하지 않고 현재 정류장과 여정을 바꾸지 않으며 "저장하지 못했어요. 다시 눌러주세요."를 보인다. 정리됐다고 안내하지 않는다.
- [Must] FR-8 출발 대기 여정: 메인에 FR-1 카드로 보이고 남은 시간은 전체 시간이다. 이어가기는 출발 안내 화면을 처음부터 다시 보여준다(저장 없음). 포기 버튼은 없다. 새 여정 시작은 FR-3·FR-4와 같고 진도 0이라 현재 정류장은 사실상 변하지 않는다.
- [Must] FR-9 도착 상태 여정(W09 전 임시): 메인에 "도착한 여정이 있어요" 카드로 보이고 이어가기 버튼은 없다. 시작 버튼은 "새 여정 시작"이며 확인 대화상자는 FR-3과 같다. 확정하면 현재 정류장은 **도착지**가 되고 진행 여정은 삭제되며 완료 기록은 없다. W09가 하차로 대체한다.
- [Must] FR-10 타이머 화면의 나가는 길: 출발 후 타이머 화면에서 메인으로 가는 길은 포기뿐이다(W05 결정 유지). 뒤로가기 버튼 없음, 스와이프 차단. "여정을 남긴 채 메인으로 나가기" 수단은 만들지 않는다.
- [Must] FR-11 생명주기 안전: 잠금·백그라운드·제어 센터·앱 종료·재실행 어느 경우에도 저장된 진도가 사라지거나 되돌아가지 않고, 진행 여정이 둘로 늘지 않으며, 앱 밖(종료 중) 시간이 더해지지 않는다. 확인 대화상자가 떠 있는 동안 백그라운드·종료가 되어도 확정 전에는 아무것도 바뀌지 않는다.
- [Should] FR-12 낭독·포커스: 포기하기 버튼, 두 대화상자, 이어가기 카드를 VoiceOver로 쓸 수 있다. 대화상자가 열리면 안전한 선택에 포커스가 가고, 닫으면 연 버튼으로 돌아온다. 포기하기 라벨은 "포기하기". 메인 이동 직후 포기 안내를 낭독한다. 이어가기 진입 시 FR-2의 낭독 안내를 1회 한다.
- [Could] FR-13: 이어가기 카드에 남은 정류장 수 등 추가 정보. 이번에는 하지 않는다.

### 비즈니스 규칙
- [Must] BR-1 도달 정류장: 도달 칸 수 = 저장된 경과 초 ÷ (버스 정류장 간격 분 × 60)의 몫이며 총 정류장 수(총 분 ÷ 간격)를 넘지 않는다. 도달 정류장은 출발 정류장에서 방향대로 그만큼 간 순환 정류장이다(9개, 끝에서 처음으로 이어짐). 간격은 2014번 5분, 강남02 6분, 343번 8분. 예: 2014번 25분(5칸), 성수역 정방향 출발: 경과 0·299초 성수역, 300초 성수동, 600초 뚝섬역, 1499초 서울숲역(4칸), 1500초(도착) 서울숲 입구(5칸=도착지).
- [Must] BR-2 방향 유지: 포기·새 여정 후 현재 정류장의 방향은 그 여정의 방향 그대로다.
- [Must] BR-3 기록 없음: 포기·새 여정 시작·이어가기 어떤 경로도 완료 기록을 만들지 않는다.
- [Must] BR-4 한 번의 저장: 현재 정류장 변경과 여정 삭제는 둘 다 반영되거나 둘 다 반영되지 않는다.
- [Must] BR-5 확정 전 불변: 대화상자를 열기만 하거나, 취소하거나, 앱이 백그라운드·종료되어도 저장값은 열기 전과 같다.
- [Must] BR-6 포기 가능 시점: 일시정지 중인 출발 후 여정만 포기할 수 있다. 일시정지 중에는 시간이 흐르지 않아 대화상자 중 도달 정류장이 바뀌지 않는다.
- [Must] BR-7 저장 실패는 성공으로 안내하지 않는다(이어가기·포기·새 여정 공통). 이동하지 않고 화면 상태를 그대로 두며 같은 동작을 다시 눌러 재시도할 수 있다.
- [Must] BR-8 연타: 포기 버튼·"그만두기"·"새 여정 시작"·"이전 여정 이어가기"를 연타해도 처리·저장·이동은 한 번만 일어난다.
- [Must] BR-9 손상된 여정: W05 규칙대로 조용히 버려진다. 메인에 이어가기 카드가 없고 일반 시작 상태다. 웹의 "이전 여정을 불러오지 못했어요." 안내는 쓰지 않는다.
- [Should] BR-10 포기 후 안내 문구는 저장하지 않는다. 다른 화면으로 가거나 재실행하면 사라진다.
- [Must] BR-11 이어가기 시 일시정지 해제: 이어가기는 사용자가 마지막에 일시정지했던 여정이라도 진행 중으로 연다. 앱 종료로 복원된 일시정지는 이어가기 시점에 풀린다.

### 품질 기대
- [Should] QE-1: 파괴적 동작은 항상 확인 한 단계를 거치고 기본 선택은 안전한 쪽이다.
- [Should] QE-2: 큰 글씨에서도 포기하기 버튼과 두 대화상자의 버튼이 가려지지 않고 눌린다(44pt 이상).
- [Should] QE-3: 동작 줄이기에서도 기능과 결과가 같다.

## 사용자 시나리오
- 포기: 25분(2014번, 성수역 정방향) 경과 600초에 일시정지 → 포기하기 → "그만두기" → 메인에 "뚝섬역에서 여행을 마쳤어요. 완료 기록은 남기지 않았어요." 현재 정류장 뚝섬역, 이어가기 카드 없음.
- 이어가기: 앱 종료 후 재실행 → 메인 카드 → "이전 여정 이어가기" → 타이머가 바로 흐름.
- 새 여정: 재실행 후 메인에서 "새 여정 시작" → 확인 → 현재 정류장이 도달 정류장으로 바뀌고 시간 선택으로.
- 엣지: 진도 0초 포기, 1499초 포기, 저장 실패(이어가기/포기/새 여정), 대화상자 중 백그라운드·종료, 이어가기 직후 종료, 연타, 출발 대기·도착·손상 여정.

## 영향 범위
- 메인: 임시 안내와 시작 버튼 동작이 바뀐다(진행 여정이 있을 때만).
- 타이머 화면: 일시정지 상태에 포기하기 버튼 추가. W06 지도 도구와 배치 충돌 가능 → 위치는 디자인 스펙으로 분리.
- 현재 정류장이 처음으로 바뀐다(메인 표시, 시간 선택 출발지, 다음 승차권 출발지에 영향).
- W05 결정 "출발 후 메인 못 감"은 유지된다.
- 저장 형식 변경 없음.
- W09 인계: 도착 여정 메인 처리는 임시.

## 수용 기준
(시간 경과는 주입 시계.)

AC-1: 메인 이어가기 카드
  Given: 2014번 25분, 경과 90초로 일시정지된 진행 여정이 저장되어 있고 앱을 종료했다 다시 켰다
  When: 메인을 연다
  Then: `main.activeJourney` 카드가 보이고 제목 "잠시 멈춘 여정이 있어요.", 저장된 할 일, 버스 종류와 번호, "24 min 남음", "{태그 이름} · {도착지 이름}까지", 버튼 "이전 여정 이어가기 →"를 포함한다. 시작 버튼 문구는 "새 여정 시작"이다. 기존 임시 문구 "여행 시작하기를 누르면 이 여정은 기록 없이 정리돼요."는 없다. → [FR-1, FR-3]

AC-2: 남은 시간 올림 표기
  Given: 25분 여정, 일시정지

  Then: 메인에 머물고 path는 `[]`다. `screen.journey`는 보이지 않는다. 저장값은 경과 90, paused=true 그대로다. `main.saveFailure`가 "저장하지 못했어요. 다시 눌러주세요."를 보이고 "이전 여정을 남은 시간부터 이어갑니다." 알림은 없다. 저장을 성공으로 바꾸고 다시 누르면 AC-3·AC-4의 결과가 된다. → [FR-2, BR-7]

## 제외 범위
- 하차 태그, 도착 안내, 완료 기록, 요약: W09. 도착 여정의 메인 처리(FR-9)는 W09 전 임시.
- 지도 화면과 지도 도구 배치: W06. 포기하기 버튼 위치는 W06과 겹치지 않게 조정.
- 다이나믹 아일랜드·잠금 화면 표시: W15.
- 실기기 VoiceOver·잠금·재실행 검증: W14 (이번에는 Simulator UI 테스트까지).
- 손상 여정의 안내 문구·백업: W05 결정(없음) 유지.
- 카드 교체 시 "진행 여정의 카드 = 현재 카드" 규칙 처리.
- 진행 중(재생 중) 곧바로 포기하는 경로: 일시정지 후에만.
- 여정을 남긴 채 메인으로 나가는 버튼("현재 정류장으로"): 만들지 않음(사용자 결정).

## 가정
- 포기·새 여정 시 현재 정류장은 방향 유지한 채 도달 정류장으로 바뀐다(웹과 동일).
- 이어가기 낭독 문구는 웹 원문을 그대로 쓰고 시각적 문구로는 넣지 않는다.
- 이어가기 저장 실패 안내는 메인에 둔다.
