## PRD: 첫 출발지 선택과 시간·버스·도착지 선택 (iOS)

규모: 대형. 신규 화면 2개와 저장 동작 1개가 생긴다.

### 배경
- 웹 프로토타입은 첫 출발지 검색(`search`)과 시간·여정 선택(`time`)을 이미 갖췄다. iOS 앱에는 이 두 화면이 없다. 같은 기능을 iOS 네이티브 앱에 만든다.
- 현재 iOS 앱은 다음과 같이 동작한다.
  - 카드는 있는데 정류장이 없으면 제목과 안내 한 줄만 있는 "최초 정류장 설정" 자리표시 화면이 나온다 (RootView에서 확인).
  - 정류장이 있으면 메인에 현재 정류장 이름·방향과 "여행 준비"·기록·설정·마이페이지 버튼이 나온다.
  - "여행 준비" 버튼은 제목만 있는 빈 화면으로 간다.
  - 정류장 이름·방향 저장 구조는 있다. 하지만 앱이 실제로 저장을 호출하는 곳은 아직 없다. 이 작업이 그 첫 사례 중 하나다.
- 카드 발급 화면은 별도 작업(W01)이 병렬로 만든다. 준비 화면 자체는 W03, 승차 접촉과 진행 여정 저장은 W04, 지도·경로 미리보기는 W06 범위다. 이 PRD에서는 모두 제외한다.
- 요구사항 원장(status.md)에서 FR-7(첫 출발 정류장)과 FR-8(시간·버스·도착지 선택)이 ⬜ 미반영이다. 새 FR은 만들지 않는다.

### 목표
- 처음 쓰는 사용자가 출발 정류장을 한 번 고르고, 곧바로 "몇 분 동안, 어떤 버스로, 어디까지 갈지"를 정해 준비 단계로 넘어간다.
- 성공 지표 (측정 방법과 목표치는 미정)
  - 선택이 끝나지 않은 채 준비로 넘어가는 경우가 0건이다.
  - 첫 출발지를 고른 사용자가 같은 세션에서 시간 선택까지 도달하는 비율을 본다.

### 요구사항

#### 기능 요구사항

**첫 출발지**
- [Must] FR-1: 첫 출발지 검색 화면 — FR-7 (status.md 미반영)
  - 카드는 있고 저장된 정류장이 없을 때, 앱을 열면 이 화면이 나온다.
  - 검색창과 결과 목록, "확인" 버튼이 있다.
  - 결과 항목에는 정류장 이름과 방면이 함께 보인다.
- [Must] FR-2: 검색 — FR-7 (status.md 미반영)
  - 검색어는 정류장 이름, 별칭, 방면 문구에서 부분 일치로 찾는다.
  - 대소문자는 구분하지 않는다.
  - 앞뒤 공백은 무시한다.
  - 검색어가 비어 있으면 전체 목록을 보여준다.
  - 목록은 웹과 같은 3건이다: 성수역 정방향, 성수역 역방향, 서울숲역 정방향.
- [Must] FR-3: 선택과 확인 — FR-7 (status.md 미반영)
  - 결과 중 1건을 고르면 "{정류장} · {방면}에서 출발" 확인 문구가 나온다.
  - 결과가 없으면 선택할 대상이 없고, 확인 버튼은 비활성이다.
  - 결과를 고르지 않았을 때도 확인 버튼은 비활성이다.
- [Must] FR-4: 첫 출발지 저장 — FR-7 (status.md 미반영)
  - 확인하면 고른 정류장(이름·방향)이 최초 정류장과 현재 정류장으로 같은 값으로 저장된다.
  - 저장에 성공하면 곧바로 시간 선택 화면으로 이동한다.
  - 저장에 실패하면 검색 화면에 머문다. 저장 실패 안내를 보여주고, 시간 선택으로 넘어가지 않는다.
- [Must] FR-5: 이후 재검색 차단 — FR-7 (status.md 미반영)
  - 정류장이 한 번 저장된 뒤에는 앱 안 어디에도 출발지 검색·변경·초기화 진입점이 없다.
  - 앱을 다시 열면 메인이 나온다.

**시간·버스·도착지**
- [Must] FR-6: 시간 선택 화면 — FR-8 (status.md 미반영)
  - 출발지는 저장된 현재 정류장과 방향이다.
  - 진입 경로는 두 가지다.
    - 첫 출발지를 저장한 직후.
    - 메인의 "여행 준비" 버튼.
  - 시간은 15~360분을 1분 단위 정수로 고른다.
  - 처음 진입할 때 초기값은 25분이다 (웹 기준).
  - 15분 미만과 360분 초과는 고를 수 없다.
- [Must] FR-7: 도착 후보 — FR-8 (status.md 미반영)
  - 후보는 고른 분이 버스의 "정류장당 분"으로 나누어떨어지는 버스만이다.
    - 2014번: 지선, 5분 간격.
    - 강남02번: 마을버스, 6분 간격. 내부 코드 302.
    - 343번: 간선, 8분 간격. 내부 코드 421.
  - 각 후보에는 버스 유형·표시 번호, 도착지, 분, 정류장 수, 거리(km)를 보여준다.
  - 정류장 수는 분 ÷ 간격이다.
  - 거리는 정류장 수 × 0.55km다.
  - 도착지는 9개 순환 정류장(성수역, 성수동, 뚝섬역, 성동구민체육센터, 서울숲역, 서울숲 입구, 성수대교 북단, 뚝섬한강공원, 성수사거리) 위에서 정한다.
    - 출발 위치에서 방향대로 정류장 수만큼 간 곳이 도착지다.
    - 9칸을 넘으면 처음으로 돌아온다. 역방향은 거꾸로 센다.
- [Must] FR-8: 후보 선택과 해제 — FR-8 (status.md 미반영)
  - 후보는 하나만 고를 수 있다.
  - 시간을 바꾸면 고른 후보는 즉시 해제된다. 같은 후보가 새 시간에도 존재해도 해제된다.
  - 처음 진입할 때는 아무것도 선택되어 있지 않다.
- [Must] FR-9: 진행 차단과 진행 — FR-8 (status.md 미반영)
  - 진행 버튼의 문구와 상태는 세 가지다.

    | 상태 | 문구 | 눌림 여부 |
    |---|---|---|
    | 후보가 없다 | "이 시간의 도착 후보가 없어요" | 불가 |
    | 후보는 있으나 미선택 | "버스와 도착지를 선택하세요" | 불가 |
    | 후보를 선택했다 | "이 여정 준비하기" | 가능 |

  - 선택 상태에서 누르면 준비 화면 진입점(현재 "여행 준비" 화면)으로 간다. 그때 선택값(시간·버스·도착지)을 함께 넘긴다.
- [Must] FR-10: 준비 진입점 연결 — FR-8 (status.md 미반영)
  - 메인의 "여행 준비" 버튼은 시간 선택 화면을 연다.
  - 준비 화면 진입점에서 뒤로 돌아오면, 같은 실행 중에는 방금 고른 시간·후보가 그대로 남아 있다.
- [Must] FR-11: 접근성 — FR-7·FR-8 (status.md 미반영)
  - 두 화면의 모든 조작 요소에 VoiceOver 레이블이 있다.
  - 후보 레이블은 "{유형} {번호}번, {도착지}, {분}분, {정류장 수}정류장" 형식이다.
  - 시간은 VoiceOver에서 1분씩 올리고 내릴 수 있다.
  - 글자 크기를 가장 크게 키워도 확인·진행 버튼에 도달해 누를 수 있다.
  - 시스템 "동작 줄이기"가 켜져 있으면 자동 움직임과 화면 전환 애니메이션을 쓰지 않는다. 기능은 동일하다.
- [Must] FR-12: 선택값 유지 범위 — FR-8 (status.md 미반영)
  - 시간·버스·도착지 선택값은 앱 실행 중 메모리에만 유지한다.
  - 저장 파일에는 남기지 않는다. 저장 형식은 바꾸지 않는다.
  - 앱을 종료했다 다시 열면 시간 선택은 처음 상태(25분, 선택 없음)로 시작한다.

#### 비즈니스 규칙
- [Must] BR-1: 출발지 검색은 최초 설정에서 한 번만 한다. 저장된 정류장이 있으면 검색 화면을 다시 볼 수 없다.
- [Must] BR-2: 시간·버스·도착지를 모두 확정해야 준비로 진행한다. 둘 중 하나라도 비면 막는다.
- [Must] BR-3: 후보는 나누어떨어지는 버스만이다. 나머지가 생기는 버스는 후보에 올리지 않는다.
- [Must] BR-4: 이 작업에서는 진행 중인 여정을 만들지 않는다. 승차 접촉(W04) 전에는 저장 파일의 진행 여정이 비어 있다.
- [Must] BR-5: 저장은 첫 출발지 확정 시 1회만 한다. 정류장 외 항목(카드 발급 상태, 카드, 진행 여정, 기록)은 그대로 유지한다.
- [Should] BR-6: 첫 출발지 저장은 카드 발급 저장(W01)과 같은 저장 경로를 쓴다. 두 작업이 서로의 저장 값을 덮어쓰지 않아야 한다.

#### 품질 기대
- [Should] QE-1: 사용자가 다음 행동(무엇을 눌러야 하는지)을 문구만 보고 알 수 있다. 차단 상태마다 이유가 문구로 보인다.
- [Should] QE-2: 문구는 쉬운 말로 쓴다.

### 사용자 시나리오

**정상 흐름 (처음 쓰는 사용자)**
1. 카드를 발급한 뒤 검색 화면이 나온다.
2. "성수"를 입력하면 3건이 나온다.
3. "성수역 · 성수동 방면"을 고르면 "성수역 · 성수동 방면에서 출발"이 나온다.
4. 확인하면 저장된다. 이어서 시간 선택 화면이 나오고 25분이 선택되어 있다.
5. 60분으로 바꾸면 후보 2건이 나온다.
   - 2014번 → 성동구민체육센터, 12정류장, 6.6km.
   - 강남02번 → 성수동, 10정류장, 5.5km.
6. 2014번을 고르고 "이 여정 준비하기"를 누른다. 준비 화면 진입점으로 간다.

**정상 흐름 (재방문)**
- 메인에서 "여행 준비"를 누르면 저장된 현재 정류장에서 시작하는 시간 선택 화면이 나온다.

**예외 흐름**
- 검색 결과가 0건이다: 선택할 항목이 없고 확인 버튼이 비활성이다.
- 저장에 실패한다: 검색 화면에 머물고 실패 안내가 보인다. 다시 확인을 누를 수 있다.
- 후보가 없는 시간(예: 17분)이다: "이 시간의 도착 후보가 없어요"가 보이고 진행이 막힌다.
- 후보를 고른 뒤 시간을 바꾼다: 선택이 해제되고 진행이 막힌다.

**엣지 케이스**
- 15분에서 더 줄이거나 360분에서 더 늘릴 수 없다.
- 360분: 한 바퀴를 여러 번 돌아 도착지가 출발지와 같아질 수 있다. 이것은 정상이다.
- 첫 출발지 저장 직후 시간 선택을 하지 않고 앱을 종료한다: 다음 실행은 메인이다. 출발지를 다시 고르지 않는다.
- 시간·후보를 고른 채 앱을 종료한다: 다시 열면 선택값은 남아 있지 않다 (FR-12).

### 영향 범위
- 기존 화면
  - "최초 정류장 설정" 자리표시 화면이 실제 검색 화면으로 바뀐다.
  - 메인의 "여행 준비" 버튼이 시간 선택 화면을 연다.
  - 준비 화면의 내용은 바꾸지 않는다 (W03).
- 기존 사용자
  - 이미 정류장이 저장된 사용자는 검색 화면을 보지 않는다. 메인으로 바로 들어간다.
  - 저장 데이터 형식은 바꾸지 않는다 (FR-12).
- 병렬 작업
  - 카드 발급(W01)과 같은 앱 상태·화면 분기를 건드린다. 서로의 변경이 충돌하지 않도록 이 작업의 변경은 첫 출발지·시간 선택 영역에 한정한다.
- 웹 프로토타입과 웹 회귀 검사는 바꾸지 않는다.

### 수용 기준

**첫 출발지 (FR-7, AC-9)**

- AC-1: 첫 실행 시 검색 화면 진입 → [FR-1]
  - Given: 카드 발급 완료, 저장된 정류장 없음
  - When: 앱을 연다
  - Then: 검색 화면이 보이고 결과 목록에 3건이 있다. 확인 버튼은 비활성이다.
- AC-2: 이름·별칭·방면 검색 → [FR-2]
  - Given: 검색 화면
  - When: 검색어 "서울숲", "건대", "성수"를 각각 입력한다
  - Then:
    - "서울숲" → 2건 (성수역 정방향, 서울숲역).
    - "건대" → 1건 (성수역 역방향).
    - "성수" → 3건.
- AC-3: 앞뒤 공백·빈 검색어 → [FR-2]
  - Given: 검색 화면
  - When: "  성수사거리  ", "   "(공백만), ""(빈 문자열)을 각각 입력한다
  - Then:
    - "  성수사거리  " → 1건 (성수역 역방향). 공백 없는 "성수사거리"와 결과가 같다.
    - "   " → 3건 전체.
    - "" → 3건 전체.
- AC-4: 결과 없음 → [FR-3]
  - Given: 검색 화면
  - When: "없는역"을 입력한다
  - Then: 결과 0건이다. "결과가 없어요" 안내가 보인다. 확인 버튼은 비활성이고, 눌러도 저장이 일어나지 않는다.
- AC-5: 선택 확인 문구 → [FR-3]
  - Given: 검색 결과 3건
  - When: 성수역 역방향 항목을 고른다
  - Then: "성수역 · 성수사거리 방면에서 출발"이 보이고 확인 버튼이 활성이다.
- AC-6: 확인 시 저장 → [FR-4, BR-5]
  - Given: 성수역 역방향을 선택한 상태
  - When: 확인을 누르고 저장이 성공한다
  - Then:
    - 최초 정류장과 현재 정류장이 모두 같은 이름("성수역")과 방향(-1)이다.
    - 카드 발급 상태, 카드 목록, 진행 여정(없음), 기록 목록(비어 있음)은 저장 전과 같다.
- AC-7: 저장 성공 후 이동 → [FR-4]
  - Given: AC-6의 저장이 성공했다
  - When: 저장이 끝난다
  - Then: 시간 선택 화면이 보이고 출발지 표시가 "성수역"이다. 검색 화면은 보이지 않는다.
- AC-8: 저장 실패 → [FR-4]
  - Given: 정류장을 선택했고 저장이 실패하도록 한 상태
  - When: 확인을 누른다
  - Then:
