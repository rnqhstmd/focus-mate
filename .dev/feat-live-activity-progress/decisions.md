# 의사결정 기록

확인 질문과 선택을 기록한다. 고른 것뿐 아니라 버린 선택지도 남으므로 왜 그렇게 정했는지가 추적된다.

## 2026-10-15 16:55 · 화면 이탈

**Q.** 여행 화면이 사라지는 경우(평소엔 안 생기는 방어 경로, 타이머는 일시정지로 저장됨) 잠금화면 카드는 어떻게 할까요?

선택지:

**→** 일시정지로 남김 (Recommended) — 앱 안 상태와 일치. 이어가기 시 같은 카드 재사용. 방치는 재실행 정리·만료로 막음
- 즉시 종료 — 카드가 남지 않아 단순. 이어가기 시 새로 시작

**A.** 일시정지로 남김 (Recommended)

## 2026-10-15 16:56 · 시간 만료

**Q.** 앱이 백그라운드인 동안 종료 시각이 지나면(앱이 깨어나지 못할 수 있음) 카드는 어떻게 보일까요?

선택지:

**→** 만료 지정 + '도착' 문구 (Recommended) — 종료 시각 직후를 만료로 지정해 0에서 멈춘 카드 대신 도착 문구를 보여줌
- 만료 지정 안 함 — 시스템 기본 동작. 0에서 멈춘 카드가 남을 수 있음

**A.** 만료 지정 + '도착' 문구 (Recommended)

## 2026-10-15 16:56 · 일시정지 진입

**Q.** 일시정지 상태로 여행 화면에 들어온 경우(재실행 후 이어가기 등), 재개 전에도 카드를 띄울까요?

선택지:

- 재개할 때 처음 표시 (Recommended) — 멈춘 여행으로 잠금화면을 채우지 않음
**→** 진입 즉시 '일시정지' 카드 — 앱 밖에서도 남은 여행을 상기

**A.** 진입 즉시 '일시정지' 카드

## 2026-10-15 16:57 · 시간 표기

**Q.** 잠금화면·아일랜드의 남은 시간 표기는 어떻게 할까요? (앱 안은 'N min' 분 올림)

선택지:

**→** 시스템 카운트다운 분:초 (Recommended) — 앱 갱신 없이 시스템이 매 초 줄여줌. 앱 안 표기와 단위는 다름
- 앱과 같은 'N min' — 일관되지만 분마다 앱이 갱신해야 하고 백그라운드에서 어긋날 수 있음

**A.** 시스템 카운트다운 분:초 (Recommended)

## 2026-10-15 16:57 · 백그라운드

**Q.** 앱이 백그라운드로 갈 때 카드를 한 번 더 동기화할까요? (상태 변화마다 이미 갱신함)

선택지:

**→** 하지 않음 (Recommended) — 불필요한 갱신을 줄이고 변경 범위를 좁게 유지
- 한다 — 어긋남 위험은 줄지만 갱신 요청이 늘어남

**A.** 하지 않음 (Recommended)

## 2026-10-15 17:11 · 진행 막대

**Q.** 운행 중 카드의 진행 막대는 어떻게 할까요? (카운트다운 글자는 계속 줄어듦. 막대는 현재 데이터로는 출발·재개·정지 시점 값에 멈춰 있음)

선택지:

- 시작 시각 필드 추가 (Recommended) — 카드 데이터에 진행 기준 시각 1개를 더해 막대도 시스템이 계속 채움. 필드 8→9개로 PRD 소폭 수정
- 고정 막대 허용 — 막대가 마지막 상태 변화 시점 값에 멈춰 있음. 글자만 줄어듦
- 운행 중엔 막대 숨김 — 일시정지에서만 막대 표시. 오표시 없음
**→** (직접 입력) 카드의 진행 막대라는게 무슨 말이야?

**A.** 카드의 진행 막대라는게 무슨 말이야?

## 2026-10-15 17:11 · 진행 막대

**Q.** 잠금화면 카드의 진행 막대(얼마나 왔는지 채워지는 가로 막대)를 어떻게 할까요?

선택지:

- 시간 따라 채워지게 (Recommended) — 카드 데이터에 기준 시각 1개를 더해 남은 시간과 함께 막대도 자동으로 차오름
**→** 막대 없애기 — 남은 시간 숫자만 보여줌. 카드가 단순해짐
- 멈춘 막대 허용 — 버튼 누른 시점 값에 멈춰 있어도 괜찮음

**A.** 막대 없애기

## 2026-10-15 17:12 · 재실행

**Q.** 여행 중 앱이 강제 종료돼도 카드는 혼자 계속 줄어듭니다. 그런데 앱을 다시 켜면 여행은 '일시정지'로 복원됩니다. 앱을 다시 켰 때 남아 있는 카드를 어떻게 할까요?

선택지:

**→** 앱 켜자마자 '일시정지'로 맞춤 (Recommended) — 앱 안과 카드가 바로 일치. 안 하면 여행 화면에 들어갈 때까지 카드가 계속 줄다가 '도착했어요'로 잘못 보일 수 있음
- 여행 화면 들어갈 때만 맞춤 — 변경 최소. 그 사이 카드가 실제와 다르게 보일 수 있음

**A.** 앱 켜자마자 '일시정지'로 맞춤 (Recommended)

## 2026-10-15 17:12 · 다른 여행

**Q.** 앱을 켰 때 지금 여행과 다른(예전) 여행의 카드가 남아 있으면(드문 경우) 어떻게 할까요?

선택지:

**→** 앱 켤 때 바로 없애기 (Recommended) — 남은 카드를 즉시 정리. 위 '일시정지로 맞춤'과 같은 시점이라 추가 부담 작음
- 여행 화면 들어갈 때만 없애기 — PRD 문면 그대로. W07 전엔 오래 남을 수 있음

**A.** 앱 켤 때 바로 없애기 (Recommended)

## 2026-10-15 17:13 · 전달 방식

**Q.** 타이머 상태 변화를 카드에 전달하는 방식을 정해주세요.

선택지:

**→** 타이머에 알림 1줄씩 (Recommended) — 타이머 코드 4곳에 '바뀜었다' 알림만 추가(진도 계산 불변). 화면 이탈·백그라운드까지 확실히 반영, W07과 겹치는 화면 파일 수정이 적음
- 화면에서 감지 (W06 방식) — 타이머 코드는 안 건드리지만 화면 파일 3곳에서 호출, W07과 충돌 가능성 큼

**A.** 타이머에 알림 1줄씩 (Recommended)
