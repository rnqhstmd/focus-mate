## 배경
여행(실제 분 타이머)의 남은 시간과 진행은 앱 안에서만 보였다. 집중하는 동안 휴대폰을 잠그거나 다른 앱을 쓰는 것이 이 제품의 일반적인 사용 방식이라, 남은 시간을 보려면 앱을 다시 열어야 했다. W15(2026-10-15 사용자 요청, journey FR-5 보조)는 잠금 화면과 다이나믹 아일랜드에 진행을 보여준다.

## 요구사항 (요약)
- 여행이 진행 중이면 잠금 화면 카드·다이나믹 아일랜드에 버스 번호·종류, 도착지, 남은 시간(시스템 분:초 카운트다운), 상태를 표시한다. 진행 막대는 두지 않는다(사용자 결정).
- 일시정지는 멈춘 남은 시간("M:SS")으로 갱신, 재개는 종료 시각을 다시 계산해 갱신, 도착하면 종료, 화면 이탈은 일시정지로 남긴다. 일시정지 상태로 진입해도 바로 일시정지 카드를 띄운다.
- 운행 중 카드는 종료 시각에 만료(stale)되어 앱이 깨어나지 못해도 "도착했어요"로 바뀐다. 일시정지 카드는 만료가 없다.
- 앱을 다시 켜면 저장 상태에 맞춰 남은 카드를 정리한다: 여행 없음·미출발·도착 → 종료, 출발·미도착 → 같은 여행 카드 1개를 일시정지로 맞추고 나머지·다른 여행 카드는 종료.
- 표시가 꺼져 있거나 실패해도 여행 진행·저장·화면은 그대로이고 오류를 보여주지 않으며 재시도하지 않는다. 같은 상태 반복(틱·복귀·체크포인트·백그라운드)에는 요청을 보내지 않는다.
- 카드에는 버스·도착지·시각·상태만 넣는다(카드 이름·사진·할 일·태그·소리·출발지 없음). 모든 문구는 한국어.
- 수용 기준 33건(AC-1~26, 28~34). 실기기 렌더·VoiceOver 확인(M-1~M-16)은 W14.

## 설계 요약
- 첫 앱 확장 타깃 `FocusMateWidgets`와 앱·위젯이 함께 컴파일하는 `ios/Shared`(카드 데이터 7필드, 문구·시간 선택 함수).
- 진도 계산은 바꾸지 않는다. `JourneyTimerController`는 상태가 바뀌는 4곳(appear·halt·resume·arrive)에서 `JourneyTimerObserving` 알림만 보낸다. 화면 세션 하나의 `JourneyLiveActivitySync`(저장자·타이머 의존 없음)가 순수 규칙 `JourneyLiveActivityPolicy`로 `LiveActivityGateway`(ActivityKit 어댑터 / UI 테스트용 기록기)에 시작·갱신·종료를 요청한다.
- 지도(W06)와 달리 뷰 onChange가 아니라 컨트롤러 알림을 쓴 이유: 화면 이탈과 백그라운드 저장 실패 정지까지 반영해야 해서다.
- AppModel·JourneyTimerView는 수정하지 않았다(W07 병렬 작업과 충돌 최소화).
