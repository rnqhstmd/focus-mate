# W06 MapKit 가상 코스 — PR 맥락

## 배경
W05가 만든 여행(타이머) 화면은 검은 배경에 남은 시간과 일시정지/재개만 있었다. journey FR-6(AC-7: 기본 지도와 승인된 앱 내 가상 코스 표시, 실제 GPS·버스 API는 범위 밖)이 미반영이었고, W05 인계 메모가 "W06: 타이머 화면 위에 지도"로 정해 두었다. 사용자가 숫자만 보는 대신 "버스를 타고 가는 중"이라는 여행 경험을 화면에서 느끼게 하는 것이 목적이다.

## 요구사항 (PRD 요약, AC 40건)
- 여행 화면 배경을 Apple 지도로 바꾸고, 9개 순환 정류장을 직선으로 잇는 앱 내 가상 코스를 그린다. 좌표는 각 정류장 실제 위치 근사, 서울 경계 안(앱 범위가 서울 전체라는 사용자 결정), 정류장 id에 묶인 데이터.
- 버스가 타이머 진도에 맞춰 코스를 따라 움직인다(정류장 구간별 직선 보간, 정수 초 산술, 도착 고정, 여러 바퀴).
- 카메라 따라가기/자유 탐색(사용자 제스처로만 탐색 전환, 따라가기 버튼은 항상 버스로 복귀), 오른쪽 위 도구 2개(버스 따라가기·지도 테마), 테마 시트(어두운 지도·라벨 있는 위성, 정류장 표시).
- 일시정지 중 도구 비활성, 일시정지·도착·이탈 시 시트 닫힘. 지도 상태는 저장하지 않음(저장 v4 불변), 위치 권한 미사용.
- 하단 정보 3종(남은 시간·남은 정류장·남은 거리), 동작 줄이기 시 카메라 애니메이션 없음, VoiceOver에서 지도는 하나의 요소.
- 제외: 정류장 목록 펼침(후속), 따라가기 중 지도 회전(Could), 이어가기·포기(W07), 도착 안내(W09), 실기기 검증(W14).

## 설계 요약
순수 규칙(JourneyCourse·JourneyCourseProgress·JourneyMapState/JourneyCameraPolicy) → 저장자·타이머 의존이 없는 @Observable JourneyMapController → SwiftUI MapKit 뷰(JourneyMapView·JourneyMapThemeSheet). 저장 도착지가 계산 도착지와 다르면 지도 없이 W05 배치로 보인다(W09도 같은 규칙). T0 스파이크로 MapKit 접근성 트리·법적 표기·드래그 감지·Toggle 값을 확인하고 규칙을 확정했다.
