## 배경
메인 메뉴의 "마이페이지"는 제목만 있는 빈 화면이었습니다. 카드는 발급 화면에서 공통 카드(PassFace)·이름(PassIdentity)으로 보이지만 마이페이지에는 없었고, 기록 쪽에는 하루 요약만 있어 전체 누적 완료 여정 수·시간 집계가 없었습니다. card FR-5는 "같은 카드와 records가 집계한 완료 여정 수·시간을 표시하고, card는 집계를 계산하지 않고 읽기만 한다"를 요구합니다. 사용자는 화면을 최신 시안(Pen EPnQQ, R38 마이페이지)에 맞춰 구성하도록 요청했습니다.

## 요구사항
- 메인 "마이페이지" → 시안 순서의 화면: 제목, "내 시간에, 내 취향을." / "한 장으로 함께하는 나만의 여정", 카드, "집중동행카드" / "모든 몰입 여정에 함께", 카드 꾸미기 행, 완료한 여정·함께한 시간 통계, 설정 행.
- records가 전체 완료 기록의 건수·분 합계를 계산하고 마이페이지는 읽기만 한다. 기록이 하나라도 유효하지 않으면 일부만 합산하지 않고 "-"와 "기록을 불러오지 못했어요"를 보인다.
- 시간 표기: 화면은 시안의 "0 min / 1 h / 1 h 5 min"(마이페이지 한정), VoiceOver는 "1시간 5분". 여정 수는 화면 숫자만, VoiceOver "완료한 여정, 3회".
- 카드 꾸미기 행은 W10 합류 전까지 자리표시 목적지 cardStudio, 설정 행은 기존 설정 화면. 메인 메뉴 4개는 그대로.
- 읽기 전용(저장 파일 불변), 카드 번호 비표시, 가장 큰 글자에서 전체 스크롤로 모든 요소 도달.
- 함께 고친 것(사용자 결정): 기준선에서 발견한 W02 큰 글자 회귀 — 가장 큰 글자에서 시간 화면 첫 후보가 잘려 탭이 닿지 않던 문제. 접근성 크기에서 머리말을 줄여 해결.
