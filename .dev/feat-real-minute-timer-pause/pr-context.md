## 배경
W04까지는 승차 태그 뒤 출발 안내의 '시작'을 눌러도 제목만 있는 임시 화면이 나왔고, 실제 집중 시간을 재는 기능이 없었다. 제품의 핵심 가치("선택한 실제 분만큼 집중")가 비어 있었다. W05(journey FR-5 / AC-6)는 선택한 분이 실제로 줄어드는 타이머와 일시정지·재개, 로컬 체크포인트를 만든다.

## 요구사항
- '시작' 후 남은 시간이 "N min"(올림)으로 줄어들고 일시정지/재개로 멈췄다 이어간다.
- 사용자 결정(2026-10-15): 이 앱은 보조 도구라 백그라운드·제어 센터에서도 타이머가 흐른다(웹 프로토타입의 "앱 밖 시간 미가산"을 iOS에서 뒤집음). 앱 종료는 여정이 끊긴 것으로 보고 재실행 시 메인에서 일시정지 상태로 남는다. 이어가기 선택 UI는 W07.
- 진행 중 10초마다, 전환·백그라운드·도착 때 즉시 저장. 저장 실패는 사용자에게 보이게 한다.
- 출발 후 메인 이동·재승차 불가. 0초 도착은 임시 상태만(완료 기록은 W09).
- 저장 형식 v4(진행 여정 paused), v3 읽기 호환, 분 1~360·경과·카탈로그 검증(손상 여정은 지금처럼 버림).
- 다이나믹 아일랜드(Live Activity)는 W15로 분리.
