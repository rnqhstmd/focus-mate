## 배경
W16a(#22)에서 서울 열린데이터광장 공공 데이터를 앱 번들로 바꾸는 스크립트와 계산 모듈을 넣었지만, 앱은 여전히 예시 데이터(가상 정류장 9개·버스 3종)로 동작했다. W09(#23) 하차 기능이 머지된 뒤 그 위에서 앱 연결을 마무리한다. GPS·실시간 API는 쓰지 않는다(사용자 결정).

## 요구사항
- 첫 출발 정류장을 서울 전체 정류장에서 이름·번호로 검색하고, 시간 선택 후보·지도·도달 정류장을 실제 노선 구간 시간으로 계산한다(±1분 규칙 유지).
- 옛 저장 파일은 정류장·진행 여정만 비우고 다시 고르게 안내한다. 카드·기록은 지킨다.
- 정류장 데이터를 읽는 중에는 포기·새 여정을 거절하고, 하차는 언제나 동작한다.
- 마이페이지에 데이터 출처(공공누리 제1유형)를 표시한다.
