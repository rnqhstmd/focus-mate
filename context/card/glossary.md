# 카드 용어 사전

> 구성 확정 / 담당·규모 미확인. 코드의 이름은 현재 구현 식별자이며 향후 네이티브 명칭 확정이 아닙니다.

| 용어 | 설명 |
|---|---|
| issuedPass | 발급 카드 ID/발급 정보 |
| 집중동행카드 | 발급 카드 표시 이름 |
| cardStyle | 카드 색·사용자 이미지와 배치 상태 |
| IC 칩 | 사진 편집과 독립된 고정 표시 요소 |
| pass-face | 승하차·프로필 등에서 공유하는 카드 표현 |
| 승차 LCD | 접촉 시 현재 카드 이름/ID 표시. 하차 LCD의 카드 외형 표시와 구분 |
