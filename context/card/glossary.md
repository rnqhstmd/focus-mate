# 카드 용어 사전

> 구성 확정 / 담당·규모 미확인. 코드의 이름은 현재 구현 식별자이며 향후 네이티브 명칭 확정이 아닙니다.

| 용어 | 설명 |
|---|---|
| issuedPass | 발급 카드 ID/발급 정보. iOS는 `CardSnapshot`(`id` `FM-`+숫자 8자리, `issuedAt`) |
| 집중동행카드 | 발급 카드 표시 이름 |
| cardStyle | 카드 색·사용자 이미지와 배치 상태 |
| IC 칩 | 사진 편집과 독립된 고정 표시 요소 |
| pass-face | 승하차·프로필 등에서 공유하는 카드 표현. iOS는 `PassFace`(기본 외형, 카드 번호 없음) |
| PassIdentity | iOS 카드 이름(집중동행카드)·번호 표기(`FM · 1234 5678`)의 단일 출처. 번호 표기는 어떤 화면에도 쓰지 않는다 |
| 카드 보충 | 발급됐지만 카드 정보가 없는 기존 저장 파일에 앱 시작 때 카드를 한 번 만들어 넣는 동작. 화면·햅틱 없음 |
| 마이페이지 통계 | 완료한 여정(기록 건수)·함께한 시간(분 합계). records가 집계하고 마이페이지는 읽기만 한다. 화면은 숫자·"1 h 5 min", VoiceOver는 "3회"·"1시간 5분". 집계 불가면 "-" |
| 승차 LCD | 접촉 시 현재 카드 이름과 체크 표시, 카드 번호 비표시(iOS 결정 2026-10-13, W04 구현. 웹 프로토타입은 이름/ID). 하차 LCD의 카드 외형 표시와 구분 |
