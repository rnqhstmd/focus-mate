# 공통 용어 사전

> 수정일: 2026-10-12. 현재 구현 기준의 공통 용어입니다. 도메인별 용어는 각 glossary.md를 봅니다.

| 용어 | 설명 |
|---|---|
| Focus Mate | 현재 앱 표시 이름. 저장소 이름 next-step과 구분 |
| 집중동행카드 | 앱에서 발급하는 가상 여행 카드. 실제 교통 결제 카드 아님 |
| 가상 정류장 | 저장·진행하는 앱 속 정류장. 실제 GPS나 실시간 운행 위치 아님 |
| 프로토타입 | 현재 HTML/CSS/JavaScript·localStorage·Web Audio 기반 구현 |
| iOS MVP | docs/MVP.md의 향후 네이티브 개발 범위. 현재 웹 완료와 구분 |
| 시연 데이터 | 실제 저장 상태와 분리한 화면 모아보기·예시 여행/기록 |
| 제품 장면 / 회귀 장면 / Pen 상태 | 현재 18 / 21 / 42개이며 서로 같은 분류가 아님 |
| localStorage | 브라우저 로컬 저장. 서버 저장·기기 간 동기화 아님 |
| 동작 줄이기 | 공간 이동·회전·햅틱 등을 줄이고 상태 피드백은 유지하는 설정 |
| ❓ | 사용자 검토가 필요한 미확인 정보 |


## 개발·검증 용어

| 용어 | 설명 |
|---|---|
| FR / NFR | 기능·비기능 요구사항 ID. 각 도메인 안에서 유일하며 경로와 함께 참조한다. |
| AC | 개별 요구사항의 검증 가능한 수용 기준. 구현 여부와 검증 여부를 구분한다. |
| Phase | 선행 조건·산출물·완료 기준을 가진 개발 단계. 순서는 개발 단계 문서를 기준으로 한다. |
| 웹 기준선 | 현재 커밋의 HTML·Pen·문서와 확인된 VM 결과. 네이티브 구현을 의미하지 않는다. |
| VM 회귀 | mock DOM과 수치·상태로 검사한 결과. 브라우저 픽셀·실기기 터치·햅틱과 다르다. |
| 네이티브 미착수 | Swift 소스·Xcode 프로젝트·실기기 증거가 없는 현재 iOS 상태. |
