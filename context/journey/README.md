# 여정 도메인

> 구성 확정 / 담당·규모 미확인 · 2026-10-16. 기존 구현과 승인된 후속 계획을 구분하며 사용자/담당/성공 지표는 미확인입니다.

시간·버스·도착지 선택부터 준비·승하차·지도 이동과 중단 복원을 묶는 흐름.

## 배경

사용자가 할 일 하나와 시간을 정하고, 카드 접촉을 출발/종료 의식으로 사용해 완료까지 이어가는 흐름을 제공한다. 현재 웹은 15~360 min 선택과 후보 검증, 준비 허브, 승하차 접촉, 지도 추적/탐색, 30초 압축 진행, 일시정지와 로컬 여정 복원을 구현한다.

## 안 하면 어떻게 되는가

준비 미완성 출발, 접촉 후 재개 상태 손실, 하차 전 완료 기록 생성 같은 상태 경계 오류가 생길 수 있다. 발생 건수·손실 비용은 ❓.

## 사용자와 규모

대상 초안: 혼자 여행 시간을 정하고 독서·작업·쉼 등 할 일 하나를 담는 사용자. 검증된 사용자 수 ❓, 사용 빈도 ❓, 월 여정/데이터 규모 ❓.

## 성공 기준

초안 기준: 미완성 준비 출발 차단, 중복 접촉 차단, 접촉 후 저장 보존, 하차 전 완료 기록 없음. 출시 목표 성공률·복원 허용 시간은 ❓.

## 현재 상태

네이티브에는 선택·준비·승차·실제 분 타이머·일시정지·지도·이어가기/포기·하차가 구현됐습니다. `FocusMateWidgetsBundle`은 현재 `JourneyLiveActivityWidget`만 등록하고 홈 위젯은 없습니다. W15의 잠금 화면·다이나믹 아일랜드는 구현돼 있지만, 승인된 차콜·오프화이트 디자인과 가로 눈금 타임라인은 W17 대기입니다. 집중 유도형 소형·중형 위젯은 공유 기반·분석형과 합쳐 W18에서 구현합니다. 실기기 렌더링·VoiceOver 통과를 의미하지 않습니다.

W17은 총 시간·시간 기준점·멈춘 남은 초로 집중 세션 진행률을 표시합니다. 실제 GPS/버스 ETA가 아니며 정상 완료 즉시 종료 정책을 유지합니다. W18 탭은 기존 최초 설정·이어가기·새 여정 확인·하차 경로를 지키고 여정을 직접 시작하거나 덮어쓰지 않습니다. [승인 계획](../../.dev/system-surfaces-plan/plan.md)에 범위·검증 기준을 기록했습니다.

card가 소유하는 카드 ID/외형을 참조한다. journey는 태그·할 일·선택 소리와 재생 수명을 소유하고 preferences의 환경 선호/복구 안내를 적용한다. records에는 하차 접촉 성공만 완료를 전달한다.
