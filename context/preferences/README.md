# 환경·복구 설정 도메인

> 구성 확정 / 담당·규모 미확인 · 2026-10-12. 제품 관점의 권장 경계이며 독립 코드 모듈이 아닙니다.

움직임 선호와 기기/브라우저 환경 제한, 저장·지도·오디오 실패 안내의 설정 경계를 정리합니다. **태그·할 일·선택 소리는 여정 데이터이므로 journey가 소유합니다.**

## 배경

현재 웹은 시스템 동작 줄이기 선호와 화면의 체크박스를 동기화합니다. 지도/오디오 재시도·무음 계속, 저장 차단/손상 안내가 있으며 여정이나 기록을 임의로 초기화하지 않습니다. 환경 제한에서도 진행/복원 데이터가 사라지지 않는 계약을 다룹니다.

## 안 하면 어떻게 되는가

사용자의 모션 선호가 적용되지 않거나 지원하지 않는 재생/저장 상태를 성공으로 안내할 수 있습니다. 발생 빈도·대상 기기 수는 ❓.

## 사용자와 규모

동작 줄이기 사용자·저장/오디오 지원 제한 환경 사용자라는 대상 초안입니다. 검증된 사용자 수 ❓, 대상 OS/기기 범위 ❓, 사용 빈도 ❓.

## 성공 기준

초안 기준: 시스템/체크박스 모션 상태 동기화, 실패 안내·재시도 동안 기존 여정 보존. 접근성 출시 기준·복구 성공률 목표는 ❓.
