# 환경·복구 설정 도메인

> 구성 확정 / W13 저장 오류 복구 구현 완료 / 담당·규모 미확인 · 2026-10-13. 제품 관점의 권장 경계이며 독립 코드 모듈이 아닙니다.

움직임 선호와 기기/브라우저 환경 제한, 저장·지도·오디오 실패 안내의 설정 경계를 정리합니다. **태그·할 일·선택 소리는 여정 데이터이므로 journey가 소유합니다.**

## 배경

웹은 시스템 동작 줄이기 선호와 화면의 체크박스를 동기화하고 지도/오디오 재시도·무음 계속, 저장 차단/손상 안내를 제공합니다. iOS는 손상·미지원 버전·내용 불일치·읽기 실패에서 원본을 바꾸지 않는 재시도와, 명시적 확인 뒤 동일 바이트 내부 백업을 검증하고 정리하는 흐름을 제공합니다. 환경 제한에서도 진행·복원 데이터를 임의로 초기화하지 않는 계약을 다룹니다.

## 안 하면 어떻게 되는가

사용자의 모션 선호가 적용되지 않거나 지원하지 않는 재생/저장 상태를 성공으로 안내할 수 있습니다. 발생 빈도·대상 기기 수는 ❓.

## 사용자와 규모

동작 줄이기 사용자·저장/오디오 지원 제한 환경 사용자라는 대상 초안입니다. 검증된 사용자 수 ❓, 대상 OS/기기 범위 ❓, 사용 빈도 ❓.

## 성공 기준

시스템/체크박스 모션 상태 동기화, 실패 안내·재시도 동안 기존 여정 보존, iOS 저장 오류에서 자동 정리 금지와 보존 실패의 명시적 안내가 현재 기준입니다. 접근성 출시 기준·복구 성공률 목표는 ❓.

## 현재 상태

웹의 `matchMedia`와 체크박스 상태는 존재하지만 **reduce의 독립 localStorage 키는 없으며 영속 설정이라고 주장하지 않습니다.** iOS W13 저장 오류 복구는 구현·인수 완료 상태로, 재시도·확인/취소·동일 원본 내부 백업 검증 뒤 정리·실패 안내를 제공합니다. iOS 26.5에서 단위 141건과 UI 21건, 웹 31건과 경계 검사, Debug·Release 빌드가 통과했습니다. VoiceOver 포커스 코드와 큰 글자 시뮬레이터 동작은 적용·검증했지만 실제 VoiceOver 포커스 이동과 실기기 사용성은 Phase 6 미검증입니다. 접근성·모션 전체 범위와 설정 화면은 계속 진행 대상입니다.
