# 환경·복구 설정 아키텍처

> 구성 확정 / W13 저장 오류 복구 구현 완료 / 담당·규모 미확인 · 2026-10-13. 개념 경계이며 독립 서비스/모듈이 아닙니다.

## 현재 시스템 구조

### 웹 환경 경계

[단일 HTML](../../designs/final/animation-preview.html)의 `matchMedia('(prefers-reduced-motion: reduce)')`, `reduce`/`settingsReduce` 체크박스와 `reduced()`가 현재 모션 상태를 연결합니다. 독립 localStorage 설정 키는 없습니다. 지도·오디오 복구는 각 구현의 오류 안내·재시도 동작에 있으며 중앙 환경 서비스로 분리되어 있지 않습니다.

### iOS 저장 오류 복구 경계

1. [LocalSnapshotStore](../../ios/FocusMate/LocalSnapshotStore.swift)는 활성 원본을 관찰합니다. 정리 시 원본을 읽고 확인 화면에서 확보한 바이트가 있으면 현재 원본과 비교한 뒤, 내부 백업을 기록·재읽기하여 같은 바이트임을 확인합니다. 이후 원본이 다시 바뀌지 않았을 때만 활성 데이터를 삭제하고 삭제 완료를 확인합니다.
2. [AppModel](../../ios/FocusMate/AppModel.swift)은 재시도, 정리 확인·취소, 성공·실패 화면 전환과 정리 시도 이력을 소유합니다. 유효한 확인을 받은 정리 중에는 다른 저장·복구 동작을 받지 않습니다.
3. [RootView](../../ios/FocusMate/RootView.swift)는 오류 원인, 다시 시도, 저장 데이터 정리, 초기화·내부 보존 안내와 실패 결과를 표시합니다. 큰 글자에서 스크롤 가능한 버튼과 VoiceOver 제목·포커스 코드를 적용했으며, 실제 VoiceOver 포커스 이동과 실기기 사용성은 Phase 6에서 확인합니다.

보존 백업은 앱 내부에서만 유지하며 외부 내보내기·공유·복원 UI는 없습니다. 버전 1·2 읽기와 버전 2 저장 계약은 유지합니다. 저장 변경은 단일 MainActor 작성자 경계에서 직렬화되지만, 원본 재확인과 삭제는 파일 시스템 트랜잭션이 아니므로 외부 작성자 경쟁과 전원 손실까지 원자적으로 복구한다고 보장하지 않습니다.

journey는 태그·할 일·선택 소리와 재생 수명·여정 복원을 소유합니다. card는 발급 ID·외형·접촉 표시 UI를 공급하고 실제 여정 생성은 journey에 맡깁니다. records는 완료/메모를 저장합니다. 이 경계는 환경 선호·지원 제한·복구 안내 계약을 정리하며 기존 도메인 데이터를 변경하지 않습니다.

## 남은 네이티브 범위

접근성·모션의 전체 화면 적용과 설정 화면은 FR-3, 실제 VoiceOver 포커스·큰 글자·드래그·햅틱·오디오 사용성은 NFR-2에 남아 있습니다. 새 설정 저장 정책·동기화는 미확정 ❓이며 W13 저장 오류 복구 완료 범위에 포함하지 않습니다.
