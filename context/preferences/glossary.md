# 환경·복구 설정 용어 사전

> 구성 확정 / 담당·규모 미확인 · 2026-10-13.

| 용어 | 설명 |
|---|---|
| prefers-reduced-motion | 브라우저가 읽는 시스템 모션 선호 |
| reduce / settingsReduce | 현재 두 체크박스로 동기화하는 모션 상태. 독립 영속 저장 키 없음 |
| 저장 차단 | localStorage 접근/쓰기 실패. 세션 사용과 재실행 복원 보장을 구분 |
| 데이터 손상 | 읽을 수 없거나 버전/형식이 맞지 않는 데이터. 명시적 정리 전 보존 |
| 재시도 / 무음 계속 | 지도·오디오 실패에서 기존 준비/진도를 보존하는 복구 선택 |
| 환경 지원 | AudioContext·햅틱 등 지원 여부. 지원하지 않아도 여행을 계속하는 계약 |
| 활성 저장 원본 | 앱 시작 때 읽는 현재 저장 파일. 재시도·확인 진입·취소만으로는 변경하지 않음 |
| 원본 검증 백업 | 정리 직전 원본과 같은 바이트임을 다시 읽어 확인한 앱 내부 백업 |
| 명시적 정리 | 초기화 결과와 내부 보존 조건을 본 사용자가 확인해야 시작되는 저장 데이터 제거 |
| 정리 시도 이력 | 유효한 정리 확인 뒤 보존·삭제 절차에 들어갔음을 기억하는 상태. 실패 후 근거 없는 원본 불변 안내를 막음 |
| 복구 실패 안내 | 보존 실패·정리 실패·원본 변경·원본 소실·정상화에 따라 정리 미완료 이유와 다음 재시도를 알리는 화면 상태 |
