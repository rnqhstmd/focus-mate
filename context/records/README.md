# 기록 도메인

> 구성 확정 / 담당·규모 미확인 · 2026-10-12. 코드·현재 문서로 추출한 초안이며 사용자/담당/성공 지표는 미확인입니다.

완료한 여정·선택 메모·연간 잔디와 기간/태그별 분석을 관리하는 경계.

## 배경

사용자가 완료한 시간과 한 일을 다시 확인하고 날짜·태그별로 돌아볼 수 있도록 한다. 현재 웹은 하차 성공 완료 기록·200자 선택 메모, 날짜별 최신순 10개씩 보기, 연간 시간 잔디, 주간/월간·태그 필터 분석을 구현한다.

## 안 하면 어떻게 되는가

진행/포기 여정이 완료 통계에 섞이거나 예시 기록이 실제 기록을 덮어쓸 수 있다. 예상 기록 수·보관 기간은 ❓.

## 사용자와 규모

대상 초안: 혼자 여행 시간을 정하고 독서·작업·쉼 등 할 일 하나를 담는 사용자. 검증된 사용자 수 ❓, 사용 빈도 ❓, 월 여정/데이터 규모 ❓.

## 성공 기준

초안 기준: 하차 성공만 완료 생성, 포기 제외, 예시 분리, 메모와 여행 연결 유지. 보관/삭제/내보내기 정책과 규모 목표는 ❓.

## 담당자

| 역할 | 이름 | 비고 |
|---|---|---|
| PM/PO | ❓ | 사용자 확인 필요 |
| 개발 리드 | ❓ | git 작성자로 추정하지 않음 |

## 현재 상태

웹 프로토타입의 현재 동작을 정리했습니다. 도메인 경계는 확인됐고 담당자는 ❓입니다. 네이티브 iOS는 미착수입니다.

journey의 하차 성공을 입력으로 받는다. 카드 외형이나 진행 타이머를 변경하지 않으며 완료 기록에 있는 태그/시간으로 분석한다.
