# 기록 용어 사전

> 구성 확정 / 담당·규모 미확인. 웹과 iOS의 현재 구현 용어를 구분합니다.

| 용어 | 설명 |
|---|---|
| 완료 기록 | 하차 접촉 성공에서 생성하는 여행 스냅샷 |
| 선택 메모 | 여행에 연결한 텍스트. iOS W08은 앞뒤 공백·개행을 제거한 뒤 UTF-16 200단위까지 저장하며 Unicode scalar를 분할하지 않는다. 빈 값으로 수정하면 삭제한다. |
| 완료 당시 날짜 | 완료 시각과 완료 당시 전달된 시간대로 생성한 `date`. 복원 후 시간대가 바뀌어도 저장된 날짜를 일별 집계에 사용한다. |
| 완료 기록 멱등성 | 같은 여행 ID로 하차 완료 저장을 다시 요청해도 기존 기록을 유지하고 중복 생성·재저장을 하지 않는 계약. iOS W08은 ID 원문의 UTF-16 코드 단위로 비교한다. |
| 연간 잔디 | 하루 완료 여행 시간 합계를 5단계 초록색으로 표시 |
| 태그 분석 | 완료 기록에 저장된 태그로 집계·필터링 |
| 예시 기록 | 실제 localStorage 완료 기록과 분리한 시연 자료 |
| postMemo | 하차 이후 홈에서 남기는 해당 여행의 선택 메모 |
| 공용 분석 집계 | 계획 W09b. 같은 완료 기록·기간·달력/시간대 입력으로 앱과 위젯이 재사용하는 순수 계산 결과. 공유 파일 입출력은 소유하지 않는다 |
| 위젯 공유 스냅샷 | 계획 W18. 앱 원본 저장소의 저장 성공 후 App Group에 게시하는 버전 있는 최소 집계/상태 읽기 모델. 메모·할 일 원문을 포함하지 않는다 |
| 분석 위젯 | 계획 W18. 공용 집계의 오늘·주간 시간/횟수·7일 추이·태그별 시간을 소형·중형으로 제공하고 해당 분석 맥락으로 연결한다 |
| 위젯 데이터 상태 | 계획 W18. 정상적인 빈 기간, 갱신이 늦은 이전 값, 파일·버전·권한 문제의 접근 불가를 구분한다. 접근 불가를 0분으로 표시하지 않는다 |
