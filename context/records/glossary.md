# 기록 용어 사전

> 구성 확정 / 담당·규모 미확인. 코드의 이름은 현재 구현 식별자이며 향후 네이티브 명칭 확정이 아닙니다.

| 용어 | 설명 |
|---|---|
| 완료 기록 | 하차 접촉 성공에서 생성하는 여행 스냅샷 |
| 선택 메모 | 여행에 연결한 최대 200자 텍스트 |
| 연간 잔디 | 하루 완료 여행 시간 합계를 5단계 초록색으로 표시 |
| 태그 분석 | 완료 기록에 저장된 태그로 집계·필터링 |
| 예시 기록 | 실제 localStorage 완료 기록과 분리한 시연 자료 |
| postMemo | 하차 이후 홈에서 남기는 해당 여행의 선택 메모 |
