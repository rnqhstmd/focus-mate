# 여행 소리 원본 입력

`scripts/build-travel-ambience.py`가 앱 소리(`designs/final/assets/audio/travel-*-v2.wav`)를 만들 때 읽는 입력 파일이다. 앱 패키지에는 포함하지 않는다.

| 파일 | 만든 곳 |
|---|---|
| bus-cabin-hum-v1.wav | `scripts/generate-bus-cabin-hum.py` (합성) |
| rain-windshield-cc0-v1.wav | `scripts/prepare-recorded-ambience.py` (BigSoundBank 1295, CC0) |
| forest-edge-cc0-v1.wav | `scripts/prepare-recorded-ambience.py` (BigSoundBank 0905, CC0) |
| recorded-stats.json | 2026-10-12 녹음 편집 당시의 수치 기록 |

출처와 라이선스는 [SOURCE.md](../final/assets/audio/SOURCE.md)를 본다.
