# Pencil 편집 가능한 시안 복원

복원일: 2026-10-12.

이 자료는 이전 36개 시안의 복원 기록이다. 현재 개선 시안은 [revised](../revised/README.md)를 사용한다. Pen의 이전 화면은 오른쪽 `이전 시안` 영역에 보존했다.

Pencil에서 열려 있던 문서에 기존 이미지 프레임을 편집 가능한 화면으로 교체했다. 원본 PDF의 도형 경로, 한글 텍스트, 글꼴, 색상, 좌표를 사용했다. 원본 PNG·PDF·HTML은 수정하지 않았다.

## 편집 범위

- 개별 화면 36개: 텍스트 433개, 벡터 도형 726개, 사진 자산 26개.
- 전체 흐름과 화면 그룹 보드 6개: 개별 화면 컴포넌트의 연결된 인스턴스로 구성했다.
- 브랜드와 모션 보드 2개: 텍스트와 벡터로 복원했다.
- 앱 아이콘: 브랜드 보드의 벡터 도형으로 복원했다.
- 지도 사진과 생성된 승차권 그래픽, 별도로 배치한 승차권 2종은 이미지 자산으로 유지했다.

텍스트는 직접 수정할 수 있다. 버튼·패널의 배경과 문구는 이름이 있는 프레임 안에 묶었다. 아이콘과 경로는 벡터 경로 또는 기본 도형이다. 원본 위치를 유지하기 위해 화면 내부는 절대 좌표로 배치했다. 그룹 보드의 화면은 연결된 인스턴스이며 개별 화면을 편집하면 함께 반영된다.

## 문서 위치

Pencil 작업 문서:

`designs/focus-mate.pen`

저장소 배포본은 [../focus-mate.pen](../focus-mate.pen)이다. 작업 문서의 네이티브 원본을 파일 형식 변환 없이 백업했으며, 참조 이미지도 `../assets/next-stop/`에 함께 보존했다. 다른 PC에서는 이 저장소의 원본을 열면 된다.

`document-snapshot.json`은 최종 검수 후 Pencil MCP로 읽은 전체 94개 최상위 노드와 변수의 편집 레이어 자료다. 벡터 경로도 포함하며 참조 누락과 placeholder가 없다. `.pen`을 대체하는 파일은 아니다. `asset-manifest.json`의 116개 참조 이미지는 모두 저장소에 포함한다. 예전 자산도 삭제하지 않고 보존했다.

## 복원 자료

`pencil-layers.json`은 38개 PDF 페이지의 편집 레이어 정의이며 `.pen` 파일이 아니다. `scripts/rebuild-pencil-from-pdf.py`가 생성한다. Pencil의 execute API에서 화면을 하위 레이어와 함께 교체하는 방식으로 반영한다. 이 스크립트는 `.pen` 파일을 읽거나 쓰지 않는다.

```powershell
python scripts/rebuild-pencil-from-pdf.py --asset-dir "designs/assets/next-stop/editable"
```

## 검증

- 01–36 화면 번호 누락 없음.
- 모든 개별 화면은 원본과 같은 402 × 874 크기.
- 모든 화면에 실제 텍스트와 벡터 레이어가 있음.
- 레이어 경계 넘침, 남은 placeholder, 잘못된 유니코드 문자 없음.
- 시작·설정·태그·집중·도착·오류·키보드 화면과 전체 보드 렌더링 확인.
- 홈의 버스 번호를 2014→2015로 변경한 뒤 2014로 복원해 텍스트 편집 동작 확인.

PDF의 일부 숨겨진 텍스트에 있던 사설 문자 영역의 콜론·화살표와 브랜드 색상 문자열을 바로잡았다. 글꼴 렌더링에 따른 픽셀 차이는 있을 수 있으며 최신 HTML의 후속 변경을 추가한 것은 아니다.
