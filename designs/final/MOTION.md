## 동작 줄이기
기기 접근성 설정을 기본으로 따른다. 지도 줌/회전/자동 카메라 추적을 끄고 고정 노선 지도로 표시한다. 카드·시트 공간 이동은 120–180ms 페이드로 대체하며 타이머/위치/잔여 정보는 계속 제공한다. 큰 자동 이동 없이 현재 정류장 변화 시에만 위치를 갱신한다. 백그라운드에서는 렌더 루프와 소리를 사용자 설정에 맞춰 제어한다.

Apple 참고: [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility), [Motion](https://developer.apple.com/design/human-interface-guidelines/motion). 앱 시안의 타이밍 수치를 Apple 지정값으로 해석하지 않는다.

## 시간 선택기 수정
FocusFlight [공개 시간 선택 영상](https://60fps.design/shots/focusflight-duration-slider-swipe-interaction)에서 관찰한 구조는 지도 위 하단의 이동 눈금, 고정 중앙 삼각 포인터, 시간에 연결된 목적지 카드다. V4는 이를 버스 한 노선의 도착 정류장 선택으로 적용한다.

일반 range 입력의 막대와 손잡이는 제거했다. 눈금과 시간 라벨 전체가 손가락 이동에 직접 따라가고, 손을 놓으면 도착 가능한 시간에 180ms로 정렬된다. 데모의 유효 시간은 15분~6시간, 5분 간격이다. 45분에 9정류장을 도는 가상 순환 코스이며 실제 버스 운행이나 정류장 소요 시간 자료가 아니다. 중앙 포인터는 이동하지 않는다. 가장자리에는 페이드가 적용되고, 15분과 6시간에서 이동을 제한한다. 시간 숫자·도착 정류장·정류장 수·거리·지도 경로 끝점을 같이 갱신한다.

좌우 화살표 키는 이전/다음 정류장 시간, Home/End는 15분/6시간을 선택한다. 보조 기술에는 slider 역할과 선택 시간·정류장 이름을 전달한다. 시각적으로 일반 슬라이더를 다시 표시하지 않는다. 동작 줄이기에서는 자동 스냅 애니메이션을 끈다. 데모에서는 실제 햅틱을 제공하지 않는다.

## 긴 여행과 지도 UI
정류장 카드는 출발, 도착, 노선, 총 정류장 수와 km, 완주 바퀴와 추가 정류장을 순서대로 표시한다. 2시간은 24정류장·13.2km·2바퀴+6정류장 예시다. 시간 눈금 외에 25분·1시간·2시간·4시간 바로 선택을 제공한다. 6시간까지 선택 가능하다.

지도 버스는 위에서 본 실루엣이며 진행 방향에 맞춰 회전한다. 방향 삼각형과 약한 그림자를 넣고, 정류장은 작은 점, 최종 하차는 원형 마커, 다음 정류장은 이름 라벨로 표시한다. 지나온 경로는 회색, 앞으로 갈 경로는 흰색이다. 반복 순환에서는 현재 회차의 구간을 표시하고 하단 진행 바는 전체 여행 기준을 유지한다. 집중 HUD에 시간(시:분:초), 남은 정류장과 km, 현재 회차를 제공한다.

브라우저 확인: End 키로 6시간/72정류장/39.6km/8바퀴 선택, 2시간 바로 선택, 생성된 카드 이미지 로드, 카드 터치 성공·중복 입력 비활성화·집중 진입, 회차·시간·정류장·거리 갱신, 일시정지를 확인했다. 실제 MapKit과 iPhone 동작은 별도 구현·검증 대상이다.

## 지도 추적·자유 탐색과 최소 HUD
FocusFlight 공식 App Store 스크린샷의 전체 지도, 얇은 흰 경로, 작은 제어 버튼과 잔여 정보 배치를 참고했다. 자동 추적·자유 탐색 버튼의 실제 작동은 공개 스크린샷만으로 확인하지 못했으며 아래 동작은 다음 정류장의 제품 설계다. https://apps.apple.com/us/app/focusflight-deepfocus-timer/id6648771147

집중을 시작하면 지도·노선·정류장·버스가 하나의 레이어로 움직인다. 버스가 지도 중앙보다 약간 아래에 머물도록 위치를 따라가며 자동 회전은 하지 않는다. 지도는 드래그하거나 방향키로 둘러볼 수 있다. 드래그가 시작되면 자동 추적을 해제하고 아이콘 버튼의 활성 상태와 접근성 이름을 갱신한다. 추적 아이콘을 눌러 복귀하거나 전체 노선 아이콘으로 경로를 한 화면에 맞춘다. 자유 탐색에서도 타이머는 계속 진행한다. 일시정지하면 타이머와 버스 이동이 멈추며 지도 탐색은 유지한다.

하단은 큰 검정 카드 대신 작은 지도 오버레이로 표시한다. 다음 정류장/회차와 하차 지점, 남은 시간·정류장·km, 얇은 진행선만 유지한다. 일시정지/재개 버튼을 앱 화면 안에 둔다. 동작 줄이기에서는 고정 지도와 수동 탐색을 유지하며 자동 추적 이동을 제한한다. 데모는 생성 이미지와 SVG 레이어 이동이며 실제 MapKit 지도를 구현한 것이 아니다.

브라우저 확인: 지도 드래그→자유 탐색, 추적 복귀, 전체 노선 원위치, 앱내 일시정지/재개 상태를 확인했다. 지도 레이어 변환값이 드래그와 추적 복귀에 따라 변경됨을 확인했다. 실제 iPhone 지도 제스처와 MapKit 카메라는 별도 검증이 필요하다.

## 카드 터치 안내와 전환 보호 — 2026-10-11
승차·하차 화면에 들어올 때 카드 위의 터치 링을 다시 시작한다. 1.2초 후 첫 안내, 이후 5초 주기로 최대 3회만 표시한다. 카드 활성화 즉시 안내를 종료하고 중복 입력을 막는다. 동작 줄이기 설정에서는 안내 애니메이션을 표시하지 않으며 항상 보이는 카드 터치 설명은 유지한다. 카드 자체는 버튼이므로 Enter/Space로 동일하게 실행한다. 키보드 활성화 후 다음 화면의 제어로 포커스를 이동한다.

태그 처리 중 다른 장면을 선택하면 대기 중인 승차·하차 전환을 취소한다. 새 카드 화면의 입력을 이전 비동기 처리로 잠그거나 이전 장면으로 되돌리지 않는다. 시간·정류장·거리 제목과 숫자는 각각 같은 행에 정렬하며 단위는 숫자 옆에 둔다. 시간 표시 열은 시:분:초와 6시간 여정을 수용한다.

## 메인 진입과 중앙 탭 안내 — 2026-10-11
초기 장면은 메인 홈이다. 현재 정류장·방향·선택 노선을 확인하고 집중 여행 시작으로 시간 선택에 들어간다. 시간 선택에서 홈으로 돌아갈 수 있으며, 하차 성공 후에는 방금 도착한 정류장을 홈의 출발지로 사용한다. 새로운 여행도 해당 출발지를 기준으로 목적지와 다음 정류장을 계산한다.

카드 위 안내는 실제 이미지 중심에 배치한 손가락 아이콘과 링으로 구성한다. 중앙 배치를 고정한 채 가벼운 탭 동작만 재생한다. 손가락과 링은 장면 진입/다시 재생 시 함께 초기화된다. 카드 아무 곳이나 터치 가능하며 설명은 승차/하차에 맞춰 표시한다.

## 참고 컴포넌트 동작 적용
홈 준비 흐름은 인사말 → 현재 정류장 → 버스 → 집중 태그 → 시간 선택이다. 선택 버튼은 활성 상태를 즉시 표시하고 선택값을 다음 화면으로 이어간다. 홈 콘텐츠는 스크롤하되 시작 버튼은 하단에 남긴다. 집중의 현재·다음·도착 안내는 항상 보이고, 전체 정류장 목록만 보조 펼침으로 제공한다. 카드 터치 안내는 원과 내부 손가락 도형 모두 중심을 맞춘다. 이 추가 동작은 HTML 프로토타입 기준이다.

시간 선택은 수평 눈금과 중앙 포인터를 유지한다. 손가락 입력에서 얻은 속도를 감쇠하며 짧게 이어 움직이고, 종료 시 선택 버스로 정류장에 도착 가능한 시간에 스냅한다. 가상 버스의 정류장 간 시간은 2014번 5분, 302번 6분, 421번 8분이다. 버스를 바꾸면 가까운 유효 시간으로 선택값도 맞춘다. 새 입력/장면 변경 시 이전 관성을 취소한다. 동작 줄이기에서는 관성을 생략하고 즉시 선택값에 맞춘다.

승차 준비 시트는 출발·도착, 시간·정류장·거리, 카드 터치 순서로 읽힌다. 시간 선택→승차 준비 전환은 지도 배경을 유지한 하단 시트의 이동/페이드로 표시한다. 경로 상세는 앱 내부의 펼치기/닫기 버튼을 제공하며 버튼 접근성 상태와 외부 미리보기 제어를 동기화한다. 다른 장면으로 이동하면 상세는 닫힌 상태로 초기화한다.

## 현재 시작·버스 선택 흐름 — 2026-10-11 후속 변경
위의 메인 즉시 진입·홈 태그 통합 설명은 이전 버전 기록이다. 현재 첫 이용은 출발 정류장 설정으로 연결하고 설정 완료 후 재실행은 마지막 정류장의 홈으로 시작한다. 출발지를 바꿀 때 검색을 다시 연다. 별도 반대편 확인 없이 정류장 이름과 방면을 보고 선택한다. 이후 시간→할 일→태그·소리→카드 태그 순서이며 자리와 음량 단계는 없다. 시간 단위는 h/min이고 공개 버스 번호는 2014/강남02/343이다.

홈의 버스 목록은 작은 행으로 표시하고 선택하면 지도에 선택 색상의 예시 노선을 미리 보여준다. 목록과 시트가 따로 스크롤되는 중첩을 없애고 홈 콘텐츠 한 영역만 스크롤하며 시작 버튼을 고정한다. 앱 내부 스크롤바를 숨기더라도 터치·휠·키보드로 내용에 접근할 수 있어야 한다. 실제 픽셀·터치 검증은 브라우저 접근 제한 해제 후 남아 있다.

## 사용자 제공 진행 화면 기준 지도 추적
따라가기는 위에서 본 버스를 화면 중앙 위쪽 기준으로 고정하고 지도·경로를 진행 접선 방향에 따라 회전/이동한다. 지도 회전과 버스의 역회전이 같은 좌표식에 연결되어 차체는 위쪽을 향한다. 손가락/휠 조작은 자유 탐색으로 전환하며 추적을 다시 켜면 최단각과 위치를 부드럽게 복원한다. 동작 줄이기에서는 회전 없이 현재 정류장 위치만 따라간다.

하단 패널은 배경/테두리 없이 시간·정류장·거리 글씨로 바꾸고 진행선은 숨겼다. 좌상단 일시정지, 우상단 세로 현위치/지도 버튼을 배치한다. 일시정지 중 지도는 흐려지고 상태 안내와 × 포기하기가 나타난다. 그만두기 확인은 이전 정책대로 시간/소리를 멈추고 취소 시 멈춤 상태를 복원한다. 정류장 목록은 작은 버튼으로 접고 펼친다.


### 지도 안전영역·경로 미리보기 후속 수정 — 2026-10-11
시간 선택의 버스 이동은 실제 여행 타이머와 별개로 4~8초 동안 선택 경로를 미리 보여준다. 시간 변경/장면 이동 때 초기화하며 동작 줄이기에서는 도착점과 선택 경로를 정적으로 표시한다. 미리보기 끝에도 선택 노선 색을 유지한다. 비여행 화면은 패널의 layout offset을 측정한 안전영역으로 지도를 맞추고 여행 중 펼친 정류장 패널은 추적 앵커를 옆으로 이동시킨다. 전체 노선 모드의 맞춤 축척은 다음 tick에서도 유지된다.


### 첫 메인·한 바퀴 미리보기·첫 출발지 전용 설정 — 2026-10-11
시간 미리보기의 4~8초/여행 길이 비례 규칙을 12초 등속 한 바퀴로 대체한다. 경로 누적 길이 기준으로 이동하며 선택 색선과 실제 여행 상태 분리를 유지한다. 일시정지 시 우측 지도 도구는 숨김·비활성이고 빨간 X 포기 버튼이 나타난다. 재개는 좌측에 유지한다. 첫 메인에는 노선 대신 현재 위치 핀과 시작 버튼을 표시한다.
