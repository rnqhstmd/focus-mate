## 이번에 직접 확인한 증거
Pen의 승차·집중·하차·지도 오류 화면을 렌더링해 아이콘, 수치 행, 카드 안내 위치를 확인했다. 하차 안내 링은 카드 앞 레이어로 옮겼다. 변경 화면과 전체 흐름 복사본 7개의 부모 크기 대비 요소 위치/크기를 확인한 결과 경계를 벗어나는 요소가 없었다. 편집 placeholder도 남아 있지 않다.

전체 보드와 수정된 개별 PNG를 다시 내보냈다. next-stop-final.pdf의 페이지 객체 38개와 파일 갱신을 확인했다. 독립 코드 리뷰에서는 접근성 이름, native button 키보드 동작, 중복 입력 방지, 지연 전환 취소 처리를 확인했다. 작은 폰의 정류장 제목이 옆 열로 넘어갈 가능성을 발견해 정류장 열의 너비를 60px로 보장했다. 숫자 크기는 폰 영역 너비에 따라 20–32px로 조정한다. 자바스크립트 구문 검사(node --check)와 정적 필수 제어/전환 조건 검사는 exit 0으로 통과했다.

## 메인 홈·중앙 터치 안내 추가 검증
홈과 승차·하차 시안을 Pen에서 렌더링했다. 카드 안내가 이미지 중앙에 놓이고 장식 경로와 구별되는 손가락 아이콘으로 표시되는 것을 확인했다. 변경된 원본/복사본 5개의 부모 경계 검사에서 넘침이 없었다. 최종 보드와 개별 화면·38페이지 PDF를 갱신했다.

Node VM과 mock DOM으로 실제 데모 스크립트를 실행했다. 메인→시간→탑승→집중→도착→메인 흐름, 현재 정류장·다음 출발/목적지 갱신, 중복 카드 입력, 취소된 지연 전환, 홈 상태 초기화, 6시간 잔여 값, 중앙 안내 배치 조건 검사가 PASS였다. 독립 코드 리뷰에서 재탑승 시 노선 끝을 넘는 남은 구간 표시 누락을 발견해, 경로 길이와 공백의 합을 폐곡선 한 바퀴 길이로 맞췄다. 출발 위치 offset 5에서 남은 5/3/1정류장과 완주·6시간의 dash/gap/offset 값을 추가 검사해 PASS를 확인했다.

이번 추가 검증은 DOM 상태와 경로 수학을 확인하며 실제 픽셀 배치, 키보드 기본 동작, 애니메이션 시각 품질을 검증하는 브라우저 테스트와 구별된다. 기존 브라우저 접근 거절 이후 브라우저나 다른 UI 수단으로 우회 실행하지 않았다.

사용자 요청에 따라 앱 내 브라우저 접근을 다시 시도했지만, 저장된 사용자 거절 설정으로 차단되어 새 허용창은 표시되지 않았다. 이 설정을 해제하는 도구는 제공되지 않았다. 실제 브라우저 화면·터치·키보드 및 60fps 성능은 미검증이며 기존 브라우저 JPG를 갱신하지 않았다.

## 홈 버스·태그 선택과 정류장 안내
HTML에 시간대 인사말, 가상 버스 세 개, 집중 태그 네 개를 추가했다. 버스별 5/6/8분 이동 간격과 도착 가능한 시간 스냅을 사용하며 선택값이 준비·집중·완료·홈 복귀까지 이어진다. 현재·다음·도착과 남은 정류장 수는 집중 화면에 기본 노출한다. 홈은 콘텐츠만 스크롤하고 시작 버튼은 별도 하단에 둔다. 지도 도구는 하단 패널의 측정 높이에 맞춰 이동한다.

확장 VM QA 직접 실행에서 버스·태그 전파와 유지, 버스별 시간 스냅과 정류장 계산, 짧은 여행·6시간의 현재/다음/도착·잔여 개수, 인사말, 기존 전체 전환·관성·중복입력·시트 상태 검사가 PASS였다.
