# Next Step · 다음 정류장 — V4

잠정 이름: **Next Step · 다음 정류장**. 영어의 '다음 단계'와 한국어의 '다음 정류장'을 연결한다. 부제: **버스로 떠나는 나만의 여행**. 2026-10-11 사용자 선택으로 프로토타입의 영문 텍스트 표기를 변경했다. 화면 문구는 '집중' 대신 버스 여행을 중심으로 구성하며 독서·작업 등은 여행 중 할 일로 표현한다. 기존 Pen·PDF·이미지에 포함된 Next Stop 및 이전 문구는 이전 시안이며 아직 교체하지 않았다.

V4 Mono + 지도 스타일을 최종 기준으로 통일했다. 이전 V1/V2/V3 및 V4 비교용 Mono/Glass 프레임을 삭제하고 최종 프레임만 다시 구성했다. designs의 이전 exports/v2/v3/v4 폴더도 삭제했다. 연구 보고서와 사용자가 첨부한 원본 문서는 유지한다.

## 핵심 워크플로우
첫 이용 01→03→02. 홈은 앱 속 현재 정류장/승차장 방향/위치의 출처를 먼저 표시한다. 반대편은 04에서 확인하고 핀/방향/버스 목록을 같이 바꾼다.

버스 선택 02→05. 시간 눈금은 15분~6시간을 선택하며 종점 이후에는 가상 순환 여행을 이어간다. 다른 버스를 임의로 바꾸지 않는다. 할 일 06(입력 중 36)→태그 07→생성/편집 08. 태그 기본 시간은 최근값/기본값으로 제안하고 이번 여행에서 수정할 수 있다. 이름이 비거나 중복이면 29의 인라인 오류를 표시한다.

승차권 11에서 좌석09/소리10 조정. 좌석은 지도 추적 카메라 프리셋의 의미이며 실제 창밖 영상이 아니다. 카드 터치 성공31 이후에 타이머 시작→12. 탑승 처리 중 중복 입력 차단.

집중12에서는 현재 이동 구간/다음 정류장/목적지, 시간/정류장/km, 진행률을 보여준다. 경로13/더보기32/소리10/지도21은 하단 시트로 연다. 일시정지14에서 이동과 시간을 함께 멈추며 중도 종료15는 지나온 마지막 정류장을 다음 출발지로 저장하고 실제 집중 시간만 기록한다. 진행률은 집중 시간 비율이며 정류장/거리 비율과 항상 같지는 않다.

정상 완료16는 기록을 먼저 저장한 뒤 하차 태그를 제공한다. 이후 홈02의 현재 정류장/방향을 목적지로 갱신한다. 기록17→상세18→메모24. 태그관리19→편집08→삭제30. 태그 삭제 후 기존 기록은 태그 없음으로 남는다. 설정20→지도21/알림22 또는 권한꺼짐35/앱정보33. 알림 허용 시 실제 iOS 권한 창을 사용한다. 앱이 비행기 모드나 시스템 집중 모드를 자동으로 바꾸는 UI는 제공하지 않는다.

지도를 못 불러와도 타이머/경로 숫자는 유지27/28. 타이머는 저장된 시작/일시정지 시각으로 계산하며 잠금/백그라운드에서도 이어진다. 진행 중 앱 복귀34는 현재 상태로 돌아오며 경로를 빠르게 재생하지 않는다. 기록 없음23/버스 없음25/검색없음26 상태도 설계했다.

## 구현 규칙
드래그 제스처에는 버튼 대안을 제공한다. 승차·하차 카드는 자체가 접근 가능한 버튼이며 별도의 시작/하차 버튼을 두지 않는다. 44pt 이상 터치영역, VoiceOver 이름을 제공한다. 태그는 색 외에 아이콘/이름/체크로 구분한다. 입력 시 iOS 키보드와 safe area에 맞춰 시트/완료 버튼을 올린다. 확대 글꼴에서는 텍스트와 시트가 세로 확장/스크롤한다. 지도 출처/Apple attribution은 실제 MapKit UI에 유지한다.

## 검증과 한계
모든 36 화면의 노드 크기/부모 경계를 확인하고 그룹과 주요 화면을 렌더링했다. 최종 원본에는 이전 버전 이름의 프레임이 남아 있지 않음을 확인했다. 브라우저 모션 검증은 MOTION.md를 참고한다.

이 산출물은 편집 가능한 UI 시안과 모션 데모다. 생성 지도 이미지이며 실제 MapKit 출력이 아니다. 노선·정류장·시간·거리 값은 검증되지 않은 디자인 예시다. 실제 iOS 앱, 알림/기록 저장/기기 터치/카메라 품질은 구현 후 검증해야 한다.

참고: [FocusFlight](https://apps.apple.com/us/app/focusflight-deepfocus-timer/id6648771147), [시간 선택 공개 영상](https://60fps.design/shots/focusflight-duration-slider-swipe-interaction). 사용자의 DESIGN-spacex.md를 시각 방향 자료로 사용했다. 최종의 검정/흰색/큰 숫자/얇은 경계에 적용했고 태그만 의미 색상을 쓴다.

### 시간 선택기 업데이트
FocusFlight의 공개 시간 선택 영상을 참고해 일반 슬라이더를 고정 중앙 포인터와 좌우로 움직이는 시간 눈금으로 교체했다. 하단 카드에는 같은 버스로 해당 시간에 도착하는 정류장, 정류장 수, 거리를 표시한다. Pen·개별 화면 05·전체 흐름·PDF·모션 미리보기에 동일하게 반영했다. 실제 FocusFlight 설치 앱의 전체 동작을 검증한 것은 아니다.

### 장시간 여정·승차 패스·집중 지도 업데이트
15분~6시간을 5분 간격으로 선택한다. 한 바퀴 이후에도 집중용 가상 순환으로 이어지며, 출발→도착 카드에 순환 횟수·정류장 수·km를 표시한다. 생성된 transit-card.png를 터치하면 짧은 태그 연출 후 집중을 시작한다. 지도에는 방향이 보이는 버스 상단 실루엣, 정류장 점, 다음 정류장 라벨, 최종 하차 마커를 적용했다. 실제 운행자료를 의미하지 않는다.

### 지도 추적과 최소 집중 화면
집중 중 지도·노선·버스 공통 레이어가 이동한다. 드래그/방향키로 자유 탐색, 버스 따라가기 버튼으로 추적 복귀, 전체 노선 버튼으로 원래 경로 뷰 복귀를 제공한다. 하단 HUD를 지도 위의 작은 잔여 정보로 줄이고 앱내 일시정지/재개를 추가했다. 실제 MapKit 자동추적 구현이 아닌 인터랙션 시안이다.

### 마지막 UI 수정 완료 — 2026-10-11
지도 추적과 전체 노선 제어는 44px 아이콘 버튼으로 표시하며 접근성 이름과 툴팁을 제공한다. 잔여 정보는 제목 행과 숫자 행을 정렬하고 단위를 분리했다. 지도 로딩/오류 시안도 같은 잔여 정보 배치로 맞췄다. 승차·하차는 카드 자체를 터치하거나 키보드로 활성화한다. 별도의 집중 시작/하차 버튼은 없다. 카드 터치 안내는 화면 진입마다 다시 시작하고, 태그 시 즉시 멈춘다. 하차 시안의 안내 링을 카드 앞 레이어로 옮겼다. 상세 검증은 QA.md를 참고한다.

### 메인 홈과 카드 안내 개선 — 2026-10-11
앱 시작 화면은 현재 정류장과 선택한 버스를 먼저 보여주는 메인 홈이다. 집중 여행 시작을 눌러 시간 선택으로 진입하고, 하차 후에는 도착 정류장을 현재 정류장으로 표시한 홈으로 돌아온다. 데모는 예시 2014번 가상 순환 노선을 사용한다. Pen 홈도 같은 시작 버튼 중심으로 정리했다.

카드 터치 안내는 노선 장식 위의 작은 점 대신 카드 중앙의 손가락 아이콘과 탭 링으로 표시한다. 카드 전체가 터치 영역임을 항상 보이는 문구로 안내한다. 최대 3회만 안내하고 동작 줄이기에서는 숨긴다.

### 참고 사이트의 제안 적용 — 2026-10-11
Componentry의 Flight Status Card에서 참고한 정보 위계로 출발·도착을 분리하고 시간·정류장·거리를 세 열로 정리했다. Wheel Carousel에서 참고한 관성·선택 스냅을 수평 시간 눈금에 적용했다. FocusFlight 하단 시트에서 참고한 정보 공개와 지도 맥락 유지 원칙으로 준비 화면과 경로 상세 전환을 다듬었다. React 라이브러리 설치 없이 기존 HTML 데모와 Pen 시안의 구조에 맞춰 구현했다.

### 홈 선택과 집중 안내 개선 — 2026-10-11
이전 HTML 버전은 홈에 인사말, 현재 정류장, 버스·태그 선택을 합쳤다. 이 구성은 시안과 달라 아래의 시작 흐름 정합 작업에서 대체한다. 선택한 버스와 태그는 시간 선택·탑승권·집중·완료 화면에 연결한다. 버스는 실제 운행 정보가 아닌 가상 여행 예시다. 하차 후 도착한 정류장에서 새 여행을 준비한다.

집중 중 현재 구간·다음 정류장·도착 정류장을 기본으로 보여준다. 전체 남은 경로는 보조 상세에서 확인한다. 카드 안내는 원 자체의 중앙 배치와 별도로 내부 손가락 그림의 실제 경계 중심을 맞춘다. 이 추가 개선은 HTML 프로토타입에 적용하며 기존 Pen·PDF는 이전 시안이다.

### 엣지케이스 수정 기록
정류장 경계 숫자, 새 집중의 일시정지 초기화, 자동 도착 포커스와 비활성 지도 노출을 수정했다. 좁은 화면·큰 문구·패널 넘침·작은 터치 영역·설명 대비·카드 이미지 실패도 보강했다. 재현과 검증은 `reports/prototype-edge-cases-2026-10-11.md`, 재실행 검사는 `scripts/prototype-edge-qa.cjs`에 보관한다. 이 변경은 HTML 기준이며 실제 브라우저 렌더링 확인은 접근 제한 해제 후 남아 있다.

### 시안 기준 시작 흐름 정합 — 2026-10-11
현재 HTML의 시작 흐름 기준은 `01-plan.png`의 첫 이용 → 정류장 검색 → 정류장 홈 → 시간 → 할 일 → 태그·소리 선택 → 탑승이다. 홈에는 상단 현재 정류장 카드와 지도 핀, 하단 방면 안내·버스 선택을 배치하고 태그는 별도 준비 화면에 둔다. 후속 요청으로 반대편 확인 단계는 제거하고 검색 결과에 정류장 이름과 방면을 표시한다. 출발 설정을 완료한 뒤 다시 열면 마지막 정류장의 홈을 표시하며 출발지 변경에서 검색을 다시 사용할 수 있다. 검색 취소, 태그 이름 검증과 첫 이용 재생도 연결한다. 태그 편집 저장 후에도 승차권으로 바로 이동한다. 세부 변경·검증은 `reports/prototype-design-alignment-2026-10-11.md`에 기록한다.

### 현재 여행 표현과 버스 안내
화면 문구는 여행을 중심으로 구성하고 시간 단위는 h / min을 사용한다. 자리 선택과 앱 내 음량 조절은 없다. 태그·소리는 한 화면에서 고른다. 버스는 유형 아이콘·번호·색을 함께 표시하며 경로 색도 같은 데이터에 연결한다. 서울알림체 Medium·Bold는 서울시 공식 배포 파일을 로컬로 사용하며 출처를 표시한다. 카드 이미지는 Next Step / Travel Pass로 갱신했다. `bus-guide.html`에서5개 유형과 서체를 비교할 수 있다. 공식 자료와 앱용 색상 선택값의 구분은 `reports/seoul-bus-visual-system-2026-10-11.md`를 참고한다.

### 여행 화면 간소화와 상단 지도 공간 — 2026-10-11
여행 중 큰 버스·태그 헤더와 중복 안내를 없애고 상단 제어, 왼쪽 세로 정류장 흐름, 아래쪽 남은 시간·정류장·거리로 정리했다. 지도 버스와 유형 배지는 공식 Lucide bus-front SVG 형태를 사용한다. 그만두기 확인 중 시간은 멈추고 취소 시 이전 상태로 복원하며, 종료는 완료 기록 없이 현재까지 도달한 정류장 홈으로 돌아간다. 홈 정류장 안내와 준비 화면 버스 헤더도 작게 줄였다. 변경·검증 기록은 `reports/travel-screen-refinement-2026-10-11.md`에 있다. HTML 기준이며 실제 화면 렌더링·터치는 접근 제한으로 미검증이다.

### 현재 준비 편집 흐름과 접힌 노선도 — 2026-10-11 후속 요청
이전의 태그·소리 저장 후 탑승 직행 규칙은 대체했다. 시간 다음에는 '버스에서 할 일' 허브를 표시한다. 새 여행의 할 일(태그)은 미선택이며 행을 눌러 태그와 할 일을 편집하고 돌아온다. 소리도 별도로 고른 뒤 돌아오며 초기값은 소리 없음이다. 허브의 완료만 탑승 패스로 연결한다. 태그 생성/편집 저장은 할 일 편집으로 복귀한다. 시간·탑승에서 뒤로 돌아오는 경우 이번 준비를 유지한다. 상세 기록: `reports/journey-preparation-flow-2026-10-11.md`.

여행 중 왼쪽 노선 목록은 기본 접힘이며 펼치기/접기로 지도 공간을 조절한다. 남은 시간은 h/min을 크게, 초는 작은 s 단위로 표시한다. 실제 FocusFlight 화면에서 검증되지 않은 배치를 그대로 복제했다고 주장하지 않으며 버스 여행에 맞춘 화면이다.

### FocusFlight 제공 이미지에 맞춘 진행 화면 — 2026-10-11
사용자가 제공한 실제 FocusFlight 진행/일시정지 이미지의 지도 중심 구성을 참고했다. 아래쪽 수치는 카드 없이 표시하고 시간은 좌측, 정류장 수는 가운데, 거리는 우측에 둔다. 좌상단 일시정지와 우상단 현위치·지도 도구를 분리한다. 포기하기는 멈춤 상태에서만 보인다. 노선은 작은 정류장 버튼으로 접고 펼친다.

지도 마커는 위에서 본 버스 차체이며 배경 사각형 없이 차체 자체에 노선 색을 적용한다. 따라가기에서는 버스가 중앙에서 위를 향하고 지도·경로가 회전/이동한다. 기존 전면 버스 마커/고정 지도 설명은 대체됐으며 유형 배지의 전면 아이콘은 유지한다. 기록과 검증은 `reports/heading-up-travel-ui-2026-10-11.md`에 있다. HTML 기준이며 실제 브라우저 픽셀/애니메이션은 미검증이다.

### 정류장 패널의 읽기 순서 개선
출발/최근 도달 정류장은 보조 표시, 다음 정류장은 노선 색으로 강조, 도착은 깃발로 구분한다. 목록은 현재→다음→중간→도착 순서다. 남은 이동이 1개일 때만 다음과 도착을 합치며 순환 경로의 같은 이름은 이동 순번으로 구분한다. 좁은 패널과 중간 정류장 내부 스크롤로 지도의 가림을 줄였다. 상세: `reports/station-rail-refinement-2026-10-11.md`.

### 현재 태그·버스 선택과 고정 시트 — 2026-10-11
뒤로가기/닫기와 저장/완료를 고정하고 긴 내용만 내부 스크롤한다. 승차권은 카드 터치 영역도 하단에 고정했다. 메인 버스 선택은 별도 버스 목록에서 고르면 메인 미리보기로 돌아간다.

할 일(태그)을 누르면 먼저 태그 목록이 열리고 선택 즉시 할 일 입력으로 이어진다. 최근 예시는 제거했다. 새 태그는 이름·실제 아이콘 5개·색 견본 5개와 미리보기만 사용하고 기본 여행 시간은 제거했다. 허브 완료만 승차권으로 이동한다. 변경/검증: `reports/preparation-sheet-cleanup-2026-10-11.md`. 현재 15장면 QA·구문/독립 검증 PASS이며 실제 작은 화면 렌더링은 미검증이다.

### 최소 승차권·선택 전용 태그·사전 합성 소리
태그 목록은 선택과 새로 만들기만 제공한다. 승차권은 번호·출발/도착·시간/정류장/거리와 카드만 표시하고 태그·할 일·소리·탑승 준비 장식을 없앴다. 입력 강조를 안쪽 테두리로 바꿔 내부 스크롤 경계의 잘림을 줄였다. 정류장 펼침 아이콘은 왼쪽에 위치한다.

백색소음·창문 빗소리·숲·버스 엔진의 24초 합성 WAV를 선택·미리듣고 여행 중 반복한다. 현장 녹음이나 외부 AI 생성 모델의 결과가 아닌 DSP 시안이다. 자산 출처는 `assets/audio/SOURCE.md`, 수정·검증은 `reports/layout-pass-and-audio-2026-10-11.md`에 기록했다. 상태·파일·비동기 회귀 PASS이며 실제 화면·청취는 미검증이다.


### 지도 안전영역·경로 미리보기 후속 수정 — 2026-10-11
정류장 버튼은 일시정지 바로 아래에 두고 남은 시간은 총 min만 표시한다. 도착 화면은 도착·역명·하차 카드로 줄였다. 시간 선택은 작은 시트와 독립 경로 이동 미리보기로 바꾸고 선택 경로 색은 미리보기 뒤에도 유지한다. 승차권은 출발/도착 2열과 수치 3열을 균등 정렬하며 화살표를 제거했다. 각 화면의 실제 패널 영역을 측정해 노선이 남은 지도 공간에 들어오도록 조정한다. 소리는 5dB 낮추고 고주파·충격음을 줄여 재생성했다. 상세 기록: reports/map-safe-area-and-route-preview-2026-10-11.md. 현재 남은 시간의 min 전용 표기는 이전 h/min+초 표시 설명을 대체한다.


### 첫 메인·한 바퀴 미리보기·첫 출발지 전용 설정 — 2026-10-11
첫 화면은 지도·현재 위치 핀·기록/설정 아이콘·여행 시작하기로 구성한다. 시작하면 현재 정류장·버스 화면을 열며 첫 이용만 출발지 검색을 거친다. 현재 정류장에서 다른 위치로 이동하거나 설정에서 출발지를 재설정할 수 없다. 하차·포기 후 저장 위치가 반영된 메인으로 돌아간다. 외부 첫 이용 재생은 데모로 표시한다. 시간 미리보기는 선택 시간과 무관한 12초 등속 한 바퀴다. 승차권은 노선 색 버스 아이콘 배지를 사용하고 일시정지 우측에는 빨간 X 포기만 표시한다. 현재 규칙은 이전 재실행 홈 진입/출발지 변경 설명을 대체한다.
