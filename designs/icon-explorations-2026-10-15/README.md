# Focus Mate 아이콘 탐색 · 2026-10-15

미확정 디자인 시안이다. 앱 아이콘 카탈로그에는 적용하지 않았다.

## 참고 분석

[FocusFlight 공식 App Store](https://apps.apple.com/us/app/focusflight-deepfocus-timer/id6648771147)의 실제 아이콘을 브라우저에서 확인했다. 밝은 바탕, 검은 사다리꼴 단일 심볼, 넓은 여백, 절제된 음영이 관찰된다. 활주로·창을 연상시킨다는 설명은 디자인 해석이다. 이를 단순한 실루엣·제한된 색·여백이라는 원칙으로 참고하고 우리 앱은 독립된 모티프로 제작했다.

## 방향

| 파일 접두사 | 의미 | 평가 |
|---|---|---|
| 01-portal | 집중에 들어가는 입구 | 차분하고 명확하지만 문·보안 앱으로도 읽힐 수 있다 |
| 02-route | 목적지로 이어지는 길 | 우선 추천. 여정과 진행을 함께 표현한다 |
| 03-arrival | 한 세션의 완주 | 집중 도구로 읽히기 쉽지만 일반적인 진행 링과 비슷하다 |
| 04-companion | 함께 가는 두 경로 | Mate의 친근함을 강조하지만 문자 m으로 읽힐 수 있다 |

## 산출물과 도구

- `*-generated.png`: 내장 이미지 생성 도구로 만든 각 방향의 독립 시안 4개.
- `*.svg`, `*-vector.png`: Figma 플러그인으로 다시 구성한 편집 가능 벡터 4개와 1024px PNG. 생성 이미지와 동일한 파일의 변환본이 아니라 같은 방향의 별도 벡터 해석이다.
- `comparison-board.png`: 벡터 버전 256px·64px·32px 비교. 작은 크기에서 형태를 육안으로 확인했다.
- `prompts.json`: 각 생성 방향의 프롬프트. 공통 조건은 단일 추상 심볼, 넓은 여백, 작은 크기 가독성, 버스·비행기·문자·목업 제외, 평면 색채다. 생성 결과에는 미세한 음영이 남아 평면 버전을 Figma로 별도 제작했다.
- [Figma 편집 파일](https://www.figma.com/design/wWLPPgn2n66zDNQ5DbVoj7?node-id=2-2)

Pencil은 Transport closed로 사용 불가였다. 추가 외부 플러그인은 설치하지 않았다. 상표 유사성 조사와 실제 홈 화면 적용 검증은 수행하지 않았다.
