# Focus Mate 창문 아이콘 고도화와 런치 동작 시안

사용자가 고른 25·26·30을 같은 흑백 원칙으로 정리했다. 바깥 프레임은 40 단위, 안쪽 레일은 24 단위로 구분하고 여백·모서리·작은 손잡이를 다듬었다.

## 파일

- `icon-25/26/30-generated.png`: 직전 생성 시안을 참조 이미지로 입력해 내장 이미지 생성 도구로 고도화한 결과 3개.
- `icon-25/26/30.svg/png`: 별도로 정리한 균일한 벡터와 1024px PNG. 검은 바탕·흰 심볼.
- `icon-25/26/30-light.svg/png`: 흰 바탕·검은 심볼.
- `refined-comparison.svg/png`: 3종과 64px·32px 비교 보드.
- `splash-preview.html`: 3종을 고르고 재생·느리게·정지를 조작하는 독립 실행용 시안.
- `prompts.json`: 이미지 생성 편집에 사용한 전체 프롬프트.

생성 이미지와 벡터는 같은 방향의 별도 해석이며 세부 비율이 다르다. 스플래시의 첫 화면은 전환 확인용 시안이다.

## 동작

1. 180ms 정지.
2. 레일과 손잡이가 같은 방향으로 550ms 이동.
3. 창 프레임이 확대·페이드되며 450ms 동안 첫 화면으로 이어진다.

총 1.18초. 반복 루프는 없다. standalone은 진입 시 1회 자동 재생하고, 대화 안 시안은 버튼을 눌러 재생한다. 동작 줄이기는 슬라이드·확대를 생략하고 180ms 페이드로 대체한다. 재생 중 재선택·정지·동작 설정 변경 시 이전 애니메이션을 취소하고 초기 상태로 복원한다.

## 검증과 범위

정제한 벡터 3종의 비교 보드를 육안 확인했고 HTML 두 시안의 JavaScript 구문, DOM 조회 대상, 애니메이션 취소 경로를 검사했다. 네트워크 요청과 외부 스크립트 의존성은 없다.

파일 URL은 브라우저 정책으로 차단돼 브라우저 자동 시각·상호작용 검증은 수행하지 못했다. 다른 URL·브라우저로 우회하지 않았다.

아이콘 기본형과 실제 iOS 연결 여부는 사용자 선택 질문에 답변을 받지 못해, 안내한 기본값(26번 중심의 움직이는 시안)으로 제작했다. iOS 앱 소스, AppIcon 카탈로그, OS 런치 화면은 변경하지 않았고 네이티브 구현·검증 완료를 주장하지 않는다. 실제 연결 시 OS 정적 런치 화면에서 앱 내부 스플래시로 자연스럽게 이어져야 하며 앱 시작 데이터 로드를 지연시키면 안 된다.
