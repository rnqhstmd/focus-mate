# Focus Mate 추가 아이콘 10종

기존 01~04에 이어지는 05~14 탐색 시안이다. 앱에 적용하지 않았다.

| 번호 | 방향 | 의미 |
|---|---|---|
| 05 | Ticket | 집중을 시작하는 작은 약속, 승차권 |
| 06 | Window | 고요한 창과 수평선 |
| 07 | Station | 다시 시작하는 정류장 |
| 08 | Interval | 한 구간의 시간, 모래시계 |
| 09 | Focus | 한 가지에 주의를 모으기 |
| 10 | Bearing | 나만의 방향, 나침반 바늘 |
| 11 | Moment | 의미 있는 시간을 간직하는 책갈피 |
| 12 | Grow | 매일 쌓이는 작은 성장 |
| 13 | Next | 한 구간씩 앞으로 나아가기 |
| 14 | Unfold | 펼쳐지는 지도와 집중의 시간 |

이미지 생성 도구의 독립 이미지 10종과 Figma 플러그인으로 만든 벡터 해석 10종을 제공한다. 생성 이미지와 벡터는 별도 해석이며 세부 비율·색이 다를 수 있다.

- `*-generated.png`: 이미지 생성 시안
- `*.svg`, `*-vector.png`: 편집 가능한 SVG와 1024px PNG
- `comparison-board.png`: 벡터 시안 216px·64px·32px 비교
- `prompts.json`: 생성 프롬프트
- [Figma 두 번째 보드](https://www.figma.com/design/wWLPPgn2n66zDNQ5DbVoj7?node-id=5-2)

추천 후보는 06(여정의 분위기), 09(집중의 명료함), 11(간결한 브랜드 형태)이다. 05는 티켓·입장 앱, 10은 지도 앱, 12는 습관 앱, 13은 분석 앱으로 읽힐 가능성이 있어 브랜드 선택 시 고려한다.

작은 크기 비교를 육안으로 확인했다. 실제 홈 화면 적용과 상표 유사성 조사는 수행하지 않았다.
