# Focus Mate 티켓·창밖 흑백 탐색 10종

사용자가 선택한 티켓·창밖 두 모티프로 좁힌 15~24 시안이다. SVG는 순수 검정(#000000)과 흰색(#FFFFFF)만 사용한다. 앱에는 적용하지 않았다.

| 번호 | 방향 |
|---|---|
| 15 | 중앙 슬롯이 있는 기본 티켓 |
| 16 | 작은 경로가 들어간 티켓 |
| 17 | 겹친 두 장의 티켓 |
| 18 | 세로형 패스 |
| 19 | 창 모양을 품은 티켓 |
| 20 | 해와 수평선이 있는 세로 창 |
| 21 | 흰 면과 검은 여백으로 표현한 창 |
| 22 | 넓은 가로 창과 수평선 |
| 23 | 나란히 놓인 두 창 |
| 24 | 아래가 열린 아치 창 |

- `*-generated.png`: 내장 이미지 생성 도구로 만든 독립 시안 10개.
- `*.svg`: 같은 방향으로 Figma 플러그인에서 별도 구성한 편집 가능한 벡터 10개.
- `comparison-board.png`: 벡터 버전 216px·64px·32px 비교.
- `prompts.json`: 각 생성 시안에 사용한 전체 프롬프트.
- [Figma 세 번째 보드](https://www.figma.com/design/wWLPPgn2n66zDNQ5DbVoj7?node-id=8-2)

생성 이미지와 SVG는 같은 방향의 별도 해석이므로 모서리·비율·선 두께가 다르다. Figma 보드 생성 후 Starter MCP 호출 한도에 도달하여 개별 벡터 PNG 내보내기는 수행하지 못했다. 생성 PNG와 SVG 원본 및 비교 보드는 로컬에 보존했다.

추천은 간결한 티켓 15와 창밖 20이다. 16·19는 복합 의미를 담지만 작은 크기에서 내부 요소가 덜 선명하다. 21은 유령 같은 형태로도 읽힐 수 있다. 실제 홈 화면 적용 검증은 수행하지 않았다.
