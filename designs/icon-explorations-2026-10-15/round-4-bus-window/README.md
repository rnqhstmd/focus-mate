# Focus Mate 실제 버스 창문 구조 탐색

해·들판·수평선 없이 창문 자체의 형태와 잠금 손잡이로 만든 흑백 10종(25~34)이다. 앱에는 적용하지 않았다.

## 실제 사진에서 확인한 형태

- [Bus Depot 미닫이 창문](https://www.busdepot.com/j11584): 가로로 긴 둥근 사각 프레임, 비대칭 두 유리판, 세로 겹침선, 가장자리의 짧은 손잡이. 제품 사진을 브라우저에서 직접 확인했다.
- [Fautras 미닫이 잠금 손잡이](https://boutique.fautras.com/hublots-baies-aerateurs-grilles-lanterneaux-de-toit/3741-bouton-baie-coulissante.html): 차량 창문 프레임 가장자리에 붙은 작은 잠금 레버. 제품 사진을 브라우저에서 직접 확인했다. 이 제품이 버스 전용이라는 주장은 하지 않는다.
- 상단 환기창·기울어진 코치 창·손잡이 단독 확대는 구조를 바탕으로 넓힌 디자인 탐색이다.

| 번호 | 방향 |
|---|---|
| 25 | 기본 가로 미닫이 창, 가장자리 손잡이 |
| 26 | 비대칭 유리판, 겹침선에 붙은 손잡이 |
| 27 | 상단 환기창 |
| 28 | 최소 프레임과 L자 잠금 탭 |
| 29 | 살짝 열린 미닫이 구조 |
| 30 | 기울어진 코치 창 |
| 31 | 잠금 손잡이 단독 심볼 |
| 32 | 창문 모서리와 손잡이 |
| 33 | 두 유리판과 중앙 그립 |
| 34 | 상단 작은 슬라이더 |

- `*-generated.png`: 내장 이미지 생성으로 제작한 독립 시안 10개.
- `*.svg`, `*-vector.png`: 같은 방향의 별도 벡터 해석과 1024px PNG.
- `comparison-board.svg/png`: 벡터 10종 및 64px·32px 비교.
- `prompts.json`: 생성 이미지에 사용한 전체 프롬프트.

생성 이미지와 벡터의 비율·손잡이 위치는 다를 수 있다. 사진은 관찰·분석에만 썼으며 생성 도구에 원본 이미지로 입력하지 않았다. 원본 사진의 복제가 아니라 관찰된 형태를 설명한 새 디자인이다. Figma는 기존 호출 한도 때문에 이번 보드를 추가하지 않았고 벡터를 로컬에 보존했다.

우선 비교 후보는 25·26(버스 창문 구조), 28(간결함), 30(특징 있는 실루엣)이다. 31은 창문보다는 잠금장치, 32는 문자처럼 읽힐 수 있다. 실제 홈 화면 적용 검증은 수행하지 않았다.
