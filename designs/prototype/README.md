# 앱 흐름 프로토타입

상세 조사 보고서의 개선안을 반영한 인터랙티브 프로토타입이다. 최신 `designs/final/animation-preview.html` 및 Pen 개선 시안과 같은 제품 규칙을 사용한다. 18개 제품 장면과 42개 화면 상태가 있다. 과거 36개 시안 뷰어는 `archive-36/`에 보존했다.

웹 화면은 실제 HTML 버튼·입력·SVG 지도와 여행 상태로 동작한다. 태그 후 할 일 입력, 미리보기 취소, 카드 승하차, 멈춤·종료·기록·메모와 오류 복구가 연결돼 있다.

## 체험

[프로토타입](https://next-step-app-flow.sqisoft-3053.chatgpt.site)

폰 바깥의 **앱 흐름 자동 재생**은 주요 여정을 순서대로 보여준다. 직접 체험하려면 폰 안의 버튼을 누른다. **화면 모아보기**에서는 설정·오류·예외 상태까지 확인할 수 있다. 자동 재생 중 폰을 조작하면 재생이 멈춘다.

```text
처음 한 번 집중동행카드 발급 → 출발 정류장 검색
→ 분 단위 시간 → 버스·도착 정류장 선택 → 준비 허브에서 태그·할 일 → 승차권 → 카드 탑승
→ 집중 여행 → 일시정지·재개 / 경로 상세
→ 도착 → 카드 하차 → 한 일 요약·선택 메모 → 메인 → 여행 기록·분석
```

출발 정류장은 첫 이용에서만 선택한다. 이후 이전 여행의 도착지에서 이어 시작한다. 15~360분 눈금으로 시간을 먼저 고른 뒤 해당 분에 맞는 버스·도착지를 선택한다. 시간 바로가기 카드는 없으며 후보가 없으면 준비로 진행할 수 없다. 시간·태그·할 일·선택 소리를 바꿀 수 있고 좌석 선택은 없다. 첫 이용·현재 정류장·방향과 완료 기록·메모를 이 브라우저에 저장해 다시 열면 복원한다. 기록은 시간 합계에 따른 연간 색 잔디와 날짜별 목록으로 확인한다. 시연용 예시 기록과 자동 재생의 도착은 실제 기록을 저장하지 않는다. 새 태그 정의는 이번 미리보기 세션 범위다. 여행은 30초로 압축하며 지도·노선은 예시다. CC0 핑크 노이즈 샘플과 실제 빗소리·숲·버스 차내 녹음을 편집해 사용한다. [음원 출처](../final/assets/audio/SOURCE.md)를 함께 보존한다.

## 로컬 실행

```powershell
python -m http.server 8796 --bind 127.0.0.1 --directory designs/prototype
```

브라우저에서 http://127.0.0.1:8796 을 연다. `scripts/build-flow-prototype.py`는 최신 HTML·시연 컨트롤·폰트·지도·카드·소리를 이 폴더와 Sites의 `dist/`로 묶는다.

최신 전체 검증은 [최종 검수 보고서](../../reports/full-ui-flow-review-2026-10-12.md)에 기록했다. 42개 상태를 402×874 및 실제 반응형 320×568 뷰포트에서 검사했고 12개 브라우저 검사와 상태 회귀 검사를 통과했다. 실제 iPhone의 키보드·햅틱·MapKit과 소리 청취 품질은 검증 범위에 포함하지 않는다.

[여행 기록 달력 검증](../../reports/records-calendar-2026-10-12.md)은 누적 기록·메모 저장, 날짜 이동과 작은 화면을 직접 검사했다.

하차 후 홈에서 선택 메모를 바로 남기거나 건너뛰고 다음 여행을 시작한다. 기록 화면의 분석 탭은 완료 여행의 태그별 시간 비중·주간/월간 활동·이전 기간 비교를 제공하며 각 최근 여행의 기록으로 연결한다.

[시간 우선 흐름 검증](../../reports/minute-first-journey-2026-10-12.md): 1분 입력, 3,096개 유효 후보, 실제 승하차·기록 연결과 다섯 화면 크기를 직접 확인했다.

기록 탭의 잔디는 GitHub 참고 형태로 연간 주×요일 격자·월 라벨·연도 선택·확대·날짜 찾기를 제공합니다. [변경과 검증](../../reports/github-activity-heatmap-2026-10-12.md).

시간 선택에서는 후보 개수와 중복 경로·거리 요약을 제거했다. 여러 버스·도착지 카드는 다음 카드 일부가 보이는 가로 스크롤로 고른다. 선택한 카드가 온전히 보이고 시간을 바꾸면 첫 카드로 돌아온다.

시작하기 한 번으로 저장된 출발 정류장의 시간 선택을 엽니다. 첫 정류장 확인도 바로 시간 선택에 이어지고, 이후 기록·분석에서 다음 여행을 시작할 때 같은 경로를 사용합니다. 갤러리의 출발 정류장 화면은 같은 시간 선택의 초기 상태이며 별도 확인 버튼이 없습니다.

Focus Mate의 기본 카드는 검정입니다. 마이페이지 → 카드 꾸미기에서 배경색·여러 사진·이동·크기를 조절하고 기기에 저장합니다. IC 칩은 고정되고 사진은 카드 안에서 잘리며 승하차·검은 LCD에도 저장한 디자인을 씁니다. 일시정지 후 앱을 닫아도 메인에서 이전 여정을 이어갈 수 있습니다. 최신 검증은 [카드 발급·검은 단말기](../../reports/focus-mate-card-and-reader-2026-10-12.md)와 [카드 꾸미기](../../reports/card-customization-2026-10-12.md)입니다.
