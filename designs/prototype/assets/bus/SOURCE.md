# 버스 아이콘

2026-10-11부터 bus-front.svg와 5개 유형별 배지는 Lucide 공식 bus-front 형태를 사용한다. 지도 마커도 같은 정면 형태이며 선택 버스 색상으로 배경을 바꾼다. 유형별 색상은 앱에서 고른 토큰으로 서울시 공식 RGB 또는 공식 아이콘을 복제했다고 주장하지 않는다.

원본: https://lucide.dev/icons/bus-front
SVG: https://github.com/lucide-icons/lucide/blob/main/icons/bus-front.svg
라이선스: https://github.com/lucide-icons/lucide/blob/main/LICENSE

원문은 LUCIDE-LICENSE.txt에 보관한다. 다운로드 날짜: 2026-10-11. 배지의 배경·크기·색상은 앱에 맞게 조정했다.

후속 변경: 지도 이동 마커는 사용자의 위에서 본 버스 요청에 따라 앱에서 만든 SVG 차체로 교체했다. 별도의 사각 배경 없이 선택 노선색을 차체 fill에 적용한다. 이 마커는 Lucide bus-front 원본이라고 표시하지 않는다. 위의 Lucide 출처는 다른 화면의 5개 유형 배지와 bus-front.svg에 해당한다.
