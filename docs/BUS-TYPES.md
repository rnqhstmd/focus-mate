# 버스 유형과 색상

기준일: 2026-10-13. iOS 개발(Phase 2 시간·버스 선택부터)에서 버스 번호 배지·지도 경로·버스 마커에 쓰는 유형별 색상을 정한다.

## 원칙

- **색상은 앱이 정한 값이다.** 서울시 공공데이터에는 노선 유형만 있고 색상 값이 없다. 간선=파랑·지선=초록·순환=노랑·광역=빨강은 서울시 안내의 색 체계를 따르지만, 아래 HEX는 서울시 공식 RGB가 아니며 공식 색이라고 표기하지 않는다.
- 값의 원본은 [`designs/final/assets/bus/tokens.json`](../designs/final/assets/bus/tokens.json)이다. iOS는 이 파일과 같은 값을 쓰고, 바꿀 때는 이 문서와 토큰 파일을 함께 고친다.
- 색만으로 유형을 구분하지 않는다. 배지에 유형 이름(간선·지선 등)을 함께 제공하고 VoiceOver 라벨에 포함한다.

## 색상표

| 앱 유형(`type`) | 표시 이름 | 배경(`color`) | 글자(`foreground`) | 예시 번호 |
|---|---|---|---|---|
| `trunk` | 간선 | `#2563EB` 파랑 | `#FFFFFF` | 343 |
| `branch` | 지선 | `#168445` 초록 | `#FFFFFF` | 2014 |
| `village` | 마을 | `#B5D532` 연두 | `#101410` | 강남02 |
| `circular` | 순환 | `#F2C94C` 노랑 | `#16130B` | 01A |
| `express` | 광역 | `#D13A42` 빨강 | `#FFFFFF` | 9401 |

마을·순환은 밝은 배경이라 어두운 글자를 쓴다. 다크 화면 위 대비와 큰 글자 표시는 Phase 2 화면 구현 때 확인한다.

## 실제 노선 데이터와의 연결 (미확정)

실제 서울 노선 데이터를 쓸지는 아직 결정하지 않았다([MVP](MVP.md)는 가상 정류장 기준). 쓰게 되면 [버스 노선 정보 API(OA-1095)](https://data.seoul.go.kr/dataList/OA-1095/S/1/datasetView.do)의 노선 유형 코드를 위 앱 유형으로 바꾸는 표가 필요하다.

| 확인할 것 | 상태 |
|---|---|
| API 노선 유형 코드(숫자)와 이름의 대응 | ❓ OA-1095 활용가이드에서 확인 필요 |
| 공항·인천·경기·폐지·공용·심야(N) 등 위 5종 밖의 유형 처리 | ❓ 제외할지, 별도 색을 줄지 결정 필요 |
| 같은 노선이 여러 유형 표기를 가질 때 | ❓ |

확인 전에는 코드를 추정해 매핑하지 않는다.
