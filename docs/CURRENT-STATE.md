# 현재 상태

기준일: 2026-10-12. 앱 이름은 **Focus Mate**, 발급 카드 이름은 **집중동행카드**입니다. 최신 실행 기준은 [animation-preview.html](../designs/final/animation-preview.html)입니다. 현재 기능 범위는 [MVP](MVP.md), 화면·성공·취소·저장 계약은 [FLOWS](FLOWS.md)를 봅니다. 과거 PNG/PDF·보고서의 이전 기본값과 흐름을 최신 구현으로 해석하지 않습니다.

## 현재 제품 흐름

첫 이용은 카드 1회 발급 → 출발 정류장 검색 → 시간 선택입니다. 이후에는 현재 정류장 메인에서 시작 한 번으로 시간·버스·도착지 선택 → 준비 허브 → 승차권 → 승차 태그 → 여행 → 하차 태그 → 요약·선택 메모 → 메인으로 이어집니다. 기록·분석·마이페이지·카드 꾸미기는 메인에서 접근합니다. 첫 설정 뒤 앱 안에서 출발지를 다시 검색하거나 초기화하지 않습니다. 마지막 도달/도착 정류장이 다음 여행의 출발지가 됩니다. 외부 첫 이용 시연은 제품과 분리합니다.

제품 18개 논리 장면, 코드 회귀 21개 장면, Pen 42개 화면 상태를 유지합니다. 코드의 이전 소개·출발 안내·버스 목록은 제품 경로가 아닌 회귀/시연용입니다.

## 구현된 프로토타입

- 시간은 15~360 min을 1분 눈금으로 먼저 고릅니다. 정확히 맞는 가상 버스·도착지 후보를 직접 선택해야 준비로 진행합니다. 시간 변경은 기존 후보 선택을 해제합니다. 한 바퀴 미리보기는 선택 시간과 독립된 12초 누적거리 등속 이동이며 실제 여행·기록·소리를 바꾸지 않습니다.
- 준비 허브의 태그는 미선택으로 시작합니다. 태그를 고르면 할 일 입력이 같은 화면에 펼쳐지고 새 태그·소리 편집 왕복에서 초안이 유지됩니다. 미완성 준비로 승차할 수 없습니다.
- 버스(기본값)·비 오는 버스·지하철·숲속·소리 없음, 미리듣기·반복·시작/중지 페이드·재생 복구를 제공합니다. 현재 파일과 라이선스는 [오디오 SOURCE](../designs/final/assets/audio/SOURCE.md)를 기준으로 합니다. 오디오 청취 품질 검증과 파일/상태 검증은 별개입니다.
- 지도는 생성 이미지와 가상 코스입니다. 선택 색상 경로, 따라가기·자유 탐색·접힌 정류장 목록을 제공합니다. 여행 시간은 실제 선택 분을 **30초로 압축한 시연**입니다. 남은 시간은 총 min으로 표시합니다.
- 승차권은 점묘 서울 지도 질감의 티켓 카드(바코드 없음)이고, 출발·도착 안내는 전체 화면 그라데이션 위에 문구를 하나씩 보여준 뒤 시작/확인 버튼을 띄운다. 태그 성공 시 LCD에는 카드 이름과 체크만 나온다. 준비 허브는 ‘무엇을 할까요?’ 제목, 태그 색 알약 칩(가로 스크롤)과 + 칩, 한 줄 할 일 입력, 하단 소리 칩으로 구성하고 설명 문구를 두지 않는다([준비 허브·여행 소리](FLOWS.md#준비-허브여행-소리--2026-10-13-3차)).
- 승하차 태그 화면은 카드 크기에 가까운 단말기와 카드만 보여준다. 카드를 태그 영역에 30% 이상 겹치면 놓기 전에 진동과 함께 인식하고, 카드는 그 자리에 남는다([승하차 태그 화면](FLOWS.md#승하차-태그-화면--2026-10-13-갱신)).
- 여행이 끝나면 도착 안내(‘곧 ○○에 도착합니다 · 버스가 멈추면 일어나주세요 · 카드를 찍고 내려주세요’)를 보여주고, 확인해야 하차 태그로 간다.
- 승차 인식 뒤 여행 화면에서 ‘문을 닫습니다 · 자리에 앉아주세요 · 버스 출발합니다’ 출발 안내를 보여주고, 확인을 눌러야 버스가 움직이고 남은 시간이 줄어든다([출발 안내](FLOWS.md#출발-안내--2026-10-13)).
- 집중 화면 오른쪽 지도 도구는 버스 따라가기(위)와 지도 테마(아래) 동그란 버튼 두 개다(2D/3D·나침반·전체 노선 제거). 지도 테마는 어두운 지도/위성(생성 지도에 색 필터를 씌운 시연)과 정류장 표시를 바꾸며 저장하지 않는다. 하단 남은 시간·정류장·거리는 좌우 끝 정렬, 큰 흰색 숫자와 작은 회색 라벨·단위로 표시한다([화면 계약](FLOWS.md#집중-화면-지도-도구와-하단-정보--2026-10-13)).
- 일시정지에서는 지도 도구 대신 우상단 빨간 포기 버튼과 정지 상태를 표시합니다. 현재 정류장으로 돌아가도 여정은 남고 메인에서 수동 재개합니다. 포기는 확인 후 도달 정류장을 저장하고 완료 기록 없이 재개 정보를 제거합니다.
- 승차는 중앙 단말기·카드만으로 안내합니다. 외부 제목·출발지·상단 표기·뒤로가기·별도 수동 태그 버튼은 표시하지 않습니다. 카드 드래그·터치·키보드는 유지합니다. LCD는 Focus Mate·실제 HH:mm·짧은 문구이고, 접촉 후 현재 카드 이름/ID를 보여줍니다(웹 기준. iOS는 이름과 체크만, 번호 비표시 — W04). 접촉 인식 시 재개 정보를 저장하고 **1400ms 인식 유지 + 450ms 페이드** 뒤 여행으로 전환합니다. 숨김·장면 이탈은 시각 전환을 취소하되 접촉 후 저장을 잃지 않습니다. [최신 승차 변경](../reports/boarding-reader-refinement-2026-10-12.md).
- 하차 접촉 성공에서만 완료 기록과 다음 출발지를 저장합니다. 요약·홈에서 200자 선택 메모를 남기고 기록에서 수정합니다. 연간 잔디는 하루 완료 시간 합계 5단계이며 개별 기록은 태그 색을 유지합니다. 날짜별 최신순 10개씩 보기·연도 탐색·확대·날짜 입력과 주간/월간·태그 분석을 제공합니다.
- 분석은 태그 도넛·지난 기간 비교에 더해 날짜 구간별 태그 누적 막대, 마친 시간대(새벽·오전·오후·저녁, 완료 3회 이상일 때), 자주 탄 노선 상위 3개, 여행 길이 분포, 기간 내 최장 연속일, 메모 회고를 보여준다. 모두 완료 기록만 쓰며 태그 필터를 따른다([시장 조사](../reports/analytics-market-research-2026-10-13.md)).
- 기본 카드는 서울 점묘 배경이고 카드 번호는 카드에 표시하지 않는다. 꾸민 카드는 IC 칩과 비접촉 표시만 고정이다.
- 마이페이지에서 같은 카드와 완료 여정·시간을 봅니다. 카드 배경색과 최대 6장 JPG/PNG/WebP 사진을 꾸미고 위치·크기·겹침·삭제·되돌리기를 제공합니다. IC 칩은 고정되고 사진은 카드 경계에서 잘립니다. 편집 취소 확인과 저장 실패 안내가 있습니다.

## 저장과 한계

카드·꾸미기·현재 정류장·기록·메모·진행 중 여정은 이 브라우저의 localStorage에 저장합니다. 접촉 성공 이후 백그라운드/종료는 여정을 정지·저장하고 앱 밖 시간을 더하지 않습니다. 메인에서 같은 진도를 수동 재개합니다. 하차 전 도착 상태도 복원합니다. 새 여정은 이전 여정 정리 여부를 확인합니다. 저장 실패/손상은 안내하며 예시 데이터는 실제 데이터와 분리합니다.

실제 GPS·실시간 버스 API·실제 경로·MapKit·선택 분 그대로의 네이티브 타이머·클라우드/기기 간 동기화는 현재 웹 구현에 없습니다. 네이티브 개발 범위와 후순위 구분은 [MVP](MVP.md)에 있습니다.

## iOS 카드 발급 — 2026-10-13 (W01)

첫 실행에서 "집중동행카드 발급받기"로 카드를 1회 발급한다. 카드 ID(`FM-`+숫자 8자리)와 발급 시각을 저장하고, 카드가 슬롯에서 나오는 연출(0.86초)과 함께 지원 기기에서 그라데이션 진동(약→강, 끝 탭) 1회를 낸다. 시스템 동작 줄이기는 연출만 생략하고 진동은 유지한다. 완료 화면은 "출발지 선택하기"를 누를 때까지 유지하며, 저장 실패 시 진행을 막고 "다시 발급받기"로 재시도한다. 발급됐지만 카드 정보가 없는 기존 저장 파일은 앱 시작 때 화면 없이 카드를 보충한다. 공통 카드 뷰는 서울 점묘·IC 칩·비접촉 표시·이름을 그리고 카드 번호는 어떤 화면에도 표시하지 않는다. iOS unit 113·UI 29 테스트를 통과했다. VoiceOver 장식 비노출·완료 후 포커스·실기기 진동 체감은 수동 확인 대기다. 승하차 카드 배치와 LCD 표시는 W04에서 이어진다.
