# 현재 상태

기준일: 2026-10-12. 최신 동작 기준은 [animation-preview.html](../designs/final/animation-preview.html)입니다. [조사 반영 개선](../reports/research-flow-improvements-2026-10-12.md)을 HTML·Pen·게시 프로토타입에 적용했습니다. 이전 PNG·PDF·모션 문서와 다른 부분은 이 문서와 최신 수정 보고서를 먼저 봅니다.

## 여행 흐름

첫 화면은 Focus Mate의 집중동행카드 발급입니다. 카드를 한 번 발급한 뒤 출발지 검색으로 바로 이어집니다. 이후에는 지도·현재 정류장·기록/마이페이지·여행 시작 버튼으로 구성한 메인에서 시작합니다. 이후에는 저장된 앱 속 정류장에서 이어 시작하며 앱 안에서 출발지를 다시 검색하거나 첫 이용을 초기화하지 않습니다. 외부 시연 컨트롤의 첫 이용 재생은 제품 흐름과 구분합니다.

지도 위에는 시간대 인사와 현재 동네의 짧은 문구가 있습니다. 하차 후 바뀐 정류장과 저장된 출발지에 맞춰 인사도 갱신합니다. 첫 이용은 동네를 정하기 전이므로 ‘오늘은 어디에서 출발해볼까요?’로 안내합니다. [동네 인사말](../reports/neighborhood-welcome-2026-10-12.md).

```text
첫 이용: 집중동행카드 발급 → 출발 정류장 검색 → 시간 선택
이후: 메인 시작 한 번 → 현재 정류장에서 시간·버스·도착지 선택
     → 여행 준비(태그·할 일·선택 소리) → 승차권 확인 → 버스에 탑승하기
     → 전체 화면 승차 태그 → 여행 → 도착 → 전체 화면 하차 태그
     → 한 일·시간 요약과 선택 메모 → 메인 / 기록·분석
```

제품에서 사용하는 18개 논리 장면: 메인, 카드 발급, 출발지 검색, 시간·버스·도착지 선택, 준비 허브, 태그 관리, 소리 선택, 태그 생성·편집, 승차권, 승차 태그, 여행, 하차 태그, 여행 요약, 기록, 분석, 마이페이지, 카드 꾸미기, 설정. 이전 소개·출발 안내와 버스 목록은 회귀 검사용 코드만 남아 있으며 제품 경로에는 없다. 별도 할 일 화면을 준비 허브로 통합했습니다. 성공·멈춤·오류 등을 포함해 Pen에는 42개 화면 상태가 있습니다.

## 현재 동작

- 시간은 15~360분을 1분 단위 눈금으로 먼저 선택합니다. 바로가기 시간 카드는 없습니다. 고른 분에 정확히 도착하는 가상 버스·정류장 조합을 카드로 표시하며 사용자가 선택하면 목적지·노선·승차권을 갱신합니다. 후보가 없거나 고르지 않은 상태에서는 다음 단계로 넘어갈 수 없습니다. 시간을 바꾸면 이전 선택을 해제합니다.
- 시간 화면은 분 눈금과 버스·도착지 카드에 집중합니다. 후보 개수와 중복 출발지→도착지·거리 요약은 표시하지 않으며, 카드가 여러 개면 좌우 스크롤로 선택합니다. **노선 한 바퀴 보기**는 선택 시간과 무관하게 12초 동안 일정 속도로 한 바퀴를 이동합니다. 실제 여행 진행값을 바꾸지 않으며 다른 장면이나 시간 변경에서 취소합니다. 버튼으로 다시 볼 수 있고, 동작 줄이기에서는 정적인 경로를 표시합니다.
- 준비 허브에서 태그를 고르면 같은 화면에 할 일 입력이 펼쳐집니다. 태그는 미리 선택하지 않습니다. 새 태그·소리 편집 후 초안이 유지되고 허브로 복귀합니다. 준비가 유효할 때만 ‘승차권 보기’로 확정합니다.
- 소리 없음과 핑크 노이즈·빗소리·숲·버스 주행의 4종 샘플을 선택할 수 있습니다. 빗소리·숲·버스는 CC0 현장 녹음 원본 기반이며 핑크 노이즈는 스튜디오 샘플입니다. 원래의 샘플레이트·채널을 유지하고 반복 연결 및 재생 시작/중지 페이드를 적용했습니다. 미리듣기와 여행 중 반복 재생을 제공합니다. [오디오 출처·측정](../designs/final/assets/audio/SOURCE.md).
- 여행은 시연을 위해 선택한 시간을 **30초로 압축**합니다. 지도 추적·자유 탐색·전체 노선·정류장 목록·일시정지/재개를 제공합니다.
- 일시정지에서는 지도 도구 대신 정지 상태와 우상단 포기 버튼을 표시합니다. 포기는 확인 후 지나온 마지막 정류장을 다음 출발지로 저장하며 완료 기록은 남기지 않습니다.
- 승차권은 여정과 할 일만 확인합니다. 버스에 탑승하기를 누르면 하단 카드와 단말기가 있는 전체 화면으로 바뀝니다. 카드를 단말기로 끌어 놓거나 터치·키보드로 태그하면 여행을 시작합니다. 잘못 놓거나 취소하면 출발하지 않습니다.
- 도착 후에는 동일한 전체 화면에서 하차 태그합니다. 성공 시점에만 완료 기록을 저장하고 그 정류장을 다음 출발지로 저장합니다. 한 일·여행 시간·도착 정류장 요약에서 200자 선택 메모를 남기고 여정을 마칩니다. 하차 후 홈의 ‘메모 남기기’에서 200자까지 줄바꿈 메모를 쓰거나 나중에 남길 수 있습니다. 저장한 메모는 해당 여행의 기록과 연결되고 다시 수정할 수 있습니다. 홈의 기록 확인에서 연간 잔디로 이동하고 날짜를 누르면 그날의 여행과 선택 메모를 봅니다. 연간 잔디의 초록색 5단계는 하루 여행 시간 합계이며 태그 색은 개별 기록에 표시합니다. 기록은 날짜별 최신순으로 10개씩 펼치고, 연도를 바꿔 탐색합니다. 1년 전체를 7개 요일 행과 주 단위 열로 표시하며, 작은 화면에서도 전체 연도를 봅니다. 확대하면 잔디만 가로로 스크롤하고 날짜 입력으로도 해당 기록을 찾습니다. 완료 기록·메모와 첫 이용 완료·현재 정류장·방향을 이 브라우저에 저장해 새로고침 후 복원합니다. 예시 기록은 실제 저장과 분리하며, 저장이 차단되거나 기존 데이터가 읽히지 않으면 상태를 안내하고 기존 데이터를 덮어쓰지 않습니다. 기기 간 동기화나 서버 저장은 제공하지 않습니다.
- 기록의 분석 탭에서 주간·월간 완료 여행 합계·횟수·활동일·평균 시간과 태그별 도넛, 날짜별 활동을 봅니다. 태그를 선택하면 활동과 최근 여행을 필터링하고 최근 여행을 눌러 해당 기록·메모로 이동합니다. 진행 중인 기간은 지난 기간의 같은 날짜 범위와 비교합니다. 완료 기록만 집계하며 예시 분석과 예시 하차 메모는 실제 저장 기록을 바꾸지 않습니다.
- 지도 실패는 다시 불러오기, 여행 중 소리 실패는 다시 재생·소리 없이 계속으로 복구합니다. 준비와 진도는 유지합니다.

## 검증 범위

[상태 회귀 검사](../scripts/prototype-edge-qa.cjs)는 장면 전환, 포커스, 지연 동작 취소, 여행 수치와 지도 계산 등을 검사합니다. [최종 전체 검수 보고서](../reports/full-ui-flow-review-2026-10-12.md)에 이번 직접 실행 결과가 있습니다. 12개 브라우저 검사와 42개 상태의 일반·작은 화면을 확인했습니다. 이 저장소를 내려받은 뒤의 결과는 다시 실행해 확인해야 합니다.

브라우저 렌더링과 클릭·키보드·휠 동작을 직접 검사했습니다. 실제 iPhone 터치·MapKit·실제 경로 데이터·오디오 청취 품질을 검증한 결과로 해석하지 않습니다. 생성 지도와 예시 노선은 실제 버스의 같은 정류장 경유·운행 시간·위치 정보를 의미하지 않습니다.

최근 기록 화면 변경과 직접 실행한 브라우저 검증은 [여행 기록 달력](../reports/records-calendar-2026-10-12.md)에 정리했습니다.

[여행 분석·하차 후 메모](../reports/analytics-and-alight-memo-2026-10-12.md)에 최신 변경과 직접 실행 결과를 기록했습니다.

[시간을 먼저 고르는 흐름](../reports/minute-first-journey-2026-10-12.md)에 분 단위 입력·후보 없음·다음 여행·작은 화면 검사 결과를 기록했습니다.

[GitHub 형태의 연간 잔디](../reports/github-activity-heatmap-2026-10-12.md)를 적용했습니다. 기존 월간 날짜 달력은 잔디로 대체하고 기록·메모·분석 연결을 유지했습니다.

[시작 한 번으로 출발](../reports/direct-start-journey-2026-10-12.md): 첫 이용만 정류장을 고르고 바로 시간 선택으로 이어집니다. 이후 메인·기록·분석의 여행 시작 버튼은 현재 정류장의 시간 선택을 바로 엽니다. 뒤로 가면 메인으로 돌아갑니다.

[전체 화면 승하차 태그와 여행 요약](../reports/fare-tag-and-journey-summary-2026-10-12.md)을 적용했습니다. 승차권 확인과 태그를 분리하고 하차 태그 뒤에 기록·선택 메모를 보여줍니다.

## 멈춘 여정 이어가기

승차 태그 이후의 여정은 남은 진도·버스·출발지와 방향·시간·할 일·태그 정의·선택 소리를 기기에 저장합니다. 일시정지하거나 앱이 백그라운드로 이동하면 진도를 멈추고 저장합니다. 앱을 다시 열면 메인에서 **이전 여정 이어가기**를 선택해 동일한 위치와 남은 시간부터 재개합니다. 앱 밖의 시간을 진도에 더하지 않으며 재입장 시 자동 재생하지 않습니다. 일시정지 화면의 **현재 정류장으로**도 여정을 남긴 채 메인으로 돌아갑니다. 새 여행은 이전 여정 정리 여부를 확인하고 시작합니다. 포기 또는 하차 태그 완료 시 복원 정보를 제거합니다. 도착했지만 하차 태그 전인 여정도 이어갈 수 있습니다. 저장이 차단되면 닫은 뒤의 복원을 보장하지 않는다는 상태를 표시하고, 잘못되거나 버전이 다른 데이터는 새 여행 정리를 선택하기 전까지 보존합니다. [구현·검증](../reports/journey-resume-2026-10-12.md).

## 집중동행카드와 검은 단말기

앱 표기는 **Focus Mate**, 카드 표기는 **집중동행카드**입니다. 처음 한 번 카드가 슬롯에서 나오는 발급 연출과 지원 기기의 짧은 진동을 제공합니다. 동일한 카드 번호를 승하차 카드와 단말기 화면에서 사용하며, 이후에는 재발급하지 않습니다. 기존 사용자는 저장된 위치·기록·진행 중인 여정을 유지한 채 카드가 준비됩니다. 단말기는 제공된 사진의 검은 본체·상단 표시창·하단 태그 영역 구조를 반영했고 **표시창도 검은색**으로 유지합니다. 안내 화살표는 두 번만 움직이고 조작을 시작하면 사라집니다. 카드를 태그하면 성공 신호와 함께 표시창에 같은 카드가 나타나며 지원 기기에서 진동을 요청합니다. 하차 기록과 승차 복원 정보는 성공 접촉 시점에 저장해 성공 연출 중 앱을 나가도 완료/재개 상태를 잃지 않습니다. 동작 줄이기에서는 공간 이동·진동 없이 상태 피드백을 유지합니다.

## 마이페이지와 카드 꾸미기

메인 우상단 마이페이지에서 내 집중동행카드와 완료 여정·함께한 시간을 봅니다. 카드 꾸미기에는 기본 검정과 배경색 선택, 여러 사진 추가·이동·크기 조절·겹침 순서·삭제·되돌리기가 있습니다. 사진은 둥근 카드 경계에서 잘리고 IC 칩은 고정됩니다. 카드 미리보기와 저장 버튼은 도구를 스크롤하는 동안에도 유지됩니다. 저장 전 취소를 확인하며 기본 카드로 되돌리는 변경도 취소할 수 있습니다. 사진은 최대 6장, JPG/PNG/WebP·파일당 8MB까지 받고 크기를 줄여 기기에 저장합니다. 저장한 모습은 승차·하차 카드와 검은 LCD의 작은 카드에 같이 적용합니다. 갤러리의 사진 카드는 실제 내 카드와 별도입니다. [구현과 검증](../reports/card-customization-2026-10-12.md).

## 최종 전체 검수 반영

화면 모아보기에서 첫 발급·출발지·오류를 체험해도 실제 저장 상태와 이어가는 여정을 바꾸지 않습니다. 지도 실패 안내는 기록·분석·마이페이지의 닫기와 탭을 가리지 않습니다. 카드 수정 취소 확인은 Escape·Tab·Shift+Tab과 포커스 복귀를 지원하며, 마이페이지와 카드 편집에서도 상태바·하단 홈 표시가 보입니다. 진행 중인 여정이 있을 때 기록·분석에서 다음 여행을 시작해도 정리 확인과 이어가기가 동작합니다.

최신 편집 파일은 [focus-mate.pen](../designs/focus-mate.pen)이며 참조 이미지를 함께 저장했습니다. [최종 검수](../reports/full-ui-flow-review-2026-10-12.md)의 검사 범위와 한계를 기준으로 확인합니다.
