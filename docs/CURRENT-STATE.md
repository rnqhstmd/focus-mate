# 현재 상태

기준일: 2026-10-11. 최신 동작 기준은 [animation-preview.html](../designs/final/animation-preview.html)입니다. 이전 PNG·PDF·모션 문서와 다른 부분은 이 문서와 최신 수정 보고서를 먼저 봅니다.

## 여행 흐름

첫 화면은 지도·현재 정류장·기록/설정·여행 시작 버튼으로 구성한 메인입니다. 처음 시작할 때만 소개와 출발지 검색을 거칩니다. 이후에는 저장된 앱 속 정류장에서 이어 시작하며 앱 안에서 출발지를 다시 검색하거나 첫 이용을 초기화하지 않습니다. 외부 시연 컨트롤의 첫 이용 재생은 제품 흐름과 구분합니다.

```text
메인 → 첫 이용 소개 → 출발 정류장 검색 → 현재 정류장·버스 선택
메인 → 현재 정류장·버스 선택 → 시간 선택 → 버스에서 할 일
     → 할 일·태그 / 소리 선택 → 준비 허브 복귀 → 완료 → 승차권
     → 카드 터치 → 여행 → 도착 → 카드 터치 하차 → 메인
```

16개 장면: 메인, 첫 이용, 현재 정류장, 출발지 검색, 버스 목록, 시간 선택, 준비 허브, 할 일, 태그 선택, 소리 선택, 태그 생성·편집, 승차권, 여행, 도착, 기록, 설정.

## 현재 동작

- 시간은 15분 이상~6시간 범위에서 버스별 예시 정류장 간격에 맞춰 선택합니다. 시간 눈금과 지도 목적지가 함께 갱신됩니다.
- 시간 선택의 경로 미리보기는 선택 시간과 무관하게 **12초 동안 일정 속도로 한 바퀴**를 이동합니다. 실제 여행 진행값을 바꾸지 않으며 다른 장면이나 시간 변경에서 취소합니다. 동작 줄이기에서는 정적인 경로를 표시합니다.
- 준비 허브에서 할 일·태그와 소리를 각각 편집하고 돌아옵니다. 태그는 미리 선택하지 않습니다. 할 일 준비를 완료해야 승차권으로 이동합니다.
- 소리 없음과 백색소음·창문 빗소리·숲·버스 주행의 4종 합성 시안을 선택할 수 있습니다. 미리듣기와 여행 중 반복 재생을 제공합니다. [오디오 출처·측정](../designs/final/assets/audio/SOURCE.md).
- 여행은 시연을 위해 선택한 시간을 **30초로 압축**합니다. 지도 추적·자유 탐색·전체 노선·정류장 목록·일시정지/재개를 제공합니다.
- 일시정지에서는 지도 도구 대신 정지 상태와 우상단 포기 버튼을 표시합니다. 포기는 확인 후 지나온 마지막 정류장을 다음 출발지로 저장하며 완료 기록은 남기지 않습니다.
- 정상 도착 후 하차하면 그 정류장을 다음 출발지로 저장합니다. localStorage에는 첫 이용 완료·현재 정류장·방향을 저장합니다. 기록·태그·진행 중 여행의 기기 간 동기화나 서버 저장은 제공하지 않습니다.

## 검증 범위

[상태 회귀 검사](../scripts/prototype-edge-qa.cjs)는 장면 전환, 포커스, 지연 동작 취소, 여행 수치와 지도 계산 등을 검사합니다. [최근 검증 보고서](../reports/one-lap-preview-and-first-station-2026-10-11.md)에 당시 직접 실행 결과가 있습니다. 이 저장소를 내려받은 뒤의 결과는 다시 실행해 확인해야 합니다.

실제 브라우저 렌더링·iPhone 터치·MapKit·실제 경로 데이터·오디오 청취 품질을 검증한 결과로 해석하지 않습니다. 생성 지도와 예시 노선은 실제 버스의 같은 정류장 경유·운행 시간·위치 정보를 의미하지 않습니다.
