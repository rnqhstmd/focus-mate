# Focus Mate 개발 phase

개발은 **총 7개 phase(0~6)**로 구분합니다. 현재 웹 프로토타입이 있으며 네이티브 Swift 구현은 모두 미착수입니다.

| Phase | 단계 | 범위 | 현재 상태 |
|---|---|---|---|
| 0 | 시안 기준선 | 현재 화면·흐름·저장 규칙 확정 | 진행 중 — [자료·연결 자동 검사 통과](PHASE-0-BASELINE.md), 승차/태그 중간 화면 확인 대기 |
| 1 | 앱 기반 | iOS 앱 구조·화면 전환·로컬 저장 | 미착수 |
| 2 | 카드·준비·승차 | 카드 발급·첫 정류장·시간/버스 선택·태그/할 일/소리·승차 태그 | 미착수 |
| 3 | 지도·타이머·재개 | 가상 코스 지도·실제 선택 시간·일시정지·여정 복원 | 미착수 |
| 4 | 하차·기록·분석 | 하차 태그·완료 기록·선택 메모·잔디·분석 | 미착수 |
| 5 | 꾸미기·설정 | 카드 사진/색 편집·마이페이지·동작/환경 설정 | 미착수 |
| 6 | QA·출시 | 실기기 화면·터치·접근성·오디오·저장/복원 검증과 출시 준비 | 미착수 |

Xcode 27.0 설치는 확인됐지만 라이선스 동의가 선행 조건입니다. 최소 iOS·시뮬레이터·서명/배포 정보·담당은 미정이며 출시일은 정하지 않았습니다.

현재 웹의 30초 압축 시연을 네이티브 완료로 간주하지 않습니다. 네이티브는 실제 선택 시간을 사용하며, 실제 GPS·실시간 버스 API·클라우드 동기화는 MVP 후순위입니다.

현재 기능과 한계는 [현재 상태](CURRENT-STATE.md), 제품 범위는 [MVP](MVP.md)를 봅니다.
