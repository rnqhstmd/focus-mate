# Focus Mate 개발 phase

개발은 **총 7개 phase(0~6)**로 구분합니다. 현재 웹 프로토타입과 Phase 1의 네이티브 앱 기반이 있으며, Phase 2~6 기능은 미착수입니다.

| Phase | 단계 | 범위 | 현재 상태 |
|---|---|---|---|
| 0 | 시안 기준선 | 현재 화면·흐름·저장 규칙 확정 | 진행 중 — [자료·연결 자동 검사 통과](PHASE-0-BASELINE.md), 승차/태그 중간 화면 확인 대기 |
| 1 | 앱 기반 | iOS 앱 구조·화면 전환·로컬 저장 | 완료·[PR #2 머지](https://github.com/rnqhstmd/next-step/pull/2) — 앱 기반·native26건·웹 회귀 및 인수 통과 |
| 2 | 카드·준비·승차 | 카드 발급·첫 정류장·시간/버스 선택·태그/할 일/소리·승차 태그 | 일시중단 — PRD18AC·검증 경계 승인, 설계 초안 완료; 독립 검토·구현 미완료. [재개 지점](../.dev/codex-feat-phase-2-card-boarding/RESUME.md) |
| 3 | 지도·타이머·재개 | 가상 코스 지도·실제 선택 시간·일시정지·여정 복원 | 미착수 |
| 4 | 하차·기록·분석 | 하차 태그·완료 기록·선택 메모·잔디·분석 | 미착수 |
| 5 | 꾸미기·설정 | 카드 사진/색 편집·마이페이지·동작/환경 설정 | 미착수 |
| 6 | QA·출시 | 실기기 화면·터치·접근성·오디오·저장/복원 검증과 출시 준비 | 미착수 |

Xcode 27.0 약관은 사용자가 동의했고 iOS 27 Simulator 실행을 확인했습니다. 작업 기준은 iOS 17 이상이며 출시 최소 버전·서명/배포 정보·담당·출시일은 미정입니다.

Phase 1은 사용자의 전체 과정 전환 요청에 따라 **PRD → 설계·테스트 가능성 검토 → RED·GREEN·REFACTOR → 요구사항·품질·보안 리뷰 → 검증·인수 → 커밋·PR**로 진행합니다. 표준 모델 프로파일과 승인된 앱 기반 범위는 유지합니다. 전체 과정은 개발 절차이며, Phase 2~6의 제품 기능을 Phase 1에 추가한다는 뜻은 아닙니다. 최소 iOS 17은 작업 기준으로 승인됐으며 출시 대상 버전은 아직 확정하지 않았습니다.

현재 웹의 30초 압축 시연을 네이티브 완료로 간주하지 않습니다. 네이티브는 실제 선택 시간을 사용하며, 실제 GPS·실시간 버스 API·클라우드 동기화는 MVP 후순위입니다.

현재 기능과 한계는 [현재 상태](CURRENT-STATE.md), 제품 범위는 [MVP](MVP.md)를 봅니다.
