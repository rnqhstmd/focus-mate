# 화면과 상태 계약

기준: 2026-10-12. 제품 경로는 18개 논리 장면, 코드 회귀 장면은 21개, Pen은 성공·중단·오류를 포함한 42개 상태입니다. 숫자는 서로 같은 분류가 아닙니다. 최신 제품 화면은 [프로토타입](../designs/final/animation-preview.html)을 기준으로 합니다.

| 화면/상태 | 성공 | 취소·차단·오류 | 저장 |
|---|---|---|---|
| 카드 발급 `issue` | 카드가 나온 뒤 첫 출발지 검색 | 지원하지 않는 진동은 생략, 발급 저장 실패 안내 | 카드 ID·발급 상태 |
| 첫 출발지 `search` | 정류장 이름·방면 선택 후 시간 선택 | 결과 없음은 선택 불가, 재이용 앱 내 검색/초기화 차단 | 최초 설정·정류장·진행 방향 |
| 메인 `main` | 현재 정류장에서 여행 시작 또는 이전 여정 이어가기 | 새 여정은 기존 여정 정리 확인, 자동 재생 없음 | 현재 정류장·남은 여정 복원 |
| 시간·여정 `time` | 15~360 min 중 고른 시간에 맞는 버스·도착지 확정 | 시간 변경 시 후보 선택 해제, 없음/미선택은 다음 불가 | 준비 중 선택값 유지 |
| 준비 `prepare` | 태그와 비어 있지 않은 할 일을 확정 | 자동 기본 태그 없음, 초안은 편집 왕복 유지 | 출발 확정값에 포함 |
| 태그 `tags`·`tagEdit` | 선택·새 태그 이름/아이콘/색 저장 후 준비 복귀 | 빈 이름·중복 검사, 취소 시 준비 초안 유지 | 여정에 태그 정의 포함 |
| 소리 `sound` | 선택·미리듣기 후 준비 복귀 | 취소는 확정값 유지, 늦은 decode는 재생하지 않음 | 여정 소리 선택 |
| 승차권 `board` | 버스·출발/도착·시간·할 일 확인 후 승차 태그 | 준비 미완성은 진입 차단 | 아직 완료/진행 여행 생성 없음 |
| 승차 태그 `boarding` | 카드 드래그·터치·키보드 접촉 → 인식 → 여행 | 잘못 놓음/중복/이탈/숨김은 지연 전환 취소 | 인식 접촉 성공 시 진행 여정 생성·저장 |
| 여행 `focus` | 지도 따라가기/탐색·정류장 펼침·일시정지·재개 | 지도/오디오 실패는 준비·진도 보존하며 복구 | 진도 체크포인트·백그라운드 정지 |
| 멈춤·포기 | 이어가기 또는 확인 후 현재 도달 정류장으로 종료 | 포기 취소는 이전 멈춤 상태 유지 | 포기는 재개 정보 제거, 완료 기록 없음 |
| 하차 태그 `alighting` | 접촉 성공 뒤 요약 | 하차 전까지 완료 기록 없음, 중복 저장 차단 | 완료 기록·도착 정류장, 재개 정보 제거 |
| 요약 `arrival` | 한 일·시간·도착 확인, 선택 메모, 메인 | 메모 없이 마쳐도 됨 | 해당 여행의 200자 메모 |
| 기록 `records`·분석 `analytics` | 날짜별 기록·메모, 기간/태그 집계 | 예시 데이터는 실제 저장과 분리 | 완료 기록만 집계 |
| 마이페이지 `profile`·꾸미기 `cardStudio` | 같은 카드·사진/색을 승하차 카드와 하차 LCD에 반영, 승차 LCD는 이름/ID | 편집 취소 확인, 사진 형식/크기 제한 | 카드·최대 6장 사진, 기기 로컬 |
| 설정 `settings` | 동작 줄이기 등 설정 | 앱 내부 첫 이용 초기화 없음 | 지원 설정 |

코드의 `intro`·`home`·`buses`는 이전 흐름 회귀/시연용입니다. 제품 준비에 별도 할 일 장면은 없고 입력을 허브로 합쳤습니다. 화면 모아보기의 성공·오류 시연은 실제 저장 상태를 바꾸지 않습니다.

## 최신 승차 태그 계약

외부 제목·출발지·상단 태그 표기·뒤로가기·별도 수동 태그 버튼은 표시하지 않습니다. 중앙 단말기와 카드, 두 번 움직이는 올림 안내를 사용합니다. 카드 자체의 터치·Enter/Space와 드래그 접촉은 유지합니다.

LCD 상단은 Focus Mate와 실제 로컬 HH:mm이고 버스 번호를 표시하지 않습니다. 대기 문구는 ‘작은 시작이 오늘을 바꿔요.’입니다. 인식 후 현재 카드 이름과 ID를 보여줍니다. 일반 동작은 접촉 이동 300ms → 인식 유지 1400ms → 페이드 450ms → 여행입니다. **저장은 인식 접촉 성공에서 수행하며 마지막 화면 전환까지 미루지 않습니다.** 동작 줄이기는 접촉 이동·페이드·햅틱을 생략하고 인식 유지와 상태 안내를 남깁니다. 단계별 장면/token/숨김 검증으로 늦은 전환을 막고 접촉 후 저장은 보존합니다. 하차 타이밍은 이번 변경 대상이 아닙니다.

## 공통 규칙

브라우저 localStorage에 카드·꾸미기·위치·기록·메모·진행 여정을 저장합니다. 저장 차단은 세션 사용을 허용하지만 재실행 복원을 보장하지 않음을 안내합니다. 손상/다른 버전 데이터는 안내하고 명시적 정리 전까지 보존합니다. 앱 밖 시간은 진도에 추가하지 않습니다. 동작 줄이기에서는 경로 미리보기·카메라 회전·카드 공간 이동을 줄입니다. 닫기·확인·장면 전환은 숨긴 컨트롤에 포커스를 남기지 않습니다.
