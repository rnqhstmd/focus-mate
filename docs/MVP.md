# Focus Mate MVP

기준: 2026-10-13. 현재 실행 기준은 [HTML 프로토타입](../designs/final/animation-preview.html), 상태·검증 기준은 [현재 상태](CURRENT-STATE.md)입니다. 아래 iOS 범위는 구현 완료 주장이 아닌 다음 개발 범위입니다.

## 가치와 대상

버스 여행의 출발·이동·도착을 작은 몰입 의식으로 사용합니다. 사용자는 시간을 정하고 독서·작업·쉼 중 한 가지 할 일을 담아, 집중동행카드를 태그하고 자기 시간을 보냅니다. 끝에는 한 일과 시간을 기록합니다. 실제 버스 탑승 인증·교통 결제·실시간 운행 안내 서비스가 아닙니다.

## 핵심 흐름

```text
첫 이용: 카드 발급 → 첫 출발 정류장 선택
이후: 현재 정류장 메인 → 시간·버스·도착지 선택 → 태그·할 일·소리 준비
      → 승차권 → 승차 태그 → 여행 → 하차 태그 → 요약·선택 메모
      → 현재 정류장 메인 / 기록·분석 / 마이페이지·카드 꾸미기
```

출발지 검색은 첫 설정에서만 허용합니다. 다음 여행은 저장된 마지막 정류장에서 시작합니다. 멈춘 여정이 있으면 이어가기 또는 확인 후 새 여행을 선택합니다.

## 범위

| 기능 | 현재 웹 프로토타입 | 네이티브 iOS MVP | 후순위 |
|---|---|---|---|
| 집중동행카드 | 1회 발급·번호 저장·꾸미기·승하차 표시 | 카드와 꾸미기 로컬 저장, 발급/태그 모션·지원 기기 햅틱 | 카드 공유·여러 카드·교통카드 연동 |
| 첫 출발지·여정 선택 | 가상 정류장, 15~360 min 1분 눈금, 정확히 맞는 예시 버스·도착지 선택 | 같은 선택 정책과 검증된 앱 내 코스 | 실제 GPS 출발지, 실제 버스 API·실시간 도착·노선 검색 |
| 태그·할 일 | 미선택 시작, 준비 허브 초안·새 태그·유효성 검사 | 태그/할 일 편집 및 로컬 복원 | 추천·공유·복잡한 프로젝트 관리 |
| 소리 | 없음·4종 샘플, 미리듣기·반복·실패 복구 | 라이선스 확인한 오디오, 중단/재개·기기 볼륨 | 스트리밍·음원 구매·사용자 음원 업로드 |
| 지도·여행 | 생성 지도·가상 폐곡선, 따라가기·탐색·정류장 목록, 지도 테마(위성은 색 시연), 출발·도착 안내 | MapKit 어두운 지도·위성 모드와 3D 기울기, 앱 내 가상 코스, 출발·도착 안내, 접근성·동작 줄이기 | 실제 버스 위치·실시간 경로·배경 GPS 추적 |
| 여행 시간 | 선택 시간을 30초로 압축한 시연 | 선택한 실제 분만큼의 타이머, 일시정지·진도 저장·복원 | 앱 밖 시간 자동 진행, 서버 실시간 상태 공유 |
| 중단·이어가기 | 승차 인식 접촉 시 저장, 백그라운드 정지, 메인에서 수동 재개 | 로컬 여정 체크포인트와 앱 생명주기 처리 | 기기 간 이어가기·실시간 동기화 |
| 기록·메모·분석 | 하차 접촉 완료 기록, 200자 메모, 연간 잔디·기간/태그 분석·마친 시간대·자주 탄 노선·여행 길이·연속일·메모 회고 | 로컬 완료 기록·메모·동일 집계 정책 | 계정·클라우드 동기화·백업·협업 |
| 오류·접근성 | 저장 실패/손상 안내, 지도·오디오 복구, 키보드·포커스 | VoiceOver·Dynamic Type·햅틱/모션 설정·저장 복구 | 실제 운행 장애 알림 |

## 출시 판단 기준

첫 발급부터 기록 확인까지 끝낼 수 있고, 미완성 준비로 출발할 수 없어야 합니다. 접촉 전 취소는 여행을 만들지 않으며 접촉 후에는 인식 연출 중 종료해도 재개 정보가 남아야 합니다. 완료 기록은 하차 접촉 성공에서만 만들고 포기는 기록하지 않습니다. 저장 실패를 성공으로 안내하지 않으며 사용자의 기존 손상 데이터를 임의로 덮어쓰지 않습니다.

iOS 출시 전에는 실제 시간 타이머·앱 생명주기·작은 화면과 큰 글자·VoiceOver·실기기 드래그와 햅틱·오디오 청취를 검증해야 합니다. 현재 웹 QA 결과로 이를 대체하지 않습니다. 전체 계약은 [FLOWS.md](FLOWS.md)를 봅니다.
