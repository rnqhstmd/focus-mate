# 승차 단말기와 카드 접촉 연출

사용자가 제공한 승차 태그 화면을 기준으로 외부 제목·출발 정류장·승차 태그 표기·뒤로가기·수동 태그 버튼을 제거한다. 단말기와 카드를 같은 중심선에 배치하고 위쪽 드래그 방향을 짧은 시각 안내로 표현한다. 카드 자체의 키보드 접근성은 유지한다.

LCD 대기 상태는 Focus Mate·현재 시간(HH:mm)·짧은 자체 작성 문구로 구성한다. 접촉 후에는 집중동행카드와 사용 중인 카드 이름·번호를 표시하고 인식 결과를 유지한 뒤 여행 화면으로 전환한다. 카드 도안·발급 정보·기존 저장 키는 보존한다.

중복 접촉 방지, 장면 변경 시 지연 전환 취소, 동작 줄이기, 성공 접촉 시 저장과 피드백의 기존 계약을 유지한다. 이번 변경은 승차 화면 대상이며 하차의 정보 흐름은 유지한다.

## 검증
JavaScript 구문 검사와 scripts/prototype-edge-qa.cjs 직접 실행 exit 0 PASS. 21개 내부 장면/441 포커스 전환/882 취소 전환을 포함한 기존 회귀를 유지했다. 현재 시간 표시·카드 이름/번호·접촉 저장 1회·중복 차단, 인식 화면 1400ms 유지와 450ms 페이드, 동작 줄이기의 유지 시간/진동·페이드 생략, 다섯 접촉 단계의 장면 변경·백그라운드 취소와 인식 후 재실행 복원을 확인했다. 브라우저 전용 QA는 기대값 갱신과 구문 검사만 했으며 직접 렌더링/터치/하드웨어 진동은 접근 제한으로 검증하지 않았다.

접촉 이동 300ms 뒤 인식이 확정되면 저장을 1회 수행한다. 화면 연출을 기다리지 않고 복원 가능한 여정을 보존하며, 장식 전환만 취소할 수 있다. 실행용 designs/prototype/index.html도 최신 HTML로 다시 묶었다.


## Pen 시안
focus-mate.pen의 R27 승차 태그·R12 인식 완료·R42 꾸민 카드 승차를 네이티브 레이어로 수정하고 저장했다. 외부 안내·버튼은 숨기고 LCD·정렬·올림 아이콘을 갱신했다. 카드 도안과 IC 칩 레이어를 보존한다. 세 화면 렌더 스크린샷으로 정렬·표시를 확인했고 PNG를 designs/revised/pen-updates/boarding-reader-2026-10-12/에 내보냈다. 이 PNG는 Pen 렌더 결과이며 브라우저 캡처와 구분한다. 브라우저 캡처 42개는 다시 캡처하지 않았다. 후속 정리에서 수정한 네이티브 레이어를 생성용 JSON과 전체 문서 스냅샷에 동기화하고, 최신 Pen 42페이지 PDF와 전체 흐름 PNG를 추가 내보냈다.
