# 마이페이지 · 집중동행카드 꾸미기

2026-10-12. Focus Mate의 기본 검정 카드와 제공된 카드 캔버스 요구를 기존 검은 UI 안에 구현했습니다. [카드 발급·단말기](focus-mate-card-and-reader-2026-10-12.md) 변경과 함께 게시했습니다.

## 사용 흐름

메인 우상단 사람 아이콘 → 마이페이지 → 카드 꾸미기 → 배경색·사진 배치 → 이 카드로 저장하기 → 같은 카드로 승하차합니다. 설정은 마이페이지에서 엽니다. 여정·완료 기록을 지우거나 카드를 다시 발급하지 않습니다.

카드는 기본 검정이며 여섯 배경색과 직접 색 선택을 제공합니다. JPG·PNG·WebP 사진을 여러 장 추가해 카드 캔버스에서 끌어 옮기고, 모서리 핸들 또는 슬라이더로 크기를 조절합니다. 사진 목록에서 선택하고 앞뒤 순서·삭제·되돌리기를 사용합니다. IC 칩은 고정되고 사진은 둥근 카드 경계에서 잘립니다. 칩과 카드 식별 정보가 사진 위에 남습니다. 사진이 있는 카드는 중앙 표제를 숨겨 사진 영역을 넓게 사용합니다.

작은 화면에서 도구는 세로 스크롤하고 카드 미리보기는 위에, 저장 버튼은 아래에 유지합니다. 사진 이동은 방향키, 크기는 슬라이더·핸들 방향키로도 조작합니다. 저장 전 뒤로 가면 변경 버리기/계속 꾸미기를 선택합니다. 기본 카드 복원도 되돌릴 수 있습니다.

## 저장과 사진

사진은 최대 6장, 파일당 8MB까지 받으며 긴 변을 최대 640px로 줄여 브라우저에서 저장합니다. 업로드 서버를 사용하지 않습니다. 버전 1 디자인은 `focus-mate-card-style-v1`에 저장하고 카드 발급 번호와 별도로 관리합니다. 저장할 때만 승차·하차·LCD의 카드에도 반영합니다. 저장 차단은 현재 페이지에만 반영됐다고 안내하며, 읽지 못한 버전은 사용자가 새 디자인을 저장하기 전까지 보존합니다.

화면 모아보기의 사진은 기존 생성 지도 자산을 잘라 쓴 시연 이미지입니다. 실제 사용자 카드·사진을 변경하지 않으며 개인 사진이 사이트 소스에 포함되지 않습니다. 사진 크기를 줄이는 과정은 원본 파일을 바꾸지 않습니다. 계정·기기 간 동기화는 없습니다.
