# 시작 한 번으로 현재 정류장에서 출발

2026-10-12. 메인 시작 뒤에 별도 출발 안내와 ‘시간 선택하기’를 다시 누르던 단계를 제거했다.

- 첫 이용: 메인 시작 → 소개 → 출발 정류장 선택·확인 → 시간 선택.
- 이후: 메인 시작 한 번 → 저장된 현재 정류장에서 시간 선택 → 버스·도착지 카드 → 여행 준비.
- 기록·분석의 다음 여행 시작도 같은 진입 함수를 사용한다. 시간 선택의 뒤로 가기는 메인으로 돌아간다.

시간 선택 진입에서 지난 여행의 준비·소리·버스 후보 선택을 초기화한다. 마지막 정상 하차 정류장 또는 포기 후 저장한 정류장과 진행 방향은 그대로 사용하며, 브라우저를 다시 열어도 해당 위치에서 시작한다. 첫 이용의 출발지 선택은 매번 반복하지 않는다.

현재 제품 장면은 14개이며, 이전 출발 안내와 버스 목록 코드는 회귀 검사에만 남겨뒀다. 시연 갤러리의 R04는 출발 정류장의 초기 시간 선택(25분)이며 별도 안내 화면이 아니다. 전체 26개 상태와 Pen R02·R04, PDF를 갱신하고 Pen 흐름 보드 설명도 수정했다.

## 직접 실행

- `node scripts/minute-first-browser-qa.cjs`: 통과. 실제 성수역 반대 방향 정류장 버튼을 선택한 첫 이용에서 시간 선택 직행, 뒤로 가기·메인 포커스, 기록·분석 재시작, 실제 카드 승하차·저장된 도착지·새로고침과 다음 여행을 확인했다. 3,096개 유효 후보와 5개 화면 크기를 검사했고 브라우저 오류는 0개였다.
- `node scripts/main-welcome-qa.cjs`: 통과. 시간대·9개 저장 위치 인사, 하차·재실행·한 번 시작, 5개 화면 크기 검사를 확인했다.
- `node scripts/prototype-edge-qa.cjs`: 통과. 기존 수치·포커스·장면 취소·지도·소리 오류 복구를 검사했다. 최초 정류장 확인 및 저장 후 시작 기대 장면을 실제 직행 경로로 갱신했다.
