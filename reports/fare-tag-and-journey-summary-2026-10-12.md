# 전체 화면 승하차 태그와 여행 요약

2026-10-12. 승차권 확인과 카드 태그를 분리했다.

- 승차권: 버스·출발·도착·시간·할 일을 확인하고 **버스에 탑승하기**를 누른다.
- 승차: 전체 화면에 단말기와 하단 카드를 표시한다. 카드를 단말기로 끌어 놓으면 접촉 위치로 이동하고 성공 표시 후 여행을 시작한다. 잘못 놓으면 하단으로 돌아온다.
- 하차: 타이머가 끝나면 같은 전체 화면에서 하차 태그를 기다린다. 이 시점에는 아직 완료 기록을 저장하지 않는다.
- 요약: 하차 태그 성공 후 정확히 한 번 기록을 저장하고 할 일·여행 시간·도착 정류장을 표시한다. 200자 줄바꿈 메모를 선택해서 남길 수 있다. 메모 입력 중 마치기는 **메모 저장하고 마치기**로 표시한다.

터치·Enter/Space·누르는 대체 버튼을 제공한다. 동작 줄이기에서도 성공 피드백을 유지한다. 화면을 바꾸거나 드래그를 취소하면 기존 제스처와 태그 타이머를 폐기한다. 단말기는 HTML/CSS/SVG로 구성했고 Pen에서는 편집 가능한 벡터·텍스트로 옮긴다. 실제 NFC와 운행 데이터는 사용하지 않는 시연이다. 기존 연간 잔디·주간/월간 분석·저장 위치·선택 소리를 유지한다.

제품 장면 16개, 회귀용 과거 장면 2개, 갤러리 상태 30개. 현재 흐름은 [CURRENT-STATE](../docs/CURRENT-STATE.md), 동작 소스는 [animation-preview.html](../designs/final/animation-preview.html)이다.

## 검증

검사 실행 결과와 게시·Pen 노드 정보는 아래에 이어 기록한다.

- `fare-tag-browser-qa.cjs`: 통과. 실제 승차·하차 드래그, 잘못 놓기, 화면 변경 중 취소, 자연 도착 전 저장 없음, 한 번 저장, 요약·줄바꿈 메모·새로고침, 키보드·동작 줄이기, 시연 기록과 위치 저장 분리를 확인했다. 5개 화면 크기(1280×1040, 390×844, 390×650, 320×568, 280×656)에서 카드와 단말기·요약·메모를 검사했다. 30개 상태를 캡처했고 브라우저 오류 0개였다.
- `minute-first-browser-qa.cjs`, `analytics-memo-qa.cjs`, `records-calendar-qa.cjs`, `main-welcome-qa.cjs`: 통과. 새 태그와 요약 흐름으로 검사 입력을 갱신했고 기존 시간 선택·완료 기록·분석·메모·저장 위치 인사를 유지했다.
- `prototype-edge-qa.cjs`: 통과. 173,376개 순방향 수치 검사, 260,064개 역방향 검사, 논리 장면 18개(제품 16개·과거 2개)의 포커스 전환 324개와 태그 취소 648개를 확인했다.

Pen 최종 화면: 승차권 `a0h6D`, 승차 태그 `abHTE`, 승차 성공 `Dap1F`, 하차 태그 `i0Jy3V`, 하차 성공 `evY8q`, 요약 `i533Ju`, 요약 메모 `yANnZ`. 전체 흐름 `e3W6e`는 11단계 컴포넌트 인스턴스로 구성했다. 카드가 포함된 네이티브 화면 스크린샷을 확인하고 전체 보드를 PNG로 내보냈다. 편집 레이어 텍스트 532개·벡터 1269개. PDF 내보내기 때만 카드 필터와 단말기 그림자를 제거해 이미지 누락을 해결했으며 브라우저의 태그 동작에는 영향을 주지 않는다.
