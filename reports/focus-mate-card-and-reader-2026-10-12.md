# Focus Mate · 집중동행카드와 검은 단말기

2026-10-12. 사용자 확정명 Focus Mate / 집중동행카드와 첫 카드 발급, 제공한 단말기 사진의 구조·검은 화면을 반영한다. 앞선 초록 화면 제안은 철회했고 본체와 LCD 모두 검은 톤이다.

처음 한 번: 카드 발급 → 출발 정류장 → 시간과 버스/도착지 → 할 일 준비 → 같은 카드로 승차 → 하차 → 기록 요약. 카드 발급 순간에는 900ms 이내의 출력·내려놓기 모션을 제공하고 지원 기기에서 짧은 진동을 요청한다. 새 카드의 표시 번호는 FM이며 NS 형식의 기존 카드는 계속 읽는다. 키 `next-step-prototype-pass-v1`과 기존 기록/여정/위치 키는 유지해 저장 데이터를 보존한다. 앱에서 사용한 카드는 실제 교통 결제·실제 NFC 카드가 아니라 몰입 여정용 프로토타입이다. 버스 전용 문양을 제거하고 교통수단과 무관한 경로·태그 문양을 써서 지하철 확장 시 같은 카드를 유지할 수 있게 한다. 지하철 운행/역 데이터나 선택 기능을 이번에 구현한 것은 아니다.

단말기는 검은 본체, 큰 검은 LCD, 아래쪽 태그 영역으로 구성한다. 검은 LCD에 버스 번호·대기/성공 상태를 표시하고 성공 접촉 후 발급받은 집중동행카드 축소 화면을 보여준다. 실제 요금/잔액 숫자는 넣지 않는다. 카드 이동 안내는 두 번만 표시하고 조작하면 멈춘다. 잘못 놓기와 중복 입력은 성공 진동을 만들지 않는다. 확인 접촉 후 짧은 진동을 요청하고, 승차 복원 상태와 하차 완료 기록은 장식 연출을 기다리지 않고 이 시점에 저장한다.

## 참고와 이름

[서울시 기후동행카드 소개](https://news.seoul.go.kr/traffic/archives/510651)의 한 장으로 버스·지하철을 이용한다는 개념을 참고했다. 공식 카드의 이름/로고/요금이나 실제 사용권을 복제하지 않는다. [MDN Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate)에 따라 기능 존재 여부를 확인해 진동을 요청하며 미지원 기기에서는 시각 피드백으로 진행한다. 실제 iPhone 하드웨어 진동을 검증했다는 의미가 아니다.

동일한 영문 이름의 기존 집중 서비스 [Focusmate](https://www.focusmate.com/)가 확인된다. 요청한 프로토타입 표기는 유지하지만 출시 브랜드의 구분은 별도 검토가 필요하다. 상표 등록 가능성·법적 사용 가능성을 확인한 결과가 아니다.

## 검증과 게시

`pass-issue-browser-qa.cjs`와 `reader-feedback-browser-qa.cjs`가 카드 한 번 발급·동일 카드 재사용·저장/재진입·키보드·동작 줄이기·저장 오류·기존 사용자 복원·검은 LCD·단일 성공 진동 요청·실패 접촉·성공 연출 중 종료와 다섯 화면 크기를 통과했다. `fare-tag-browser-qa.cjs`, `journey-resume-browser-qa.cjs`, `minute-first-browser-qa.cjs`도 승하차·요약·여정 복원과 시간 우선 선택을 통과했다. 브라우저 오류는 없었다.

[마이페이지와 카드 꾸미기](card-customization-2026-10-12.md)를 함께 반영했다. 기본 카드는 검정이고, 고정 IC 칩 위에 사진이 덮이지 않는 카드 캔버스에서 배경색과 사진을 꾸민다. 승차·하차·LCD에 같은 디자인을 표시한다.

Pen은 총 42개 화면 상태, 텍스트 743개·벡터 경로 1,567개로 갱신했다. 발급 전/출력/발급 완료와 마이페이지·사진 배치 화면을 추가했으며 검은 단말기와 카드 표시를 네이티브 시안에서 확인했다. [최신 시안](../designs/revised/README.md).
