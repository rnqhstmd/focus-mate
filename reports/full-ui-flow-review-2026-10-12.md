# Focus Mate UI·UX·플로우 최종 검수

2026-10-12. 최신 HTML·게시 프로토타입·편집 가능한 Pen·화면 스냅샷을 기준으로 전체 작업을 재검수하고 수정했다. 이전 보고서는 당시 결정과 결과를 보존하며, 최종 판단은 이 문서와 [검증 JSON](verification/full-review-2026-10-12.json)을 사용한다.

## 흐름 판단

집중동행카드를 한 번 발급하고 현재 정류장에서 반복 여행을 시작하는 구조는 제품의 지속 사용과 맞는다. 시간부터 고른 뒤 버스·도착지를 선택하고 준비 허브에서 할 일을 정하므로, 집중 시간을 정하려는 사용자의 순서와 일치한다. 승차권은 여정 확인에 집중하고 승하차 태그는 각각 별도 화면으로 분리해 동작을 이해할 수 있다.

```text
처음: 검정 집중동행카드 발급 → 출발 정류장 → 시간 선택
반복: 메인 시작 → 분 단위 시간 → 버스·도착지 선택
     → 준비(태그·할 일·선택 소리) → 승차권 → 승차 태그
     → 집중 / 일시정지·재개 → 하차 태그 → 요약·선택 메모
     → 기록·연간 잔디·분석 / 마이페이지·카드 꾸미기
```

42개 화면 상태에서 첫 이용, 정상 여행, 빈 결과, 오류, 중도 종료, 기록 누적, 카드 사진 편집, 저장 차단, 복귀 여정을 확인했다. 외부 갤러리와 자동 재생은 실제 기록을 바꾸지 않으며, 지도·노선은 가상 예시다. 검정 카드·검정 단말기 LCD, 시간 바로가기 제거, 후보 개수·중복 경로 제거 등 사용자가 확정한 방향을 유지했다.

## 발견한 문제와 수정

| 문제 | 수정 후 동작 |
| --- | --- |
| 갤러리에서 카드 발급·출발지를 체험하면 실제 이용자의 진입 상태가 바뀔 수 있었다. | 시연 진입 전에 실제 정류장·방향·첫 이용·복원 여정을 보관하고 실제 여행 진입 시 복구한다. |
| 시연 오류가 다음 화면으로 남거나 실제 지도 오류가 기록·분석의 닫기·탭을 덮었다. | 시연 오류를 초기화하고 실제 지도 오류는 메인에서 복구할 수 있게 한다. 기록·분석·마이페이지의 조작을 가리지 않는다. |
| 카드 수정 취소 확인에 Escape와 키보드 포커스 처리가 빠졌다. | 배경을 비활성화하고 Tab·Shift+Tab을 확인창 안에 유지한다. Escape로 편집을 계속하고 포커스를 복원한다. |
| 마이페이지와 카드 꾸미기에서 상태바·홈 표시가 가려졌다. | 화면의 겹침 순서를 수정해 두 표시가 유지된다. |
| 진행 중인 여정이 있을 때 기록·분석의 다음 여행 버튼이 확인창을 열지 못했다. | 메인에서 기존 여정 정리 확인을 열고 취소·이어가기·새 여행 시작이 모두 동작한다. |

시연 설명도 실제 저장 방식과 맞췄다. 기록·카드·중단 여정은 같은 브라우저에 저장되고 지도·운행 정보는 가상이라는 내용을 표시한다. 최종 별도 검수자는 처음 발견한 네 가지 주요 문제의 해결을 확인하고 제공 가능한 상태로 판정했다. 다섯 번째 진입 문제는 추가 회귀 검사로 확인했다.

## 직접 실행한 검증

- 42개 상태를 402×874와 실제 반응형 320×568 뷰포트에서 캡처·검사했다. 작은 화면 검사는 고정 크기 내보내기 모드를 사용하지 않았다.
- 첫 발급, 분 단위 선택, 승하차, 단말기, 복원, 기록, 분석·메모, 카드 꾸미기는 각 다섯 뷰포트의 전용 검사도 통과했다.
- 총 12개 브라우저 검사: 전체 흐름, 카드 발급, 시간 우선, 승하차, 단말기 피드백, 여정 복원, 연간 기록, 분석·메모, 카드 꾸미기, 동네 인사, 미리보기 배치, 오디오. 페이지 실행 오류가 없었다.
- 상태 회귀 검사: 논리 장면 21개, 전환 441개, 취소된 태그 전환 882개, 수치·경로 단언 433,440개를 통과했다.
- Chromium의 합성 터치로 시간 눈금을 조작하고 종료 후 드래그 상태가 해제되는지 확인했다. 키보드·휠·클릭, 잘못된 카드 놓기, 중복 저장 방지, 동작 줄이기도 검사했다.
- 실제 Web Audio에서 4개 WAV를 디코딩하고 시작·정지 페이드와 반복 연결을 오프라인 렌더링으로 검사했다. 스피커·헤드폰 청취 평가 결과는 아니다.

자동 UI 감지 결과의 경고 88개도 확인했다. 낮은 대비 55개, 작은 글자 10개, 작은 조작 영역 18개, 간격 1개, 이미지 관련 2개, 클리핑 2개였다. 숨겨진 기존 DOM과 카드의 보조 인쇄 문구, 의도한 카드·폰 경계 등이 포함되므로 숫자를 접근성 결함 확정으로 해석하지 않았다. 이번 검수는 주요 조작·가림·키보드 문제를 수정한 범위이며 전체 WCAG 적합 인증은 아니다.

## Pen·자산·실행 자료

[focus-mate.pen](../designs/focus-mate.pen)은 앱이 저장한 네이티브 원본의 파일 형식 변환 없는 백업이다. 디자인 내용은 Pencil MCP로 읽고 수정했다. 최신 42개 상태와 이전 36개 시안, 흐름·브랜드·모션 보드를 포함하며 최상위 노드는 94개다. 현재 42개 상태에는 편집 가능한 텍스트 745개와 벡터 도형·경로 1,561개가 있다. 지도와 사진은 이미지이고 카드 테두리·글자·IC 칩은 독립 레이어다.

모든 참조 이미지 116개를 `designs/assets/`에 포함했다. MCP 전체 스냅샷에 벡터 경로 누락, 잘못된 컴포넌트 참조와 placeholder가 없음을 확인했다. 카드 사진은 둥근 카드 프레임 내부에서 잘리며 IC 칩 위치를 유지한다. 최신 42개 PNG·PDF·네 줄 흐름 보드도 다시 생성했다. 이전 산출물은 보존한다.

Node 의존성·Python 디자인 의존성을 명시하고, 브라우저 검사가 무시된 Sites 체크아웃의 `node_modules`에 의존하던 문제를 제거했다. 사진 검사 입력도 저장소에 포함했다. 이제 깨끗한 체크아웃에서 `npm ci`와 루트 README의 명령을 사용한다. `npm run build`는 Sites 메타데이터가 없어도 독립 프로토타입을 생성한다.
