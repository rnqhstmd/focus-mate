# GitHub 형태의 연간 기록 잔디

2026-10-12. 사용자가 첨부한 GitHub contribution graph를 참고해 큰 월간 날짜 달력을 **연간 잔디**로 바꿨다.

가로는 주, 세로는 일~토 7개 요일이다. 1~12월을 표시하고 선택한 연도의 모든 날짜를 작은 정사각형으로 보여준다. 시작과 끝에 해당 연도 밖의 빈칸을 두며 365/366일과 53/54주 구조를 계산한다. 1년 전체가 폰 안에 들어오고, ‘확대해서 보기’에서는 잔디 영역만 가로로 스크롤한다. 연도 버튼과 이전·다음 연도, 올해 복귀를 제공하며 미래 연도로 이동하지 않는다.

하루 완료 여행 시간 합계에 따라 초록색 5단계로 표시한다. 0분, 1~30분, 31~60분, 61~120분, 121분 이상이며 미래 날짜는 비활성화한다. 오늘과 선택한 날짜를 별도로 표시하고 색 외에 접근성 이름·날짜별 횟수·시간으로 값을 제공한다. 연간 합계는 실제 완료 기록에서 계산하며 진행 중/포기한 여행은 포함하지 않는다.

잔디 칸을 누르면 그날의 여행과 선택 메모가 열린다. 작은 칸을 누르기 어려우면 44px 높이의 날짜 입력으로 같은 기록을 선택한다. 방향키 위·아래는 하루, 좌·우는 한 주이며 연도 경계도 이동한다. 기록은 최신순으로 10개씩 펼치고 메모 저장·수정·분석에서 기록으로 돌아오는 연결을 유지했다. 예시 잔디는 최근 365일의 시연 데이터이며 실제 저장 기록을 바꾸지 않는다.

## 직접 실행

- `node scripts/records-calendar-qa.cjs`: 28건 누적·중복 방지·새로고침·메모 수정, 1900/2000/2023/2024/2028/2100년의 날짜·윤년·요일·54주 배치, 연간 합계·날짜 입력·연도 버튼·키보드 경계 이동·미래 날짜 차단을 확인했다. 예시 데이터와 저장 실패/손상 데이터도 검사했다.
- 1280×1040, 390×844, 390×650, 320×568, 280×656에서 전체 연도 표시·확대 스크롤·목록/메모·고정 닫기와 다음 여행 버튼을 검사했다. 확대는 화면 전체의 세로 위치를 바꾸지 않는다.
- `node scripts/analytics-memo-qa.cjs`: 월/주 분석·태그 필터·해당 기록 열기·하차 메모·줄바꿈·예시 격리 검사 통과.
- `node scripts/prototype-edge-qa.cjs`: 기존 6,192개 조합의 정/역방향 수치·포커스·지연 취소·소리/지도 복구 검사 통과.
