# 진행 방향을 유지하는 여행 지도

사용자 요청: 하단 수치는 글씨만 표시하고, 노선 목록을 간결하게 정리한다. 버스는 위에서 바라본 형태와 유형별 차체 색으로 표시한다. 버스가 직진하는 느낌으로 지도가 움직인다. 일시정지는 좌상단, 현위치 따라가기와 지도는 우상단이며 포기하기는 일시정지했을 때 노출한다.

## 구현 기준
- 하단 수치의 카드 배경·테두리를 제거한다. 가독성을 위한 지도 아래의 옅은 그라데이션과 얇은 진행선만 남긴다.
- 제어를 양쪽으로 분리하고 큰 통합 도구 패널을 없앤다. 일시정지하면 일시정지 아래에 '× 포기하기'가 나타나며 기존 중단 확인 정책을 유지한다.
- 정류장 펼침은 작은 이름/화살표 버튼으로 제공한다. 기본 접힘이고 펼쳐도 현재·다음·도착을 우선 읽고 중간 목록은 보조 스크롤로 확인한다.
- 지도 마커는 위에서 본 차체·전후 유리·바퀴 형태로 만든다. 별도의 초록 사각 배경 없이 차체 색 자체가 지선/마을/간선 색으로 바뀐다. 다른 화면의 버스 유형 배지는 Lucide 전면 버스로 유지한다.
- 따라가기에서는 경로 접선의 진행 방향을 위로 향하게 지도와 경로를 회전·이동한다. 버스는 같은 좌표식을 사용해 화면의 기준 위치에 두고 차체는 위를 향한다. 자유 지도 조작에서는 추적을 해제한다. 다시 따라가기 하면 기준 위치로 복원한다.
- 회전은 가장 짧은 방향으로 이어지고 역방향·경로 순환 경계도 처리한다. 동작 줄이기에서는 보간 없이 단순한 위치 추적을 사용한다.

이번 버스 마커 요청은 이전 전면 아이콘/회전 없는 마커 결정을 대체한다. 프로토타입 경로는 가상 예시이며 실제 운행 데이터가 아니다. HTML 기준 변경으로 Pen/PDF/이전 PNG는 이전 시안이다.

## 검증
최종 소스에서 좌표 변환·접선 방향·버스 고정 위치·역방향/경계/긴 여행, 정류장 접힘 및 일시정지/포기 흐름과 기존 전체 회귀를 검사하고 결과를 추가한다. 브라우저 접근 거절을 우회하지 않으므로 실제 렌더링·터치·회전 애니메이션의 시각 품질은 미검증이다.

## 사용자가 제공한 FocusFlight 실제 화면
사용자가 FocusFlight의 진행/일시정지 화면 두 장을 제공했으므로 공개 소개만으로 추정했던 참고 제한을 보완한다. 확인된 배치: 왼쪽 위 일시정지/재개 원형 버튼, 오른쪽 위 지도 관련 세로 제어, 아래 왼쪽 남은 시간과 오른쪽 남은 거리의 배경 없는 글씨, 중앙 위를 향하는 이동체, 일시정지 시 흐린 지도와 아래쪽 상태 안내.

버스 앱에서는 정류장 수를 가운데 작은 수치로 추가한다. 항공기/앱 차단 등 비행 앱의 별도 기능을 그대로 복제하지 않는다. 지도 따라가기·지도 버튼을 오른쪽 세로로 배치하고, 중단은 일시정지 상태 안내 영역의 '× 포기하기'로 연결한다. 실제 참고 이미지와 앱의 새 브라우저 화면을 픽셀로 비교한 검증은 아직 하지 않았다.

## 최종 검증 결과
최신 HTML 구문과 전체 회귀 스크립트, 독립 검증 PASS/exit 0. 기존 정방향 173,376개·역방향 260,064개 assertion과 14장면/196포커스/392취소 회귀를 유지했다.

원형 폐곡선 모형을 별도로 사용해 양방향·출발 위치·짧은/6 h 여행·여러 진행률에서 지도 좌표 변환 후 버스 앵커 위치, 회전 수렴과 버스 역회전, 최단 회전, 자유 탐색의 북쪽 복원 좌표 보존, 재추적 수렴을 검사했다. 동작 줄이기에서는 회전 없이 정류장 위치 추적과 aria-pressed가 일치한다. 기존 도달 정류장 스냅은 유지한다.

좌상단 일시정지/우상단 세로 지도 도구, 배경 없는 하단 수치, 멈춤 상태에서만 포기 노출, 지도 흐림, 3색 버스 차체와 위에서 본 형태, 접힌 정류장 안내를 상태·정적 소스로 확인했다. 지도에 CSS 회전 지연이 중복되지 않게 수정해 버스 역회전과 같은 회전 값을 사용한다. 실제 브라우저 렌더링·회전의 시각 품질·터치는 미검증이다.
