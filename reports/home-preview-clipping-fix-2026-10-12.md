# 이번 여정 미리보기 잘림 수정

2026-10-12. 사용자가 게시 프로토타입의 버스 선택 화면에서 ‘이번 여정 미리보기’가 잘린다고 보고했다.

내용 영역에 항상 적용되던 하단 12px 흐림 마스크와 모바일의 `높이 - 500px` 제한이 원인이었다. 390×844에서는 도착지와 시간 줄이 영역 밖에 있었고, 320×568에서는 내용 영역이 10px까지 줄어드는 것을 브라우저에서 재현했다.

수정:

- 현재 정류장 패널에 화면 높이를 고려한 상한을 적용했다.
- 항상 적용되던 흐림 마스크를 제거했다.
- 제목·푸터 간격과 시간 줄의 중복 여백을 줄였다.
- 긴 이름과 큰 글자에서는 내용만 스크롤하며 시작 버튼을 고정한다.
- HTML·게시용 묶음·Pen R04 현재 정류장과 PDF를 갱신했다.

`node scripts/home-preview-layout-qa.cjs` 통과. 1280×1040, 390×844, 390×650, 320×568, 280×656에서 기본 도착지·시간의 잘림 0건을 확인했다. 긴 정류장명·22px 글자에서도 시간 줄을 스크롤해 읽을 수 있고 시작 버튼이 보이며, 눌렀을 때 시간 선택으로 이동한다.

실행 증거는 `.impeccable/review/home-preview/verification.json`, 수정 화면은 `.impeccable/review/home-preview/after.png`다. 이 수정의 검증은 해당 화면의 브라우저 레이아웃과 시작 동작에 한정했다. 최초 개선판의 전체 상태 검증 기록은 이전 보고서에 보존했다.
