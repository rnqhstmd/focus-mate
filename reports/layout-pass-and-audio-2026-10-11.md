# 화면 정렬·승차권·소리 선택 후속 수정

사용자 제공 화면에서 할 일 입력의 포커스 테두리가 내부 스크롤 경계에서 잘리고, 메인 화면의 긴 설명과 태그 목록 편집 버튼, 승차권의 과도한 정보가 확인됐다.

## 수정 기준
- 입력 포커스는 영역 밖으로 나가는 outline 대신 안쪽 강조와 테두리로 표시한다. 좁은 메인 화면에서 긴 문구를 줄이고 하단 여행/기록/설정 탭은 같은 너비로 배치한다.
- 태그 목록은 선택과 새로 추가만 제공한다. 기존 태그 편집 버튼은 제거한다. 새 태그의 아이콘·색 견본과 미리보기는 유지한다.
- 승차권 정보는 버스 번호, 출발/도착, 여행 시간, 정류장 수, 이동 거리만 표시한다. 태그·할 일·소리·탑승 준비 배지·준비 완료 원형 안내·탑승 성공 문구는 제거한다. 아래 카드 배치와 터치 동작은 유지한다.
- 여행 중 정류장 목록 펼침은 왼쪽 아이콘 버튼으로 옮긴다. 버튼/펼친 목록의 위치와 접근성 상태가 일치한다.

## 소리
사용자가 제시한 백색소음·버스 창문 빗소리·숲·버스 주행 네 종류와 소리 없음을 제공한다. 이 세션에 오디오 생성 모델 도구는 없어, 사전 생성 DSP 합성 파일을 준비한다. 외부 생성 모델의 결과나 실제 버스 현장 녹음이라고 표시하지 않는다. 소리 생성 과정·수준·길이·파일 검사는 assets/audio/SOURCE.md와 생성 스크립트에 기록한다.

소리 선택에서 미리듣고 여행에서 반복 재생한다. 늦게 완료된 파일 로딩이 일시정지/다른 선택/다른 화면/중단 후 소리를 다시 시작하지 않게 처리한다. 음량 UI는 없으며 기기 음량을 사용한다. 로딩/재생 지원 실패는 여행을 막지 않는다.

HTML 기준이며 실제 브라우저 렌더링·터치·소리 청취 검증은 접근 제한으로 미실행이다. 최종 구문·상태·파일·재생 모형 결과를 아래에 추가한다.

## 최종 검증 결과
최신 HTML 구문 검사, 전체 회귀 직접 실행과 독립 검증 PASS/exit 0. 기존 15장면/225포커스/450취소와 정방향 173,376개·역방향 260,064개 assertion을 유지했다. 태그 목록 선택/새로 추가만, 최소 승차권 정보, 입력 안쪽 강조, 좌측 정류장 아이콘과 메인 grid/짧은 문구 규칙을 상태/정적으로 검사했다.

소리 파일 네 개는 각각 24 s, 24 kHz, mono, 16-bit PCM WAV이다. RMS -21 dBFS, 클리핑 0, 반복 양끝 샘플 차이 0이며 실제 음향 품질은 청취하지 않았다. 초기 생성 경로가 서버 루트 밖인 것을 발견해 designs/final/assets/audio로 옮기고 생성 스크립트 기본 출력 경로도 수정했다. 최종 루트 직접 확인에서 8794의 4개 파일 모두 HTTP 200/audio-x-wav/1,152,044 bytes였다. 독립 실행 중 한 차례 연결 거부는 루트 재검사에서 재현되지 않았다.

fetch와 decode를 각각 지연한 모형에서 여행 일시정지/화면 변경/숨김/소리 변경, 미리듣기 중단 이후 재생이 되살아나지 않음을 검사했다. 캐시 재사용·반복·파일 실패 안내·지원 없는 환경에서 여행 유지도 통과했다. 브라우저 렌더링·터치·실제 청취는 미검증이다.
