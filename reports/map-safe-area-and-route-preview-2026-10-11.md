# 지도 공간·경로 미리보기·간결한 도착 안내

사용자 요청: 정류장 버튼은 일시정지 바로 아래, 남은 시간은 분만 표시한다. 하차는 도착으로만 안내하고 완료 문구를 없앤다. 시간 선택의 큰 설명 카드 대신 경로 애니메이션을 보여준다. 승차권을 정렬하고 화살표는 제거한다. 모든 화면에서 지도가 패널 뒤에 가려지지 않도록 위치를 조정하고 소리의 거친 잡음을 줄인다.

## 기준
- 남은 시간은 총 분(min)만 표시한다. 준비 시간/승차권의 h/min 표기는 유지한다.
- 정류장 아이콘과 펼친 목록은 왼쪽 일시정지 아래에서 연결한다.
- 도착 화면은 '도착'과 도착지/하차 카드만 안내한다. 여행 완료/기록 완료/여행했어요 문구는 제거하며 내부 완료 기록과 다음 출발지 갱신은 유지한다.
- 승차권은 일정한 좌우 여백과 출발/도착 2열·여행 수치 3열로 정렬하고 방향 화살표를 제거한다.
- 시간 선택은 시간·눈금·확인 중심의 작은 시트로 바꾼다. 바퀴/정류장/거리의 큰 설명 카드는 제거하고 지도에서 선택 경로를 버스 이동으로 미리 보여준다. 미리보기는 실제 여행 타이머와 분리하며 변경/화면 이동에서 취소한다. 동작 줄이기에서는 경로와 도착지만 정적으로 표시한다.
- 지도는 화면에 실제로 보이는 상단/하단 요소를 측정해 남은 지도 공간 안으로 경로를 맞춘다. 여행 중의 진행 방향 추적은 유지하고 펼친 정류장 안내와 겹치는 여백을 보정한다.

## 소리 개선
사용자가 청취한 거친 노이즈 피드백을 기준으로 기존 합성 WAV의 고주파·순간적인 클릭/충격음을 줄이고 일정한 층으로 재생성한다. 외부 AI 모델이나 실환경 녹음이라고 주장하지 않는다. 생성 스크립트·출처·측정은 기존 assets/audio와 scripts/generate-travel-audio.py에 기록한다.

## 검증
최종 JavaScript 구문 검사와 scripts/prototype-edge-qa.cjs 직접 실행은 exit 0 PASS다. 기존 정방향 6,192 조합/173,376 수치 검사, 역방향 6,192 조합/260,064 수치 검사, 15장면 포커스·취소·오디오 비동기 회귀를 유지했다. 새 검사는 시간 미리보기의 실제 여행 상태 무영향·선택/장면/동작 줄이기 취소, 완료 뒤 선택 경로 색 유지, 총 분 표시, 승차권 균등 열과 화살표 제거, 단순 도착을 확인한다.

272×656 mock 좌표에서 측정된 패널의 안전영역 안에 경로 마커가 들어오는지, 펼친 정류장 패널 옆 추적 앵커와 전체 노선 모드 유지, 시트 입장 transform보다 안정적인 layout offset 측정을 확인했다. HTML 기준이며 실제 렌더링·회전/미리보기 시각 품질·음원 청취는 접근 제한으로 미검증이다.

4개 WAV는 24초/24kHz/mono/16bit이며 RMS -26dBFS, 클리핑 0, 반복 경계값 차이 0, 1초 RMS 변동 0.101~0.157dB다. 기존보다 5dB 낮추고 고주파·순간 충격을 줄였다. HTTP 미리보기 응답 200을 확인했다. 기존 페이지의 오디오 캐시를 갱신하려면 새로고침한다.
