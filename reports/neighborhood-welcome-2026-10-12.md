# 시작 화면의 동네 인사말

2026-10-12. 사용자 요청: 현재 동네에서 출발하는 시작 화면에 인사말을 넣고 FocusFlight를 참고한다.

[FocusFlight의 공개 예약 장면](https://www.spottedinprod.com/apps/focusflight/561)에서 지도 위 시간대 인사와 출발 도시명을 함께 배치한 구성을 참고했다. 앞선 조사에 보존한 공개 영상 프레임에서도 이를 확인했다. 원본 화면 자산·문구를 복사하지 않고 우리 앱의 정류장과 한국어 인사말로 구성했다. 이름이 비슷한 별도 웹 타이머 사이트는 참고하지 않았다.

변경 전은 지도 중앙의 정류장 핀과 시작 버튼만 있었다. 변경 후는 지도 왼쪽 위에 짧은 시간대 인사와 동네 문구를 둔다. 지도·현재 정류장·기록/설정·시작 버튼을 유지한다.

| 조건 | 인사·동네 문구 예시 |
|---|---|
| 첫 이용, 출발 정류장 미설정 | 좋은 아침이에요. / 오늘은 어디에서 출발해볼까요? |
| 성수사거리 | 좋은 아침이에요. / 성수동에서, 오늘도 나만의 속도로. |
| 뚝섬역 | 좋은 오후예요. / 뚝섬에서, 잠깐 나에게 집중해요. |
| 서울숲 입구 | 오늘도 수고했어요. / 서울숲에서, 오늘은 조금 느긋하게. |
| 뚝섬한강공원 | 고요한 밤이에요. / 한강 곁에서, 잠깐 쉬어가도 좋아요. |

시간대는 기기의 현지 시간을 기준으로 새벽 0–5시, 아침 6–11시, 오후 12–17시, 저녁 18–23시로 구분한다. 화면 진입·위치 갱신·앱 복귀 때 문구를 갱신한다. 동네 표현은 기존 가상 노선의 9개 정류장에 지정한 카피이며 실제 GPS·날씨·별도 위치 권한을 사용하지 않는다.

정상 하차와 중도 종료 뒤 바뀐 앱 속 현재 정류장에 맞춰 인사가 바뀐다. 저장된 위치로 다시 열어도 같은 동네 인사를 보여준다. 처음 이용할 때는 임의의 동네를 이미 선택한 것으로 표현하지 않는다. 시연용 ‘하차 후 홈’도 예시 기록의 도착지에 맞게 표시한다.

새 문구는 상단의 기존 도구와 분리하고, 읽기 위한 어두운 배경을 지도 위에 얹었다. 작은 높이에서는 문구 크기와 핀 위치를 조정한다. 인사말에 별도의 등장 애니메이션이나 카드·추가 버튼을 넣지 않았다.

검증은 `scripts/main-welcome-qa.cjs`로 첫 이용, 시간대 4종, 정류장 9개, 하차와 저장 위치 복원, 시작 동작, 5개 화면 크기의 겹침과 동작 줄이기를 확인한다. 상태 회귀 검사는 `.impeccable/review/main-welcome-state-qa.log`에 기록한다. 실제 iPhone의 VoiceOver·글자 확대와 사용자 선호는 이 검증에 포함하지 않는다.

두 검사를 직접 실행해 종료 코드 0을 확인했다. 320×568의 긴 문구와 핀 간격을 검사 중 발견해 위치를 조정했고 재확인했다. 브라우저 페이지 오류는 0건이다. Pen의 R01 메인·R18 하차 후 홈, 연결된 전체 흐름 보드와 PDF도 갱신했다. 두 Pen 화면의 잘림 문제 0건을 확인했다.

기존 소유자 전용 프로토타입에 게시 완료. 소스 `5a92e6e46987542ea95bdd1f31e10feed3a23986`, 배포 `appgdep_6acc4e5899cc8191ad05451015c7b8a8`의 `succeeded`를 확인했다. [성수동의 오전 인사 예시](../designs/revised/main-welcome-seongsu.png)는 오전 9시를 지정해 캡처했다.
