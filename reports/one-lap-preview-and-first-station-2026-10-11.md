# 한 바퀴 미리보기와 첫 출발지 설정

## 요청과 적용 기준
- 시간 선택의 미리보기는 선택한 여행 시간과 무관하게 12초 동안 일정한 경로 거리 속도로 한 바퀴 이동한다. 실제 여행 진행 상태는 변경하지 않는다.
- 승차권의 버스 번호는 노선 색·전면 버스 아이콘·유형·번호를 가진 중앙 배지로 표시한다.
- 일시정지 시 현재 위치/지도 도구를 숨기고 우측 상단 빨간 X 포기 버튼을 표시한다. 좌측 재개 버튼과 기존 포기 확인 흐름을 유지한다.
- 출발지 검색은 첫 이용 설정에서만 제공한다. 이후 현재 정류장은 안내이며 여행 도착지가 다음 출발지가 된다. 앱 내부 설정에서 첫 이용 재설정을 제공하지 않는다. 외부 프로토타입 시연용 첫 이용 재생은 앱 흐름과 구분한다.

## 지도 중심의 첫 메인
첫 메인은 현재 위치 지도, 기록/설정 아이콘, 여행 시작하기 버튼으로 구성한다. 시작을 누르면 저장된 현재 정류장·버스 선택 화면으로 연결하며 출발지가 없는 첫 이용은 검색 설정을 먼저 거친다. 큰 여행/기록/설정 탭은 정류장 화면에서 제거한다. 위치는 실제 GPS가 아닌 기존 예시/저장된 앱 정류장 데이터다.

## 검증
최종 JavaScript 구문 검사 PASS, scripts/prototype-edge-qa.cjs 직접 실행 exit 0 PASS. 16장면/256 포커스 전환/512 취소 전환과 기존 정방향 173,376·역방향 260,064 수치 회귀를 통과했다.

새 검사는 3개 버스/짧은·긴 여행의 동일한 12초 한 바퀴 속도, runtime 폐곡선 fullRoute, 실제 여행 상태 무영향, 일시정지의 우상단 포기 버튼·지도 도구 숨김/disabled/직접 호출 방어와 재개 시 포커스 복구, 승차권 아이콘 배지를 확인한다. 첫 설정 검색·취소·빈 결과, 저장된 상태의 검색 차단, 설정 재설정 비활성, 첫/재방문 메인 부팅과 시작 버튼 분기, 기록/설정 복귀와 하차 위치 저장도 통과했다.

실제 브라우저 렌더링과 애니메이션 시각 품질은 기존 접근 거절로 미검증이다.
