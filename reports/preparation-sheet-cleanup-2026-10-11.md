# 준비 시트와 태그 선택 정리

사용자 요청: 뒤로가기를 위해 스크롤하지 않게 하고, 버스 선택·태그 목록·새 태그 만들기를 간결하게 정리한다. 최근 할 일 예시와 기본 여행 시간은 제거한다.

## 화면·흐름 기준
- 뒤로가기/닫기는 시트 상단, 저장/완료는 하단에 고정한다. 긴 내용만 내부 스크롤하고 일반 폰 크기에서는 짧은 준비를 한 화면에 보인다.
- 탑승 패스는 중복 설명과 큰 여백을 줄여 핵심 출발/도착·여행 수치·카드가 함께 보이게 한다. 작은 높이/큰 글씨에서도 탐색 제어를 숨기지 않는다.
- 메인 버스 선택은 별도 간단한 목록으로 열고 노선 유형·번호·방면을 확인해 선택하면 메인 경로 미리보기로 돌아간다.
- 준비 허브의 할 일(태그) 항목 → 태그 목록 → 선택한 태그의 할 일 입력 → 저장 → 허브 → 완료 → 탑승.
- 최근 할 일 예시는 제거한다. 태그 변경은 다시 목록으로 연결하고 초안/취소 정책은 유지한다.
- 새 태그는 이름과 실제 아이콘 견본, 실제 색 견본으로 편집한다. 선택 상태와 미리보기를 즉시 반영한다. 기본 여행 시간 필드·설명·검증은 제거한다. 여행 시간은 별도 시간 화면에서만 정한다.

HTML 기준이며 Pen/PDF/이전 PNG는 이전 시안이다. 브라우저 접근 거절은 우회하지 않고 실제 렌더링·터치는 미검증으로 구분한다.

## 검증
최종 구현 후 신규 흐름·저장/취소·견본 선택·접근성·기존 회귀 결과를 추가한다.

## 최종 검증 결과
최신 구문 검사와 전체 회귀, 독립 검증 PASS/exit 0. 현재 15개 화면의 225개 포커스/숨김 전환과 450개 지연 전환 취소를 검사했다. 기존 정방향 173,376개/역방향 260,064개 assertion, 지도 추적과 정류장 경계 회귀도 유지했다.

별도 3버스 선택→홈/노선 미리보기, 준비 허브→태그 목록→선택 즉시 할 일 입력, 생성/편집 저장, 초안/저장 선택 취소, 완료 후 탑승을 확인했다. 5개 실제 SVG 아이콘과 5개 색 견본은 44px 버튼이며 단일 aria-pressed와 미리보기/텍스트 안전성·재생성 포커스를 검사했다. 기본 시간 필드는 없고 빈/중복 이름 검증을 유지한다. 검토 중 숨긴 tagApply로 이동하던 포커스를 보이는 탐색 버튼으로 수정했다.

고정 시트는 header/footer를 줄어들지 않는 별도 영역으로 두고 내부 body에 min-height:0/overflow:auto를 적용한다. 승차권 카드는 footer에 고정하고 170px 이미지와 간결한 요약을 사용한다. 320×680 레이아웃 규칙은 소스로 확인했으며 실제 렌더링 치수/무스크롤 여부는 브라우저 미실행으로 확정하지 않는다. 접근 제한 때문에 픽셀·터치 검증은 남아 있다.
