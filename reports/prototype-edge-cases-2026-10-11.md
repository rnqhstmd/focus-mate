# 프로토타입 엣지케이스 조사·수정 기록

대상: `designs/final/animation-preview.html`. 조사일: 2026-10-11.
범위는 현재 HTML의 홈 → 시간 → 탑승 → 집중 → 도착 → 홈 흐름이다. 실제 운행 데이터·iOS 런타임·기록 저장 서버는 구현 대상에 포함되지 않는다.

## 조사 방법

기능 상태와 화면·접근성을 독립 검토했다. 실제 스크립트를 Node VM에서 실행해 선택 조합과 경계 상태를 검사했다. 3개 버스의 모든 유효 시간, 4개 태그, 9개 출발 정류장으로 6,192개 준비 조합을 조사하고, 각 조합의 6개 진행률에서 경로 길이와 도착지·숫자의 불변 조건을 검사했다. 기본 검사는 173,376개 assertion이다. 추가 회귀 검사는 아래 재현 조건을 대상으로 한다.

화면은 320/360/402px 너비, 낮은 화면·가로 화면, 글자 확대 200%, 긴 정류장명, 6시간 숫자, 상세 펼침, 이미지 실패를 소스 기준으로 검토했다. 저장된 브라우저 접근 거절은 유지되어 실제 렌더링이나 터치를 실행하지 않았다. CSS 위험과 실제 화면 재현을 구분한다.

## 발견 사항과 수정 범위

P2는 흐름·접근성·가독성에 영향을 주는 문제, P3는 실패 상태의 표현 문제다. U01·U02는 코드 구조에서 확인한 클리핑 위험이며 실제 픽셀 재현으로 단정하지 않는다.

일반 글자 대비 기준은 [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/#contrast-minimum)의 4.5:1을 참고했다.44px는 이 프로토타입의 휴대폰 터치 사용성 목표다. WCAG 2.2 AA의 최소24px 기준과 혼동하지 않는다. [목표 크기 기준](https://www.w3.org/TR/WCAG22/#target-size-minimum)

## 유지한 동작 / 구현 한계

- 버스 변경 시 해당 노선의 도착 가능한 시간에 스냅한다. 최소값은2014번15분,302번18분,421번16분, 최대6시간이다.
- 탑승·하차 중복 입력을 막고 다른 장면으로 이동하면 대기 전환을 취소한다.
- 동작 줄이기에서는 관성·카메라 추적·터치 안내 애니메이션을 생략한다.
- 탭을 떠났다 돌아올 때 지난 시간을 급하게 따라잡지 않는30초 압축 데모다. 실제 앱의 백그라운드 타이머를 검증한 것이 아니다.
- 버스·태그 선택은 같은 페이지의 다음 여행까지 유지한다. 새로고침 이후 저장, 실제 기록 영속화, 앱 복원, 실제 버스 API는 현재 시안에 없다.
- 외부 폰트 의존은 없으며 기존 지도 실패 시 단색 배경과 SVG 경로는 남는다.

## 재검증

실행 가능한 회귀 검사를 `scripts/prototype-edge-qa.cjs`에 보관한다. 저장소에서 `node scripts/prototype-edge-qa.cjs`로 실행한다. 구문 검사·전체 상태 검사·발견 버그 회귀 검사 결과는 수정 완료 후 아래에 기록한다.

수정 후 직접 실행 결과: JavaScript 구문 PASS, 173,376개 상태 assertion PASS, 정확한 정류장 경계5,658개 불일치0, 빠른 장면 전환50개 PASS. 발견했던 소수점 잔여 개수·일시정지 복원 문제의 회귀 조건도 PASS다. 비집중 지도 비활성화, 자동 도착 포커스 전달, 드래그 취소·휠 전환 취소, 동작 줄이기에서 수치 진행, 탭 복귀 시 오래된 시간 delta 배제도 통과했다. 독립 검증이 같은 명령을 실행해 결과를 확인했다.

최종 독립 검토에서 F03의 지도 도구 버튼도 포커스 전달 범위에 포함해야 함을 확인해 보완했다. U05는 이미지 제거 후에도 버튼 면적이 남도록 실패 상태에196px 최소 높이를 명시했다. 공통 카드 규칙에도 같은 최소 높이가 있어 실제 높이0 회귀로 확정하지 않는다. 이 보완도 회귀 검사 대상에 포함한다.

최종 추가 회귀 결과: 집중·지도·지도 도구·상세 닫기 총5개 제어의 자동 도착 포커스 전달 PASS. 이미지 error, 캐시에 남은 실패 이미지, 이후 정상 load 복구와 대체 카드 최소 면적 조건 PASS. 무한 재시도는 추가하지 않았다.

실제 브라우저의320/360/402px 렌더링,200% 글자 확대, iOS Safari 터치·VoiceOver, 이미지 실패 화면, 좁은 숫자 폭, 상세 시트 스크롤과 지도 버튼 배치는 접근 제한 해제 후 확인해야 한다. Pen·PDF·기존 JPG는 이전 시안이며 이번 HTML 수정의 시각 검증 자료로 사용하지 않는다.
