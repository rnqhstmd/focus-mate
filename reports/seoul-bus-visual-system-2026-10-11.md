# 버스 번호·아이콘·노선 색·안내 서체

조사·적용일: 2026-10-11.

## 확인한 공식 자료

[서울시 시내버스 체계 및 이용방법](https://news.seoul.go.kr/traffic/archives/1706)의 유형 구분을 참고한다. 간선은 파랑, 지선은 초록, 순환은 노랑, 광역은 빨강이다. 마을버스는 같은 초록 계열에 속하며 이 앱에서는 지선과 구분하기 위해 연두색으로 표현한다. 아래 HEX는 앱 화면용 선택값이며 공식 차량 도색의 정확한 RGB 규격이라고 주장하지 않는다.

[서울시 서체 안내](https://www.seoul.go.kr/seoul/font.do)는 서울알림체를 공공안내에 최적화된 기능 서체로 소개한다. 공식 수동 설치 파일에서 Medium·Bold 원본 TTF를 내려받아 로컬 프로토타입에 사용한다. 모든 실제 버스 정류장이 이 글꼴을 쓴다고 확인한 것은 아니다. 이용 안내와 출처는 `designs/final/assets/fonts/SOURCE.md`에 보관했다.

번호·유형은 공식 기관의 교통 안내에서 교차 확인했다: [중구의회2014 지선 안내](https://council.junggu.seoul.kr/kr/cms/location), [강남구청343 간선 안내](https://www.gangnam.go.kr/contents/guoffice/1/view.do?mid=ID06_040501), [강남구 지역자활센터 강남02 마을버스 안내](https://www.gangnam.go.kr/office/gjhope/contents/gjhope_location/1/view.do?mid=gjhopelocation). 이 확인은 유형·번호 예시의 근거이며 실제 노선·운행 시간을 데이터 API로 불러온 검증은 아니다.

## 표시 체계

| 유형 | 번호 예시 | 화면 색 | 글자색 | 대비 |
|---|---|---|---|---|
| 지선 | 2014 | #168445 | 흰색 | 4.75:1 |
| 간선 | 343 | #2563EB | 흰색 | 5.17:1 |
| 마을 | 강남02 | #B5D532 | #101410 | 11.09:1 |
| 순환 | 01A | #F2C94C | #16130B | 11.69:1 |
| 광역 | 9401 | #D13A42 | 흰색 | 4.78:1 |

번호는 버스 유형의 표시 예시이며 같은 정류장을 운행한다는 의미가 아니다. 이 시안의 이동 시간과 순환 경로는 가상 예시다. 실제 운행 API에 연결한 결과로 표시하지 않는다.

색만으로 구별하지 않고 버스 아이콘·유형명·번호를 함께 제공한다. 배지 색과 활성 경로 색은 같은 버스 데이터에서 가져온다. 지나온 경로는 중립색, 앞으로의 경로와 도착 표시는 버스 유형 색을 사용한다.

앱용 SVG 아이콘5개와 색 토큰은 `designs/final/assets/bus/`, 유형·번호·서체 미리보기는 `designs/final/bus-guide.html`에 보관한다. SVG는 공식 아이콘 파일을 복제한 것이 아니라 버스 유형을 표현하는 앱용 도형이다.

## 여행 용어

화면에서 '집중 시간·집중 태그·집중 패스'는 '여행 시간·여행 태그·승차권'으로 바꾼다. 독서·작업·공부·휴식은 여행 중 할 일이다. 카드 이미지도 NEXT STEP / TRAVEL PASS로 수정해 `transit-card-next-step.png`로 보관하고 이전 원본은 남긴다. 내부 코드의 `focus` 장면 ID는 기능 회귀를 줄이기 위해 유지한다.

여행 시간 표기는25 min / 2 h / 2 h 30 min으로 통일한다. 태그와 소리는 같은 준비 화면에서 선택하고 완료·편집 저장 뒤 승차권으로 바로 이동한다. 자리 선택과 앱 내 음량 슬라이더는 제공하지 않는다.

소리는 버스·빗소리·소리 없음 중 선택한다. 프로토타입의 버스·빗소리는 Web Audio로 합성한 예시이며 실제 차량 녹음 파일이 아니다. 카드 탭을 계기로 재생을 준비하고 여행 시작·일시정지·화면 전환·완료·탭 숨김에서 재생 수명을 관리한다. API 지원이 없거나 재생이 거절되어도 여행 선택·타이머 흐름은 유지한다. 브라우저 API 사용은 [W3C Web Audio](https://www.w3.org/TR/webaudio/) 및 [MDN 사용자 입력 기반 재생 지침](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)을 참고했다.

## 검증 제한

배지 대비는 토큰 값으로 계산했다. 서체 파일과 SVG의 실제 브라우저 렌더링, 노선 가독성과 작은 화면 시각 검증은 저장된 접근 차단 해제 후 필요하다. Pen·PDF는 이전 시안이며 이번 HTML 업데이트를 자동 반영한 파일이 아니다.
