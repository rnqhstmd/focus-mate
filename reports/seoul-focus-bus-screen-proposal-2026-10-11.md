# 서울 버스 집중앱 화면·기능 제안

상태: 논의용 제안. 사용자가 결정한 것은 온라인 사용과 Apple MapKit의 높은 추적 시점이다. 아래 화면 구성·기능 우선순위·시간 규칙은 제안이며 아직 확정된 구현 명세가 아니다.

## 제품 중심

집중 시간을 서울 버스 여행으로 바꾼다. 사용자는 목적지까지 이동하며 집중하고, 완료한 정류장에서 다음 여행을 이어간다. 첫 화면에서 바로 탑승 준비에 들어갈 수 있어야 한다. 다양한 생산성 도구보다 출발·집중·도착의 한 흐름을 먼저 완성한다.

## 기본 구조

하단 탭은 여행과 기록 두 개. 설정은 화면 상단 아이콘. 지도는 여행 화면과 집중 화면의 중심이다.

| 화면 | 내용 | 주요 행동 |
|---|---|---|
| 여행 홈 | 마지막 하차 정류장, 주변 지도, 25/50분·직접 설정, 탈 수 있는 노선 | 여정 선택 |
| 노선·목적지 선택 | 진행 방향, 정류장 순서, 목적지까지 집중 시간, 추천 목적지 | 목적지 선택 |
| 탑승 준비 | 출발/도착/시간 요약, 선택형 할 일 한 줄, 소리 설정 | 카드 드래그 태그 |
| 집중 중 | MapKit 경로·버스 추적, 남은 시간, 다음 정류장, 목적지 | 보기·소리 변경, 일시정지 |
| 도착 | 실제 집중 시간과 도착 정류장, 카드 태그 연출 | 쉬기 또는 다음 탑승 |
| 기록 | 오늘·이번 주 집중 시간, 여정 목록, 방문 정류장 | 지난 여정 보기 |

## 시간과 목적지

빠른 시작은 시간 우선이다. 홈에서 25분을 선택하면 현재 정류장에서 가능한 노선과 목적지 후보를 추천한다. 여행을 계획하고 싶은 사용자는 노선의 정류장 목록에서 직접 목적지를 고른다. 첫 사용자는 위치 권한 없이 대표 출발지를 선택한다. 앱 속 여행 위치와 실제 GPS 위치는 구분한다.

첫 버전의 시간은 교통 상황에 따른 실제 도착 예측이 아닌 고정된 가상 집중 여정 시간이다. 앱 안에 이를 짧게 설명한다. 한 구간의 시간 표는 일관되게 유지하고, 시간 변경으로 목적지 후보가 달라지도록 한다. 사용자가 특정 목적지와 정확한 시간을 함께 원하면 선택한 구간을 그 시간에 맞추는 방식은 후속 검토 대상이다. 시간 표의 산정 방식은 별도 설계가 필요하며 현재 확정하지 않았다.

## 집중 화면

지도가 화면 대부분을 차지한다. 상단에 출발→도착과 가상 여정임을 알 수 있는 정보, 하단 작은 카드에 남은 시간·다음 정류장·간단한 조작을 둔다. 기본은 비스듬히 높은 시점에서 버스를 추적한다. 전체 노선 보기와 추적 보기의 두 모드만 둔다. 지도 탐색 이후 버스 따라가기 버튼으로 추적에 복귀한다. 좌우 좌석 선택은 초기 높은 추적 시점에서 차이가 작으므로 후속 기능을 제안한다. 실제 버스 좌석 위치·높이를 재현한다고 표현하지 않는다.

카메라 회전은 완만하게 만들고 정류장마다 팝업이나 알림을 띄우지 않는다. 소리는 기본 버스 주행음과 빗소리, 무음부터 시작한다. 움직임 줄이기를 켜면 정적인 지도와 이동 아이콘을 사용한다. 상세 건물 표현과 타일 로딩 품질은 실제 기기 검증이 필요하다.

## 시작과 도착 연출

카드를 단말기에 드래그하여 탑승하는 동작이 첫 버전의 대표 연출이다. 태그 성공 때 집중 시간이 시작된다. 한 번만 짧게 수행하고 햅틱·소리를 넣는다. 접근성을 위해 버튼으로도 출발할 수 있다. 불필요한 카드 잔액·요금·충전 시스템은 초기 범위에 넣지 않는다.

목적지 도착 시 완료 기록과 도착 정류장은 자동 저장한다. 하차 태그는 완료를 확인하는 연출이며 기록 저장을 막지 않는다. 화면을 잠그거나 앱을 떠나도 기본 모드에서는 시간이 계속 흐른다. 다시 열면 경과 시간에 맞는 위치를 복원한다. 일시정지는 가상 버스 이동도 멈추며 중도 종료는 수행한 시간만 기록하고 중도 종료로 표시한다. 중도 종료 후 위치는 마지막 통과 정류장으로 정착시키는 것을 제안한다.

## 다음 여정

완료 후 도착 정류장을 다음 홈에 표시한다. 같은 방향 계속 타기, 반대 방향 출발, 다른 출발지 선택을 제공한다. 초기 선정 노선에서 확인한 반대편 연결만 제공하고, 서울 전체 자동 연결은 후속으로 둔다. 반대편 정류장은 같은 이름으로 추정하지 않고 실제 정류장·노선 연결로 선택한다. 왕복·순환 노선에는 해당 형태에 맞는 안내를 사용한다. 사용자가 가상 위치에 갇히지 않게 다른 출발지 선택은 항상 허용한다.

## 첫 출시 범위

선정한 서울 노선 3~5개, 정류장·목적지 선택, 가상 여정 시간, MapKit 노선과 추적 카메라, 승하차 태그, 소리, 일시정지·복원, 도착 위치 저장, 간단한 집중 기록.

이후 검토: 서울 전체 노선, 환승 여행, 카드·버스 외형 꾸미기, 정류장 수집 확장, 낮밤 연출, 앱 차단, 위젯·Live Activity. 초기에는 실제 창밖 영상, 광범위한 할 일/캘린더 통합, 실시간 교통·도착 예측을 넣지 않는다.

## 사용 예시

홈에서 25분을 선택한다 → 현재 출발지에서 탈 수 있는 노선·목적지 중 하나를 고른다 → 할 일 한 줄을 선택적으로 적는다 → 카드를 찍는다 → 경로를 따라 움직이는 버스를 보며 집중한다 → 도착 기록이 자동 저장된다 → 하차 태그 후 다음 여행 또는 휴식을 고른다.
