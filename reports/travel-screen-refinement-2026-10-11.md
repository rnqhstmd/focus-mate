# 여행 화면 간소화

사용자 요청: 전면 버스로 인식되는 아이콘, 왼쪽 노선도, 간단한 남은 수치, 상단 제어, 태그/버스 설명 제거, 그만두기 추가.

## 화면 구성

- 상단 안전 영역 아래에 일시정지·따라가기·지도·그만두기를 배치한다. 아이콘은 접근성 이름과 선택 상태를 가진다.
- 왼쪽에 현재·다음·도착 정류장을 세로 노선으로 표시한다. 긴 이름은 줄바꿈하고 지도 이동 버스와 겹치는 떠 있는 정류장 설명은 숨긴다.
- 아래는 남은 시간·정류장·거리 세 수치와 진행 정도를 간결하게 표시한다. 요청에서 두 번 나온 남은 시간은 기존 남은 거리로 해석했다.
- 여행 중 상단 버스 번호/태그/할 일 헤더, 소리 설명, 중복 정류장 정보는 보이지 않는다. 선택값과 여행 준비 흐름은 유지한다.

## 버스 아이콘 출처

[Lucide bus-front](https://lucide.dev/icons/bus-front) 공식 SVG를 사용한다. 버스 정면의 앞유리·양쪽 거울·헤드라이트·바퀴 구조로 표현한다. 지도 위 아이콘은 진행 방향에 따라 회전시키지 않고, 선택 버스의 색으로 위치를 표시한다. 유형별 배지도 같은 형태를 사용한다.

원본: https://github.com/lucide-icons/lucide/blob/main/icons/bus-front.svg
라이선스: https://github.com/lucide-icons/lucide/blob/main/LICENSE
다운로드: 2026-10-11. 로컬 자산에 원문 라이선스를 보관한다. 서울시 공식 버스 아이콘이라고 주장하지 않는다.

[FocusFlight 참고 페이지](https://60fps.design/apps/focusflight)를 다시 확인했다. 공개 페이지에서 확인 가능한 자료와 사용자가 지정한 상단 제어 배치 원칙을 참고한다. 유료 샷이나 실제 앱 화면을 이번에 직접 검증했다고 주장하지 않는다.

## 그만두기 정책

그만두기는 앱 내부 확인 화면을 연다. 확인하는 동안 시간과 소리는 멈춘다. 계속 여행/취소는 원래 일시정지 상태를 복원한다. 종료하면 완료 기록 없이 현재까지 도달한 정류장의 홈으로 돌아가고 출발 위치를 저장한다. 완료된 여행의 하차 동작과 구분한다. 중복 실행·다른 화면 전환·키보드 포커스도 검증한다.

## 검증

구문·상태 회귀와 독립 검토를 실행한 뒤 결과를 추가한다. 저장된 브라우저 접근 거절을 우회하지 않으며 실제 렌더링·터치·음향 품질은 미검증이다. HTML 기준 변경이며 Pen/PDF/이전 PNG는 별도 이전 시안이다.

## 상단 지도 가림 후속 요청
메인 정류장 안내는 이름과 방면 중심의 작은 표시로 축소하고 출발 변경 접근은 유지한다. 준비 화면의 큰 버스/태그 헤더도 버스 배지 중심으로 줄인다. 할 일·태그 상세는 이미 있는 하단 준비 화면에서 보여주며 지도 위에 중복해서 표시하지 않는다. 여행 화면에는 큰 정보 헤더를 두지 않는다. 첫 이용의 출발 설정 의미는 유지한다.

## 최종 검증 결과
최신 HTML 구문 검사와 `scripts/prototype-edge-qa.cjs` 직접 실행, 독립 검증 모두 exit 0. 기존 정방향 173,376개·역방향 260,064개 assertion과 정확한 정류장 경계 불일치 0을 유지했다.

신규 검증은 그만두기 확인 중 시간·오디오 정지, 실행/일시정지 상태 취소 복원, Tab/Escape, 부분 도달 정류장 저장과 재실행, 완료 기록 미생성, 12개 외부 화면 전환 시 확인창 정리·포커스를 포함한다. 검토 중 발견한 숨겨진 확인창 버튼의 포커스 잔류와 정류장 레일 자동 도착 포커스를 수정했다. 15 min/6 h와 양방향 정류장 순서·레일 스크롤 구조, 전면 버스 회전 제거, compact 상단과 기본 정보 간소화도 소스/모형으로 확인했다.

실제 픽셀 배치·터치·소리 청취는 미검증이다. 위 PASS는 구문·상태·수학·정적 CSS 검증을 뜻하며 실제 브라우저 시각 검사 통과를 의미하지 않는다.

## 노선도 펼치기 후속 요청
긴 정류장 레일은 기본으로 접고, 작은 노선 버튼을 누르면 왼쪽 목록으로 펼친다. 다시 접으면 지도 공간을 되찾는다. 접힘 상태와 접근성 이름을 동기화하고 내부 포커스가 숨겨지지 않게 처리한다. 상단 버튼 배치와 시간 표시는 FocusFlight 공개 자료를 추가 확인하되 앱의 버스 여행 맥락과 h/min 표기 요구를 유지한다. 긴 노선은 펼친 영역 내부에서 스크롤한다.

노선 접힘과 새 준비 흐름 최종 검증: 14개 화면/196개 포커스 전환/392개 취소 전환 및 기존 수학 회귀 PASS. h/min 주표시와 초 보조표시, 접기 ARIA·포커스·중단 취소 상태 유지도 통과했다. focus-only 표시 규칙이 hidden을 덮지 않도록 명시적인 hidden 우선 규칙을 추가했다.

FocusFlight 추가 확인의 한계: 공식 App Store 페이지(https://apps.apple.com/us/app/focusflight-deepfocus-timer/id6648771147)와 60fps 공개 소개를 확인했으나 여행 중 HUD의 정확한 버튼 배치와 카운트다운 화면은 직접 검증하지 못했다. 상단 compact 제어와 h/min 주표시·s 보조표시는 사용자 요청에 맞춘 해석이며 실제 FocusFlight 화면 복제라고 주장하지 않는다.
