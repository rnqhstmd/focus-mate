# 버스 노선 데이터 (W16)

앱에 넣는 서울 버스 정류장·노선·구간 시간 데이터는 `scripts/build_route_data.py`가 서울 열린데이터광장 원천 파일 두 개로 만든다. 원천 xlsx는 저장소에 두지 않는다.

| 원천 | 데이터셋 | 내려받기 |
|---|---|---|
| `서울시버스노선별정류소정보(YYYYMMDD).xlsx` | [OA-1095](https://data.seoul.go.kr/dataList/OA-1095/F/1/datasetView.do) | 파일 목록 맨 위(최신) |
| `서울시버스노선기본정보(YYYYMMDD).xlsx` | [OA-15066](https://data.seoul.go.kr/dataList/OA-15066/F/1/datasetView.do) | 같은 달 파일 |

저작권자 서울특별시, 두 데이터셋 모두 공공누리 제1유형(출처표시, 상업적 이용 및 변경 가능 — 2026-10-15 데이터셋 페이지에서 확인). 앱 안 '데이터 출처' 화면에 표기한다. 매월 내려받을 때 유형이 바뀌지 않았는지 다시 확인한다.

원천 xlsx는 저장소 밖 폴더에 두고(`.gitignore`가 `*.xlsx`를 막는다) 산출 JSON은 W16b 앱 연결 전까지 번들 위치(`ios/FocusMate/Resources/`)에 두지 않는다.

## 갱신 절차(매월)

1. 위 두 페이지에서 같은 날짜의 xlsx를 내려받는다(파일 이름을 바꾸지 않는다 — 괄호 안 날짜가 기준일이 된다).
2. 실행한다.

```
python3 scripts/build_route_data.py \
  --stops "서울시버스노선별정류소정보(YYYYMMDD).xlsx" \
  --routes "서울시버스노선기본정보(YYYYMMDD).xlsx" \
  --out scripts/data/out/seoul-route-data.json
```

3. 요약(포함·제외 노선, 운행시간 이상 노선, 산출 크기, SHA-256)을 확인하고 산출 파일을 앱 번들 위치로 옮긴다(앱 연결은 W16 후속 단계).

종료 코드: 0 성공, 2 입력 오류(필수 열 누락·기준일 없음), 3 두 파일 결합률 95% 미만, 4 산출 10MB 초과. 실패하면 기존 산출 파일은 그대로 남는다.

## 규칙

- 노선: 두 파일에 모두 있는 노선(정류소정보 `노선명` = 기본정보 `노선번호`). 유형 한강·관광은 제외, 빈 유형은 심야.
- 정류장 정리: 순번 정렬 → 좌표 이상 노선 제외 → 이름이 `(가상)`으로 끝나는 지점 제거 → 연속 같은 정류장 합치기 → 끝이 첫 정류장과 같으면 끝 행 제거.
- 구간 시간: 노선 운행시간(분)을 정류장 사이 직선거리 비율로 나눈다. 구간 최소 30초, 합은 운행시간과 같다(운행시간이 30초×구간 수보다 짧은 노선은 모두 30초라 합이 더 길다). 운행시간이 없거나 직선 속도 3km/h 미만이면 유형별 대체 속도(간선 13.4, 지선 11.6, 마을 8.8, 광역 19.6, 공항 34.8, 심야 17.3, 순환 9.4, 그 밖 11.6km/h).

## 산출 형식

UTF-8 JSON, 줄 단위(정류장 1줄, 노선 1줄). 좌표는 ×1e6 정수.

```
{"format":1,"source":{…},"stops":[
["<NODE_ID>","<정류소명>","<ARS 또는 빈 문자열>",<위도>,<경도>],
…
],"routes":[
["<ROUTE_ID>","<노선 번호>","<유형>",["<NODE_ID>",…],[구간 초…],[구간 m…]],
…
]}
```

노선의 구간 i번째는 정류장 i → i+1이고 마지막은 회차(마지막 → 첫 정류장)다.
